senselab.utils.tasks.embedding_distribution

Describe one set of embedding vectors: a centroid, and statistics about the distribution.

This module describes and never decides. There is no verdict field, no probability, and no thresholded label anywhere in its output. A consumer applies its own threshold, so every statistic here is either bounded on an interpretable scale or paired with an analytic null it can be read against.

Every reference scale is closed-form, which is what keeps the module free of literals nobody fitted:

  • sd of pairwise cosines between independent directions: 1/sqrt(d) (0.0722 at d=192)
  • mean resultant length of n independent directions: E[Rbar^2] = 1/n, so 1/sqrt(n)
  • participation ratio under Marchenko-Pastur: d*n/(d+n)
  • Mann-Whitney AUC under exchangeability: exactly 0.5

The counter-intuitive one. A small sd of cosines is not evidence of a coherent speaker. At d=192 independent random directions give sd ~= 0.072, so an observed 0.05 is below the random-vector null. sd is therefore never reported as a headline dispersion figure -- only beside nulls.cos_sd_null.

Geometry: vectors are L2-normalised on entry, unconditionally. SpeechBrain speaker embeddings are not unit norm, and the norm covaries with window energy and how much speech fills the window -- a cough, or 0.4 s of speech in a 2.0 s window, gets a systematically different norm. Any unnormalised statistic would mix that loudness/occupancy nuisance into what a reader takes for speaker dispersion. ECAPA is trained with an angular-margin objective and scored by cosine, so the norm is not part of the discriminative geometry to begin with.

After normalisation cosine and Euclidean are the same geometry -- ||x-y||^2 = 2(1-cos t), a strictly monotone reparametrisation -- so the common "Euclidean is unusable at high d" objection does not apply to any rank- or neighbour-based quantity. Where a true metric is needed (medoid, linkage) the geodesic arccos(clip(cos,-1,1)) is used, because cos is not a metric and neither is 1-cos.

Deliberately absent, each for a mechanical reason rather than taste:

  • Silhouette. silhouette(metric="cosine") and silhouette(metric="euclidean") return different numbers for identical geometry on unit vectors (Jensen: the square root compresses large distances more than small ones), so any threshold on silhouette is a threshold on a parameterisation choice. It is also a property of a chosen partition, not of the data.
  • k-NN purity. Hubness is severe at this dimension -- k-occurrence skew ~3.3 at d=192, with a measurable fraction of points appearing in no neighbour list -- so neighbour counts carry a bias unrelated to speaker identity. Worse, at 50% window overlap a window's nearest neighbour is almost always the temporally adjacent window, so any same-file purity statistic would read ~1.0 for every input: it would measure the hop size.
  • Intrinsic-dimensionality estimators. Two-NN's r1 becomes the distance to a near-duplicate window, driving the estimate down by the hop size. Same artefact.
  • von Mises-Fisher concentration. kappa = Rbar(d - Rbar^2)/(1 - Rbar^2) is a deterministic function of Rbar and d, both reported, so it stores nothing new; it is unbounded as Rbar -> 1, so it is not interpretable on its own scale; and vMF assumes isotropic concentration, which embedding spaces violate. Recover it in one line if you want it.

 276def _load_gap_significance_margin(path: Optional[Path] = None) -> float:
 277    """Load the gap-significance margin from the bundled profile.
 278
 279    Args:
 280        path: Profile path, or ``None`` for the bundled default.
 281
 282    Returns:
 283        The margin: how many times larger the top merge-height gap must be than the runner-up gap
 284        before it is trusted as a real cluster split rather than a single coherent group's largest
 285        fluctuation.
 286
 287    Raises:
 288        ValueError: If the profile file is missing, its version does not match, or ``margin`` is
 289            missing or not positive. A missing profile used to fall back to
 290            ``DEFAULT_GAP_SIGNIFICANCE_MARGIN`` while the caller still recorded
 291            ``gap_significance_margin_source="profile"`` -- an unfitted constant mislabeled as a
 292            measured one. Raising is what closes that gap: a broken install now fails loudly here
 293            instead of shipping confidently-wrong provenance.
 294    """
 295    target = path if path is not None else _GAP_SIGNIFICANCE_PROFILE_PATH
 296    if not Path(target).exists():
 297        raise ValueError(
 298            f"gap-significance profile {target} is missing from this install. Refusing to "
 299            f"substitute the undocumented constant {DEFAULT_GAP_SIGNIFICANCE_MARGIN} for it and "
 300            "report the result as profile-derived; reinstall senselab or pass an explicit "
 301            "gap_significance_margin."
 302        )
 303    profile = json.loads(Path(target).read_text())
 304    if int(profile.get("version", -1)) != _GAP_SIGNIFICANCE_PROFILE_VERSION:
 305        raise ValueError(
 306            f"gap-significance profile {target} has version {profile.get('version')!r}; "
 307            f"expected {_GAP_SIGNIFICANCE_PROFILE_VERSION!r}"
 308        )
 309    margin = float(profile.get("margin", 0.0))
 310    if margin <= 0:
 311        raise ValueError(f"gap-significance profile {target}: margin must be > 0; got {margin}")
 312    return margin

 381def select_dominant_vectors(
 382    vectors: Union[Sequence[Sequence[float]], np.ndarray, Any],  # noqa: ANN401 — torch.Tensor duck-typed
 383    file_ids: Optional[Sequence[str]] = None,
 384    *,
 385    linkage: str = LINKAGE_AVERAGE,
 386    cut_theta: Optional[float] = None,
 387    gap_significance_margin: Optional[float] = None,
 388    min_file_share: Optional[float] = None,
 389) -> DominantSelection:
 390    """Group vectors and return the dominant group, for optional contamination rejection.
 391
 392    **This is the one function in the module that decides something**, which is why it is separate
 393    from :func:`describe_embedding_distribution` and why callers opt in. Everything it did is
 394    recorded in the returned object.
 395
 396    Agglomerative hierarchical clustering on geodesic angular distance, average linkage. Chosen
 397    over spectral clustering for three reasons: it is deterministic, where
 398    ``SpectralClustering(assign_labels="kmeans")`` is stochastic and pinning a seed hides that
 399    variance rather than removing it; k-means-family clustering carries an equal-size bias and will
 400    split one speaker's prosodic halves before isolating a small intruder; and AHC turns "choose
 401    k" into a merge-height profile that can be reported instead of decided.
 402
 403    Args:
 404        vectors: ``(n, d)`` embeddings. L2-normalised on entry.
 405        file_ids: One id per row. Enables file-balanced selection and per-file drop accounting.
 406        linkage: Passed to ``scipy.cluster.hierarchy.linkage``. ``"average"`` by default.
 407        cut_theta: Angular cut in radians. ``None`` derives it from the largest gap in the merge
 408            heights, accepted only when it beats the runner-up gap by ``gap_significance_margin``
 409            -- a *rule*, not a fitted constant; see the derivation below. Supply a value to
 410            override; either way the value used and its source are recorded.
 411        gap_significance_margin: How many times larger the top merge-height gap must be than the
 412            runner-up gap before it is trusted as a real split. ``None`` (the default) loads the
 413            fitted value from `data/embedding_gap_significance.json`, derived from a 1600-draw
 414            sweep of the null (single coherent group) merge-gap-ratio distribution to hold the
 415            false-split rate at or below 1%; see that file for the full derivation. Supply a value
 416            to override; either way the value used and its source are recorded.
 417        min_file_share: Optional floor on a file's share within a group before that file counts
 418            toward the group's file-balanced share. ``None`` counts every contributing file.
 419
 420    Returns:
 421        A :class:`DominantSelection`.
 422
 423    Raises:
 424        ValueError: If fewer than 2 vectors survive normalisation, or ``file_ids`` length disagrees.
 425    """
 426    from scipy.cluster.hierarchy import fcluster
 427    from scipy.cluster.hierarchy import linkage as scipy_linkage
 428    from scipy.spatial.distance import squareform
 429
 430    raw = _as_array(vectors)
 431    n_total = int(raw.shape[0])
 432    if file_ids is not None and len(file_ids) != n_total:
 433        raise ValueError(f"file_ids has {len(file_ids)} entries for {n_total} vectors")
 434
 435    norms = np.linalg.norm(raw, axis=1)
 436    keep_mask = norms > 0
 437    original_index = np.flatnonzero(keep_mask)
 438    x, _ = _l2_normalise(raw)
 439    n = int(x.shape[0])
 440    if n < 2:
 441        raise ValueError(f"need at least 2 non-zero vectors to select a dominant group; got {n}")
 442
 443    ids = [str(f) for f, k in zip(file_ids, keep_mask) if k] if file_ids is not None else ["_all"] * n
 444
 445    theta = np.arccos(np.clip(x @ x.T, -1.0, 1.0))
 446    np.fill_diagonal(theta, 0.0)
 447    theta = (theta + theta.T) / 2.0  # enforce exact symmetry for squareform
 448    z = scipy_linkage(squareform(theta, checks=False), method=linkage)
 449    merge_heights = [float(h) for h in z[:, 2]]
 450
 451    if gap_significance_margin is None:
 452        margin_value = _load_gap_significance_margin()
 453        margin_source = "profile"
 454    else:
 455        margin_value = float(gap_significance_margin)
 456        margin_source = "caller"
 457
 458    if cut_theta is None:
 459        # The largest gap between consecutive merge heights is where the data itself separates --
 460        # but the raw argmax is not enough on its own. A single coherent group (no intruder at all)
 461        # still has *some* largest gap, and it is usually down near the leaves from sampling noise
 462        # in how tightly the first few points happen to land, not at the root where a real
 463        # population split would show up. `margin_value` is the fitted answer to "how much bigger
 464        # than the runner-up gap must the top gap be before it is trusted": see
 465        # `data/embedding_gap_significance.json` for the 1600-draw sweep of the null distribution
 466        # and the false-split rate the bundled margin achieves. Below that margin nothing stands
 467        # out from the rest, and the cut is set at the maximum merge height, which folds every row
 468        # into one cluster rather than fabricating a split.
 469        heights = np.asarray(merge_heights)
 470        gaps = np.diff(heights)
 471        if gaps.size >= 2:
 472            order = np.argsort(gaps)
 473            top1_idx, top2_idx = int(order[-1]), int(order[-2])
 474            if gaps[top1_idx] > margin_value * gaps[top2_idx]:
 475                resolved_cut = float((heights[top1_idx] + heights[top1_idx + 1]) / 2.0)
 476            else:
 477                resolved_cut = float(heights.max())
 478        elif heights.size:
 479            # Fewer than two gaps to compare -- too little evidence to call a gap significant, so
 480            # the conservative reading (one cluster) is the same fallback as the no-signal branch.
 481            resolved_cut = float(heights.max())
 482        else:
 483            resolved_cut = 0.0
 484        cut_source = "largest_merge_gap"
 485    else:
 486        resolved_cut = float(cut_theta)
 487        cut_source = "caller"
 488
 489    labels = fcluster(z, t=resolved_cut, criterion="distance")
 490
 491    file_counts: dict[str, int] = {}
 492    for f in ids:
 493        file_counts[f] = file_counts.get(f, 0) + 1
 494
 495    summaries: list[ClusterSummary] = []
 496    for cid in sorted(set(int(v) for v in labels)):
 497        member = labels == cid
 498        member_files = [f for f, m in zip(ids, member) if m]
 499        per_file: dict[str, float] = {}
 500        for f in set(member_files):
 501            per_file[f] = member_files.count(f) / file_counts[f]
 502        counted = {f: s for f, s in per_file.items() if min_file_share is None or s >= min_file_share}
 503        summaries.append(
 504            ClusterSummary(
 505                cluster_id=cid,
 506                n_vectors=int(member.sum()),
 507                window_share=float(member.sum() / n),
 508                file_balanced_share=float(sum(counted.values()) / len(file_counts)),
 509                n_files_contributing=len(per_file),
 510                per_file_share=per_file,
 511            )
 512        )
 513
 514    ranked = sorted(summaries, key=lambda c: (c.file_balanced_share, c.window_share), reverse=True)
 515    dominant = ranked[0]
 516    runner_up = ranked[1] if len(ranked) > 1 else None
 517
 518    dominant_centroid = _spherical_mean(x[labels == dominant.cluster_id])
 519    cos_to_runner: Optional[float] = None
 520    if runner_up is not None:
 521        cos_to_runner = float(dominant_centroid @ _spherical_mean(x[labels == runner_up.cluster_id]))
 522
 523    kept = [int(original_index[i]) for i in range(n) if labels[i] == dominant.cluster_id]
 524    dropped = [int(original_index[i]) for i in range(n) if labels[i] != dominant.cluster_id]
 525    dropped_per_file: dict[str, int] = {}
 526    for i in range(n):
 527        if labels[i] != dominant.cluster_id:
 528            dropped_per_file[ids[i]] = dropped_per_file.get(ids[i], 0) + 1
 529
 530    return DominantSelection(
 531        kept_indices=kept,
 532        dropped_indices=dropped,
 533        clusters=summaries,
 534        dominant_cluster_id=dominant.cluster_id,
 535        runner_up_cluster_id=runner_up.cluster_id if runner_up else None,
 536        cos_dominant_to_runner_up=cos_to_runner,
 537        dropped_per_file=dropped_per_file,
 538        rule_used=SelectionRule(
 539            linkage=linkage,
 540            cut_theta=resolved_cut,
 541            cut_source=cut_source,
 542            merge_heights=merge_heights,
 543            gap_significance_margin=margin_value,
 544            gap_significance_margin_source=margin_source,
 545            min_file_share=min_file_share,
 546        ),
 547    )

 550def _as_array(
 551    vectors: Union[Sequence[Sequence[float]], np.ndarray, Any],  # noqa: ANN401 — torch.Tensor duck-typed
 552) -> np.ndarray:
 553    """Coerce input to a 2-D float64 array without importing torch at module scope.
 554
 555    Args:
 556        vectors: A nested sequence, a numpy array, or anything exposing ``detach``/``cpu``/``numpy``
 557            (a torch tensor).
 558
 559    Returns:
 560        A 2-D ``float64`` array, one row per vector.
 561
 562    Raises:
 563        ValueError: If the result is not 2-D.
 564    """
 565    if hasattr(vectors, "detach"):
 566        vectors = vectors.detach().cpu().numpy()
 567    arr = np.asarray(vectors, dtype=np.float64)
 568    if arr.ndim != 2:
 569        raise ValueError(f"vectors must be 2-D (n, d); got shape {arr.shape}")

 573def _l2_normalise(x: np.ndarray) -> tuple[np.ndarray, int]:
 574    """Return unit-norm rows and the count of zero-norm rows removed.
 575
 576    Args:
 577        x: ``(n, d)`` array.
 578
 579    Returns:
 580        ``(normalised, n_dropped)``. A zero-norm row has no direction, so it cannot contribute to
 581        any angular statistic; it is dropped rather than producing ``nan``, and counted so
 582        ``n_scored`` stays explainable.
 583    """
 584    norms = np.linalg.norm(x, axis=1)
 585    keep = norms > 0
 586    n_dropped = int((~keep).sum())
 587    return x[keep] / norms[keep][:, None], n_dropped

 590def _spherical_mean(x: np.ndarray) -> np.ndarray:
 591    """Unit-norm mean direction of unit-norm rows.
 592
 593    This is the von Mises-Fisher MLE direction, and its error shrinks as ``O(n^-1/2)``. An
 594    arithmetic mean of *unnormalised* vectors would weight each row by its norm -- i.e. by
 595    loudness and speech occupancy -- so a loud cough would outvote a quiet target utterance.
 596
 597    Args:
 598        x: ``(n, d)`` unit-norm array.
 599
 600    Returns:
 601        A unit-norm ``(d,)`` direction.
 602
 603    Raises:
 604        ValueError: If the rows sum to the zero vector, which has no direction.
 605    """
 606    s = x.sum(axis=0)
 607    norm = float(np.linalg.norm(s))
 608    if norm == 0.0:
 609        raise ValueError("vectors sum to zero; no mean direction exists")
 610    return s / norm

 613def _similarity_stats(values: np.ndarray) -> SimilarityStats:
 614    """Summarise a 1-D array of cosine values.
 615
 616    Args:
 617        values: Any 1-D array of cosines.
 618
 619    Returns:
 620        Quantiles plus mean and sd. ``sd`` is included for completeness but is meaningless without
 621        ``nulls.cos_sd_null`` beside it; see the module docstring.
 622    """
 623    v = np.asarray(values, dtype=np.float64).ravel()
 624    q = np.quantile(v, [0.05, 0.25, 0.50, 0.75, 0.95])
 625    return SimilarityStats(
 626        min=float(v.min()),
 627        q05=float(q[0]),
 628        q25=float(q[1]),
 629        q50=float(q[2]),
 630        q75=float(q[3]),
 631        q95=float(q[4]),
 632        max=float(v.max()),
 633        mean=float(v.mean()),
 634        sd=float(v.std(ddof=1)) if v.size > 1 else 0.0,
 635    )

 638def _loo_cos_to_centroid(x: np.ndarray) -> np.ndarray:
 639    """Cosine of each row to the centroid computed *without* that row.
 640
 641    Scoring a vector against a centroid it helped define is optimistically biased -- each row pulls
 642    the centroid toward itself. Closed form, one pass, no loop: with ``S = sum x_j`` over unit
 643    rows, the leave-one-out mean direction is proportional to ``S - x_i``, so
 644    ``cos_loo(i) = x_i . (S - x_i) / ||S - x_i||``.
 645
 646    Args:
 647        x: ``(n, d)`` unit-norm array with ``n >= 2``.
 648
 649    Returns:
 650        ``(n,)`` array of leave-one-out cosines.
 651    """
 652    s = x.sum(axis=0)
 653    diff = s[None, :] - x
 654    denom = np.linalg.norm(diff, axis=1)
 655    numerator = np.einsum("ij,ij->i", x, diff)
 656    out = np.zeros_like(denom)
 657    nz = denom > 0
 658    out[nz] = numerator[nz] / denom[nz]
 659    return out

 662def _trimmed_spherical_mean(x: np.ndarray, fraction: float = _TRIM_FRACTION) -> np.ndarray:
 663    """Spherical mean after dropping the ``fraction`` of rows least aligned with the full mean.
 664
 665    Args:
 666        x: ``(n, d)`` unit-norm array.
 667        fraction: Share of rows to drop, from the low end of leave-one-out cosine.
 668
 669    Returns:
 670        A unit-norm direction. Falls back to the untrimmed mean when trimming would leave fewer
 671        than two rows.
 672    """
 673    n = x.shape[0]
 674    k = int(np.floor(fraction * n))
 675    if k < 1 or n - k < 2:
 676        return _spherical_mean(x)
 677    keep = np.argsort(_loo_cos_to_centroid(x))[k:]
 678    return _spherical_mean(x[keep])

 681def _medoid(x: np.ndarray) -> np.ndarray:
 682    """The input row minimising total geodesic distance to the others.
 683
 684    Uses angular distance ``arccos(clip(cos))`` rather than ``1-cos``, because only the former is
 685    a metric on the sphere and "medoid" is defined against a metric.
 686
 687    Args:
 688        x: ``(n, d)`` unit-norm array.
 689
 690    Returns:
 691        A copy of the selected row.
 692    """
 693    theta = np.arccos(np.clip(x @ x.T, -1.0, 1.0))
 694    return x[int(np.argmin(theta.sum(axis=1)))].copy()

 697def _centroid_robustness(x: np.ndarray, file_ids: Optional[list[str]], mean_centroid: np.ndarray) -> CentroidRobustness:
 698    """Aggregation sensitivity plus leave-one-file-out stability.
 699
 700    Args:
 701        x: ``(n, d)`` unit-norm array.
 702        file_ids: One id per row, or ``None``.
 703        mean_centroid: The spherical mean over all rows. Kept as the one reference for every
 704            comparison here regardless of which aggregator the caller selected for the returned
 705            centroid, so e.g. ``cos_mean_vs_medoid`` never ends up comparing the medoid to itself.
 706
 707    Returns:
 708        The populated robustness block.
 709    """
 710    trimmed = _trimmed_spherical_mean(x)
 711    medoid = _medoid(x)
 712
 713    lofo: dict[str, float] = {}
 714    if file_ids is not None:
 715        ids = np.asarray(file_ids)
 716        order: list[str] = []
 717        for f in file_ids:
 718            if f not in order:
 719                order.append(f)
 720        for f in order:
 721            rows = x[ids != f]
 722            # A single remaining row still has a direction; zero remaining rows does not.
 723            lofo[f] = float(mean_centroid @ _spherical_mean(rows)) if rows.shape[0] >= 1 else 1.0
 724
 725    return CentroidRobustness(
 726        cos_mean_vs_trimmed10=float(mean_centroid @ trimmed),
 727        cos_mean_vs_medoid=float(mean_centroid @ medoid),
 728        leave_one_file_out_cos=lofo,
 729    )

 732def _spectrum(x: np.ndarray) -> SpectrumStats:
 733    """Participation ratio, centred PC1 share, and the top-5 eigenvalue shares.
 734
 735    Uses singular values of the centred matrix rather than forming the ``d x d`` covariance: both
 736    quantities are ratios, so the ``1/(n-1)`` factor cancels and the SVD is cheaper and better
 737    conditioned.
 738
 739    Args:
 740        x: ``(n, d)`` unit-norm array.
 741
 742    Returns:
 743        The spectrum summary.
 744    """
 745    centred = x - x.mean(axis=0, keepdims=True)
 746    sv = np.linalg.svd(centred, compute_uv=False)
 747    lam = sv**2
 748    total = float(lam.sum())
 749    if total == 0.0:
 750        # Every row identical: no variation at all. One occupied direction, by definition.
 751        return SpectrumStats(participation_ratio=1.0, pc1_share_centred=0.0, eigenvalue_shares_top5=[0.0] * 5)
 752    pr = float(total**2 / float((lam**2).sum()))
 753    shares = (lam / total).tolist()
 754    top5 = [float(v) for v in shares[:5]] + [0.0] * max(0, 5 - len(shares))
 755    return SpectrumStats(participation_ratio=pr, pc1_share_centred=float(shares[0]), eigenvalue_shares_top5=top5)

 758def _per_file_stats(
 759    x: np.ndarray, file_ids: Optional[list[str]], pooled_centroid: np.ndarray
 760) -> tuple[dict[str, WithinFileStats], CrossFileStats]:
 761    """Within-file coherence and cross-file agreement.
 762
 763    Kept strictly apart because the measured error budget on this pipeline is almost entirely
 764    cross-file (within-file cosine stability 0.984 against cross-file 0.891). Pooling them would
 765    average away the most informative split there is.
 766
 767    Args:
 768        x: ``(n, d)`` unit-norm array.
 769        file_ids: One id per row, or ``None``.
 770        pooled_centroid: The centroid over all rows.
 771
 772    Returns:
 773        ``(within_file, cross_file)``. Both are empty when ``file_ids`` is ``None``.
 774    """
 775    if file_ids is None:
 776        return {}, CrossFileStats()
 777
 778    order: list[str] = []
 779    for f in file_ids:
 780        if f not in order:
 781            order.append(f)
 782
 783    within: dict[str, WithinFileStats] = {}
 784    centroids: dict[str, np.ndarray] = {}
 785    ids = np.asarray(file_ids)
 786    for f in order:
 787        rows = x[ids == f]
 788        c = _spherical_mean(rows)
 789        centroids[f] = c
 790        cos_own = rows @ c
 791        within[f] = WithinFileStats(
 792            n_vectors=int(rows.shape[0]),
 793            rbar=float(np.linalg.norm(rows.sum(axis=0)) / rows.shape[0]),
 794            cos_to_own_centroid_q05=float(np.quantile(cos_own, 0.05)),
 795            cos_to_own_centroid_q50=float(np.quantile(cos_own, 0.50)),
 796        )
 797
 798    to_pooled = {f: float(centroids[f] @ pooled_centroid) for f in order}
 799
 800    pairwise: Optional[SimilarityStats] = None
 801    if len(order) >= 2:
 802        stacked = np.stack([centroids[f] for f in order])
 803        gram = stacked @ stacked.T
 804        iu = np.triu_indices(len(order), k=1)
 805        pairwise = _similarity_stats(gram[iu])
 806
 807    return within, CrossFileStats(cos_file_centroid_to_pooled=to_pooled, file_centroid_pairwise_cos=pairwise)

 810def _mann_whitney_auc(within: np.ndarray, between: np.ndarray) -> float:
 811    """Probability that a randomly chosen within-group value exceeds a between-group one.
 812
 813    ``AUC = P(w > b) + 0.5*P(w == b)``, computed from ranks so it costs one sort rather than a
 814    quadratic comparison. Rank-based is the point: the value is invariant to any monotone
 815    reparametrisation of the similarity, which is exactly the property silhouette lacks.
 816
 817    Args:
 818        within: 1-D array of within-group values.
 819        between: 1-D array of between-group values.
 820
 821    Returns:
 822        The AUC in ``[0, 1]``. Returns ``0.5`` when either side is empty -- no evidence either way.
 823    """
 824    if within.size == 0 or between.size == 0:
 825        return 0.5
 826    from scipy.stats import rankdata
 827
 828    combined = np.concatenate([within, between])
 829    ranks = rankdata(combined)
 830    r_within = float(ranks[: within.size].sum())
 831    u = r_within - within.size * (within.size + 1) / 2.0
 832    return float(u / (within.size * between.size))

 835def _eta_squared_between_files(x: np.ndarray, ids: np.ndarray) -> float:
 836    """Between-file share of angular variance.
 837
 838    ``1 - sum_f n_f (1 - Rbar_f^2) / [n (1 - Rbar^2)]``: the residual within-file dispersion
 839    removed from the total. Bounded in ``[0, 1]`` for well-formed input.
 840
 841    Args:
 842        x: ``(n, d)`` unit-norm array.
 843        ids: ``(n,)`` array of file ids.
 844
 845    Returns:
 846        The between-file share; ``0.0`` when the pooled set has no dispersion to explain.
 847    """
 848    n = x.shape[0]
 849    rbar = float(np.linalg.norm(x.sum(axis=0)) / n)
 850    total = n * (1.0 - rbar**2)
 851    if total <= 0:
 852        return 0.0
 853    resid = 0.0
 854    for f in np.unique(ids):
 855        rows = x[ids == f]
 856        nf = rows.shape[0]
 857        rf = float(np.linalg.norm(rows.sum(axis=0)) / nf)
 858        resid += nf * (1.0 - rf**2)
 859    return float(1.0 - resid / total)

 862def _file_effect(
 863    x: np.ndarray,
 864    file_ids: Optional[list[str]],
 865    window_starts_s: Optional[list[float]],
 866    window_s: Optional[float],
 867    hop_s: Optional[float],
 868    n_permutations: int,
 869    seed: int,
 870) -> FileEffect:
 871    """Separability AUC plus a block-permutation reference for the between-file variance share.
 872
 873    Args:
 874        x: ``(n, d)`` unit-norm array.
 875        file_ids: One id per row, or ``None``.
 876        window_starts_s: Window start times aligned to ``x``, or ``None``.
 877        window_s: Window length, used for the guard band and the block length.
 878        hop_s: Hop, used for the block length.
 879        n_permutations: Shuffles for the reference.
 880        seed: Permutation seed.
 881
 882    Returns:
 883        The populated :class:`FileEffect`, or a default one when there is no file structure.
 884    """
 885    block_len = 1
 886    if window_s is not None and hop_s is not None and hop_s > 0:
 887        block_len = max(1, int(np.ceil(window_s / hop_s)))
 888
 889    if file_ids is None or len(set(file_ids)) < 2:
 890        return FileEffect(permutation_block_len=block_len, n_permutations=0, seed=seed)
 891
 892    ids = np.asarray(file_ids)
 893    gram = x @ x.T
 894    iu = np.triu_indices(x.shape[0], k=1)
 895    same = ids[iu[0]] == ids[iu[1]]
 896    cos_pairs = gram[iu]
 897
 898    guard_band_s: Optional[float] = None
 899    keep = np.ones(cos_pairs.shape, dtype=bool)
 900    if window_starts_s is not None and window_s is not None:
 901        # Adjacent windows share audio, so a same-file pair drawn from them is a near-duplicate.
 902        # Excluded from both sides, or the AUC would report the hop size.
 903        guard_band_s = float(window_s)
 904        starts = np.asarray(window_starts_s, dtype=np.float64)
 905        too_close = np.abs(starts[iu[0]] - starts[iu[1]]) < guard_band_s
 906        keep = ~(same & too_close)
 907
 908    auc = _mann_whitney_auc(cos_pairs[keep & same], cos_pairs[keep & ~same])
 909
 910    observed = _eta_squared_between_files(x, ids)
 911    rng = np.random.default_rng(seed)
 912    n = x.shape[0]
 913    n_blocks = int(np.ceil(n / block_len))
 914    # Named for what it counts, not what it sounds like it should: each iteration tests
 915    # `shuffled_eta_sq <= observed`, i.e. a permutation draw that does *not* exceed the observed
 916    # statistic, so the resulting quantile is "share of the null at or below observed" -- a
 917    # variable called `exceeded` here previously counted the opposite of its own name.
 918    n_le_observed = 0
 919    for _ in range(n_permutations):
 920        block_order = rng.permutation(n_blocks)
 921        shuffled = np.concatenate([ids[b * block_len : (b + 1) * block_len] for b in block_order])[:n]
 922        if _eta_squared_between_files(x, shuffled) <= observed:
 923            n_le_observed += 1
 924    quantile = float(n_le_observed / n_permutations) if n_permutations > 0 else None
 925
 926    return FileEffect(
 927        auc_same_file_vs_diff_file=auc,
 928        permutation_quantile=quantile,
 929        permutation_block_len=block_len,
 930        n_permutations=n_permutations,
 931        guard_band_s=guard_band_s,
 932        seed=seed,
 933    )

 949    Decides nothing. See the module docstring for the geometry, the analytic nulls, and what is
 950    deliberately absent.
 951
 952    Args:
 953        vectors: ``(n, d)`` embeddings. Normalised on entry regardless of input scale.
 954        file_ids: One id per row, when the vectors come from several files. Enables the per-file
 955            statistics; ``None`` treats the set as one group.
 956        aggregator: ``"spherical_mean"`` (default), ``"trimmed_mean"``, or ``"medoid"``. A tool
 957            parameter, not a decision: the returned block always reports the cosine between the
 958            mean and both alternatives, so a reader sees whether the choice mattered.
 959        window_s: Window length in seconds, used for ``n_effective`` and the permutation block
 960            length. ``None`` leaves both unreported rather than guessed.
 961        hop_s: Hop between windows in seconds.

 963            same-file guard band; without it that guard is skipped and reported as ``None``.

 972            ``aggregator`` is unknown, or if ``file_ids``/``window_starts_s`` lengths disagree with
 973            ``vectors``.
 974    """
 975    if aggregator not in _AGGREGATORS:
 976        raise ValueError(f"aggregator must be one of {_AGGREGATORS}; got {aggregator!r}")
 977
 978    raw = _as_array(vectors)
 979    n_total = int(raw.shape[0])
 980    if file_ids is not None and len(file_ids) != n_total:
 981        raise ValueError(f"file_ids has {len(file_ids)} entries for {n_total} vectors")
 982    if window_starts_s is not None and len(window_starts_s) != n_total:
 983        raise ValueError(f"window_starts_s has {len(window_starts_s)} entries for {n_total} vectors")
 984

 986    keep_mask = norms > 0
 987    x, n_dropped = _l2_normalise(raw)
 988    n = int(x.shape[0])
 989    if n < 2:
 990        raise ValueError(f"need at least 2 non-zero vectors to describe a distribution; got {n}")
 991    d = int(x.shape[1])
 992
 993    kept_files = [str(f) for f, k in zip(file_ids, keep_mask) if k] if file_ids is not None else None
 994
 995    # The robustness comparisons and per-file statistics stay pinned to the spherical mean
 996    # regardless of `aggregator`, so a caller who picked "medoid" still gets a diagnostic
 997    # comparing the medoid *against* the mean rather than against itself.
 998    mean_centroid = _spherical_mean(x)
 999    if aggregator == AGGREGATOR_SPHERICAL_MEAN:
1000        centroid = mean_centroid
1001    elif aggregator == AGGREGATOR_TRIMMED_MEAN:
1002        centroid = _trimmed_spherical_mean(x)
1003    else:
1004        centroid = _medoid(x)
1005
1006    within_file, cross_file = _per_file_stats(x, kept_files, mean_centroid)
1007

1009    file_effect = _file_effect(x, kept_files, starts_list, window_s, hop_s, n_permutations, seed)
1010
1011    per_file: dict[str, int] = {}
1012    if kept_files is not None:
1013        for f in kept_files:
1014            per_file[f] = per_file.get(f, 0) + 1
1015
1016    n_effective: Optional[float] = None
1017    if window_s is not None and hop_s is not None and window_s > 0:
1018        # total covered duration / window_s (this class's own contract, see `CountsInfo`):
1019        # overlapping windows do not carry independent information, and pretending they do makes
1020        # every n^-1/2 null overconfident. Per file, not over the pooled set as one timeline --
1021        # a multi-file pool has no single timeline to begin with, and treating `n` rows as one
1022        # contiguous recording undercounts duration by roughly half whenever there are several
1023        # files (measured: 100 single-window files reported 50.5 against the correct 100.0).
1024        # `per_file` already holds one count per file (or one entry for the whole set when no
1025        # file ids were supplied), so this reduces to the single-timeline formula in that case.
1026        if per_file:
1027            n_effective = float(sum((hop_s * (nf - 1) + window_s) / window_s for nf in per_file.values()))
1028        else:
1029            n_effective = float((hop_s * (n - 1) + window_s) / window_s)
1030

1032        geometry=GeometryInfo(
1033            metric="cosine",
1034            l2_normalised=True,
1035            dim=d,
1036            distance="angular",
1037            centroid_rule=aggregator,
1038        ),
1039        counts=CountsInfo(
1040            n_vectors_total=n_total,
1041            n_scored=n,
1042            n_zero_norm_dropped=n_dropped,
1043            n_files=len(per_file) if per_file else (1 if kept_files is None else 0),
1044            vectors_per_file=per_file,
1045            window_s=window_s,
1046            hop_s=hop_s,
1047            n_effective=n_effective,
1048        ),
1049        nulls=NullsInfo(
1050            cos_sd_null=float(1.0 / np.sqrt(d)),
1051            rbar_null=float(1.0 / np.sqrt(n)),
1052            participation_ratio_null=float(d * n / (d + n)),
1053            auc_null=0.5,
1054        ),
1055        cos_to_centroid_loo=_similarity_stats(_loo_cos_to_centroid(x)),
1056        rbar=float(np.linalg.norm(x.sum(axis=0)) / n),
1057        spectrum=_spectrum(x),
1058        within_file=within_file,
1059        cross_file=cross_file,
1060        file_effect=file_effect,
1061        centroid_robustness=_centroid_robustness(x, kept_files, mean_centroid),
