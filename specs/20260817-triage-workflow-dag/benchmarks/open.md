# Still unmeasured

What the current design owes. A parameter listed here is in the spec with its interval or its shape
stated and its constant unjustified — not silently guessed.

## Blocking an outcome that the design promises

| item | what it blocks | what would settle it |
| --- | --- | --- |
| **SQUIM thresholds over speech spans** | SPEECH's quality `fail` is unreachable, so "dismiss because of quality" has no path | labelled quality verdicts on speech spans, from more than one recording |
| **How much disruption is too much** | the same `fail`. Disruption *counts* are exact and need no threshold; what has no value is the tolerance — how many clipped runs, or what clipped duration, makes a span unusable | labelled verdicts pairing disruption counts with a human judgement of usability |
| **The phonation gate's floors** | VOICE's gate carries an interval — periodicity `(0.44, 0.933)`, RMS `(0.0007, 0.0161)` — and no value | labelled voiced/unvoiced verdicts; a wide gap on one file cannot locate the boundary on another |
| **TAXONOMY's presence floors** | **both `triage: pass` and `triage: discard`, on every default run.** Every floor under `taxonomy.presence_floor` is null, so every evidence line reads `unavailable`, every kind reads `uncertain`, and TAXONOMY writes a `flag` — which the fold's ladder row 2 tests before anything else it could have concluded. The acoustically-empty discard is blocked twice over, since no kind can read `absent` either. The graph therefore flags every file it is given, whatever it measured | labelled per-kind presence verdicts, enough of them to fit a floor per line rather than per kind |
| **The redaction padding margin** | REDACT pads outward by a margin that must exceed the *worst* alignment edge error, which is unquantified | edge error distribution for `alignment` over many words, not its median |

## Blocking implementation, found by the capability audit

| item | what it blocks | why |
| --- | --- | --- |
| **A PII finding cannot say where it is** | **SPEECH step 7 and all of REDACT** | the speaker-scoped rule needs to know where a finding sits to test it against target spans, and REDACT needs an extent to redact. The fix is to carry the `ScriptLine` scanned rather than to add offset fields: `ScriptLine` already holds `start`, `end`, `speaker` and `timestamp_model`, and a bespoke `start_s` float would both duplicate `start` and discard which producer timed it. Planned as Task 1 of `plan-foundation.md` |
| **HeAR's module refuses the padded input AIRWAY specifies** | AIRWAY step 1 | the whole-span-in-a-2 s-buffer path works only because a buffer of exactly 32000 samples passes the length check. It needs a named function rather than each caller rediscovering the coincidence |
| **`MossFormer2_SS_16K` RMS-normalises its input to −25 dBFS** | SPEECH steps 5, 7, 8 | absolute level is destroyed on separated streams, so `level` and any dBFS-referenced measurement taken on a separated stream is not comparable with one taken on the recording. Every measurement already records its stream; the consequence needs stating in the spec |
| **`classify_audios` defaults to `top_k=5` for YAMNet** | PREPROCESS `silence`, TAXONOMY | `Silence` can fall outside the top 5 and simply be absent, which reads as a zero score |
| **`classify_audios` applies softmax for AST** | TAXONOMY | AudioSet is multi-label; softmax makes the scores a distribution they are not |
| **`resample_audios` designs its anti-alias filter at the target rate and applies it at the source rate** | PREPROCESS's 16 kHz resample | for 48→16 kHz the explicit pre-filter may be close to inert. **Unverified** — SpeechBrain's sinc interpolation may cover it, and a sweep test would settle it. Not asserted as a defect |

## Decisions with no measurement behind them

| item | current state |
| --- | --- |
| **The word-gap threshold** grouping words into speech spans | unspecified. Any value is a claim about what makes one utterance |
| **The F0 search range** — `voice.f0_range_hz` and `voice.f0_range_by_population` | no single range serves both populations: wide enough for a low adult male fundamental admits period-doubling artefacts, narrow enough to exclude them cuts off infant and high-F0 voices. The caller must state which population it is measuring, and a run whose F0 sits where the range is ambiguous is flagged rather than resolved |
| **What consumes fabrication candidates** | SPEECH detects them and nothing acts on them |
| **`speech.second_diarizer`** — which model corroborates pyannote's count | no measured ranking of second diarizers exists. While null, a count that is not 1 records `second_diarizer: not_consulted` and still flags, so the flag is reached without the corroboration it was meant to carry |
| **`speech.target_match_cosine`** — the similarity above which a diarized speaker is the enrolled target | no threshold has been derived on this embedding model. While null, an enrollment is refused rather than answered with an invented cut, so the enrolled path is unreachable by design until it is fitted |
| **`taxonomy.presence_floor` per line** | the v1 `min_families` committee is deleted. Each kind now has named evidence lines — speech `acoustic`/`lexical`, airway `health_acoustic`/`acoustic` — and all four floors are null. The asymmetry the v1 row stated survives as the line structure; the counts do not exist |

## Measurements named in the specs and not run

| item | why it matters |
| --- | --- |
| **ASR plain vs pre-emphasised** — WER and token-edge displacement | PREPROCESS sends ASR the plain signal by analogy from SQUIM's incoherent shift, not from measurement |
| **`MossFormer2_SS_16K` across SNR** | never run; the two *enhancement* MossFormer variants diverge sharply, so its behaviour cannot be assumed from theirs |
| **Separation's benefit on overlapping speech** | on the reference recording speech and airway never overlap, so the case separation exists for is untested |
| **Span rules inside proposed rather than labelled regions** | every scored peak was located inside a labelled span; unsupervised operation over a whole envelope is the harder problem |
| **A recording with gaps longer than the widest reader window** | invented events cannot be measured on the reference file — its longest verified-empty stretch is 1.80 s against HeAR's 2 s window, so `verified_empty` measures window bleed |
| **Labelled data for the non-lexical kind** | VOICE has none, so nothing there can be scored |
| **The glide criterion cannot classify a pitch glide on steady formants** | the phonation criterion's two continuity limbs are OR'd and the formant limb alone suffices, so F0 150-600 Hz sweeps over a steady vowel read `sustained` at every rate probed; only articulatory sweeps (formants moving with F0) ever read `glide`. The clinical glissando task is exactly the misclassified shape. No fit of `f0_stability_cents`/`formant_stability_hz` repairs it — the criterion needs an independent F0-excursion limb, an owner ruling |
| ~~**The token lane's text-skipping width, and the lane's density at campaign length**~~ **— both settled 2026-08-26; what is left is one monotonicity wart** | The seconds threshold is gone: `TOKEN_LABEL_MIN_WIDTH_S` and the panel's `min_width_s` key are deleted, and `_FittedTokenLabel.draw` compares the label's own rendered width in points against the span it is given, measured against the renderer of the draw in progress — so it holds for Agg, for `savefig` to PNG and for `PdfPages`, and is retaken from the full size on every draw. The label is shrunk from `TOKEN_LABEL_FONTSIZE = 5.0` pt toward `TOKEN_LABEL_FLOOR_FONTSIZE = 4.0` pt and dropped if it does not fit there; the bar is never dropped. **The density is settled by staggered rows.** The tokens that declare no `row` are spread over `R` sub-rows, token `i` in row `i mod R` counted from the top; a bar keeps its time extent and each label is measured against the slot its row leaves it — the midpoint to the nearest token sharing its row, the window edge, or `R` times its own bar, whichever is nearest — so `R = 1` is byte-identical to the per-bar fit. `R` is the fewest rows at which the lane's own labels lie side by side, `ceil(Σ(width at the floor + padding) / row width)`, with no target fraction and no tuned constant, capped by a typographic ceiling: `TOKEN_ROW_PITCH_EM = 2.0` multiples of the label's point size, derived from a rendered label box being at most 0.972 × its point size tall. Story-recall density at 14 in: 12 s **33 → 33 of 35 at 1 row** (unchanged, as intended), 30 s **13 → 84 of 88 at 2 rows**, 60 s **0 → 144 of 168 at 3 rows**, 30 s at 8 in **0 → 46 at 2 rows**. Round-robin was measured against greedy first-fit and wins at every row count and geometry (84 vs 71 at 30 s / R=2; 144 vs 114 at 60 s / R=3); the declared `row` keeps precedence and is never restaggered; the rows carry no y-tick and share one colour, so they cannot read as speaker lanes; pairwise display-space non-overlap is asserted at 30 s, at 60 s and on a page narrow enough to exhaust the ceiling. **Still owed, and it is not a threshold:** *a wider page can draw fewer labels than a narrower one* — 84 at 14 in against 72 at 20 in for the same 30 s lane, because at 20 in the aggregate demand fits one row while 16 labels still overflow their own bars. The per-token quantile that would fix it was measured and rejected: only `q = 0.90` repairs the inversion, and it is also the value that spends 4 rows on 29 uncrowded words and 5 on a two-bar lane, while `q = 0.75`/`0.80` agree with the shipped rule everywhere and fix nothing. The same root leaves the longest words dropped at 60 s (`grandfather` needs 24.76 pt at the floor; three rows of a 0.30 s bar give 14.5 pt). `report-legibility-2026-08-26.md` D-3 and D-4 |
| **The 40 Hz envelope's own ringing proposes spans** | between two close events the zero-phase lowpass rings, and the lobe in the gap clears the airway `k_db`: on the three-burst preprocess fixture the lobe at 1.4745 s rises 36.3 dB over an honest floor of −74.98 dBFS, so one span reports `merged_proposals: 4` for three bursts. The count therefore mixes filter ripple with events. Unmeasured: whether the ripple lobe is separable from a real event by rise, width or the filter's own impulse length, or whether the merge count should be taken over post-merge events instead. Measured 2026-08-26 while removing the −240 dBFS clamp (`report-legibility-2026-08-26.md`) |
| **Single-frame span fragmentation in the phonation pass** | one near-flat or reversed F0 frame opens a 2-frame `sustained` span mid-sweep, splitting one glide into glide/sustained/glide and halving the reported excursion; a noise bed produced 18 spans on 3 s. Root cause is `_sustained_runs` opening a span on a single continuing frame with no minimum duration; T5 reads the longest span, so fragmentation changes what it reports |
| **`config.get` on a deleted key is a silent None** | pre-alpha delete-outright leaves any surviving `config.get(old_key)` reader as a silent no-op rather than an error (observed: speech.py reading a T1-deleted key through `get`); whether `get` should raise on unknown-key like `require` does is a foundation decision |
| **CT2-path CrisperWhisper reports no word scores** | on the Linux ct2 backend every word `score` and the line score are None, so the asr axis carries no native CrisperWhisper uncertainty signal on the cluster; unmeasured on the transformers path |
| **Separated-stream quality routing** | branch-speech.md §8 wants a known target's quality measured on that speaker's separated stream; no source-to-speaker assignment mechanism is specified, so SPEECH measures every span on `plain` and records `stream: plain` honestly. Needs a specified assignment (e.g. embedding match per stream) before the routing can exist |
| **Duplicate PII text within one span** | the word-labelling locator maps a repeated finding text to its first occurrence only; the second occurrence's words carry no `pii` label — an under-redaction hazard for REDACT. The token-subsequence scheme (N11) does not define the repeat case |
| **N7's record-similarities-without-deciding reading** | the shipped node refuses at entry when a provenanced target arrives while `speech.target_match_cosine` is null, so no similarities are recorded; N7's prose implies they would be. One of the two must move |
| **PREPROCESS's recognizer set is declared only per-block** | REDACT derives the expected verification set from the asr activities, which are written just before each transcribe call; a recognizer dying earlier (HFModel construction, offline commit resolution) leaves no activity and silently drops out of the expected set. The durable fix is PREPROCESS declaring its recognizer set unconditionally in the condition activity before any block runs |
| **Fusion coupling under the post-fusion bound** | out-of-bounds hallucinated words participate in `fuse_word_streams` before being dropped; if fusion couples one word's presence to another's confidence, survivors' confidences differ from a never-there baseline. Unmeasured; bounding the input streams pre-fusion would remove the question at the cost of a per-stream count |
| **A fix to a derivative producer does not reach a completed run, and the page cannot tell** | REPORT draws the envelope from the stored sidecar (`run/derivatives/energy_envelope.npz` via `envelope.attributes["path"]`) and the spans from `store.jsonl`; it recomputes nothing. So `d8543990`, which replaced the -240 dBFS clamp with NaN and fixed two span-proposal bugs behind it, is a **no-op on every existing run**: 12 of 14 sampled campaign sidecars carry 97-3184 samples at exactly -240.0 and not one NaN, so ~6 of every 7 re-rendered pages still show the stretched axis, and span counts are byte-identical to the pre-fix render because they come out of the store. Masking the sentinel at render time was rejected -- it would make the artifact disagree with the code that made it and still would not reproduce the changed proposal. Two consequences to hold: a derivative-level fix requires re-analysis, not re-rendering; and the campaign's spans (which AIRWAY and VOICE both read) were proposed by the buggy proposer, so the three-lane comparison and the LLM lane both describe pre-fix spans |
| **A sustained-phonation span needs no voicing to be admitted** | `propose_phonation_spans` forms runs on `continues = f0_ok OR formant_ok` (`tasks/phonation/api.py:410`), and voicing is only *described* afterwards by `_statistics`. Formant stability is defined on any audio -- broadband noise has a slowly-moving LPC envelope -- so the formant limb alone admits spans on material with no voicing at all. Measured on the campaign's breath file: 3 spans covering 0.02-19.85 s (the entire recording), every one `member=sustained`, `production=unvoiced`, `voiced_fraction=0.0`, `offset_criterion=formant_stability`; and on `Free-speech-(v2)-1` a single sustained/unvoiced span covering the whole file, which is what the report's phonation lane draws. A span whose voiced fraction is 0.0 and whose family is `phonation` is a contradiction in terms. The fix owed is a decision, then a fit: whether the sustained member requires the voiced fraction to clear a floor (and what that floor is), or whether the formant limb proposes a differently-named family. Nothing here should be re-thresholded by hand |
| **Phonation spans are written twice into the store** | the breath run's store carries each of its 3 phonation spans as two entities with identical extents and different ids -- one pair carrying `voiced_fraction`, one not, so two writers with different attribute sets, not one writer looping. REPORT filters with `_spans_of_family(store, "phonation", voice=False)` and so draws one copy, which is why the duplication is invisible on the page and was found only in the store. Related to the architect review's A-5 (spans have four writers disambiguated by activity-node string) |
| **Clipping is measured and never adjudicated** | PREPROCESS writes `disruptions_file` with `clipped_runs`, `clipped_s`, `dropout_runs`, `dropout_s`, `discontinuities`, `dc_offset`, `zero_crossing_rate` -- measured on the ORIGINAL recording, which is the right instrument. But `quality.disruption_clipped_s_max` and `quality.disruption_dropout_s_max` are both null and the campaign override leaves them null deliberately ("the gates they would arm report without gating, by design, until labelled verdicts exist"), so no node reads the counts, VERDICT has no clipping reason, and REPORT draws no disruptions block. The counts reach the store and stop there. Compounding it, the shipped `clip_headroom` 0.999 with `min_clip_run` 3 reads 0 on every campaign file including four whose originals peak at exactly 0.0 dBFS -- the campaign breath file has exactly 2 adjacent samples at 0.9995, one short of the run length, so a recording that touches full scale records no clipping. The fit owed: the tolerance (how much clipped audio is too much), and a re-examination of `min_clip_run` against recordings known to be clipped |
| **Enrollment-path extents overrun the decode by 14-447 ms** | four files (Picture-description, Rainbow-Passage, DDK-Pataka, Free-speech-1 across two subjects) completed SPEECH unenrolled but raised the extent-inconsistency guard when an enrollment was supplied — overruns of 223.5-7157.5 samples, far past the one-sample float tolerance, so a real inconsistency in the per-speaker slice path that only the enrollment branch exercises. Phase-4 evidence retained on the cluster |
| **Whole-corpus enrollment centroids are contaminated by non-lexical files** — *source policy DECIDED 2026-08-25 and implemented; the cut and the re-measurement are still owed* | enrolling over ALL of a subject's files pulls the ECAPA centroid toward cough/breath/DDK material (HardCough cosine -0.045 against its own subject's centroid); leave-one-out medians 0.51-0.64 straddle the guessed 0.5 cut, so target attribution lands at 53%. **The source policy is no longer open**: the owner ruled that enrollment skips breathing/cough/airway files and focuses on speech, and `runs/b2ai-v2/make_enrollment.py` now selects exactly the tasks whose hint `speech_type` is `read`/`elicited`/`recall` — excluding every airway file and every non-lexical voice task (vowel, MPT, glides, loudness, DDK) — refusing a subject with no speech file. What is still owed is a fit, not a decision: **`speech.target_match_cosine`**, and a **re-measurement of leave-one-out separation and target attribution over speech-only centroids**, since every number in this row was taken on contaminated centroids against a guessed cut and none of them describes what the policy now builds. **Re-measured 2026-08-25** (sbatch 21248774, `$SCRATCH/triage_b2ai_v2_enr_speech/measurement.md`; recomputed old centroids reproduce phase 4 to cosine 1.0000 and HardCough -0.045 to the digit): speech-only LOO medians rise to 0.669/0.705/0.693 with every q25 above 0.5; falsely attributed non-speech files fall 39/59 to 13/59 while attributed speech holds 52/53; the speech-vs-excluded separation margin moves from negative on all three subjects (-0.166/-0.147/-0.157) to +0.287/+0.035/-0.085. HardCough reads -0.088 against the new centroid, still negative as it should. What the policy did NOT supply is the cut: no single threshold separates speech from non-speech on all three subjects (one subject admits none; the two-subject intersection is a 0.035-wide band nowhere near 0.5), so **`speech.target_match_cosine` is now the sole binding open item** -- and these are file-direction cosines, bounding rather than predicting the SPEECH node's per-diarized-speaker scoring |
| **`_can_align_segment` guards `t1` and never `t2`** (upstream, `forced_alignment.py:138-144`) | an over-long transcript end passes the guard and raises `ValueError` from `extract_segments` three frames deeper instead of the `False` the guard exists to return — every caller of forced alignment inherits this, not just triage |
| **The PII planner and its verifier do not scan the same thing** | SPEECH's planner scans per-span `ScriptLine`s built from CONSENSUS words, while REDACT's verifier re-transcribes the redacted audio whole-file per recognizer and scans fresh hypotheses. A name no recognizer pair agreed on is invisible to the planner and visible to the verifier, which is a permanently unreleasable state with no path to release — observed on DDK-KA: 0 planned redactions, verifier found NAME/PERSON. The verifier being the stricter of the two is defence in depth and should stay; what is missing is a designed path out, e.g. the planner falling back to single-recognizer hypotheses when consensus is empty or sparse |
| **PII findings on non-lexical audio are not reproducible** | re-transcription of the same wordless or DDK audio hallucinated different text across runs and across hosts, so a PII finding on such a file is not stable run-to-run — seen cross-host, and it is the mechanism behind the DDK-KA planner/verifier split above. Any release policy for wordless recordings has to be stated in terms of hallucination instability, not of a single scan's findings |

## Retired with the round-based workflow

`design.md` §8 carried M1–M10. M1 (`nontarget_active` semantics), M2 (frame-posterior dip in a short
gap), M3 (frame-level speech/babble separation), M5 (dominant-cluster anchor under a talkative
intruder), M6 (the embedding window), M7 (the shrinkage pseudo-count) and M10 (region-narrowed cache
misses) all concern machinery the current DAG does not contain. They are not outstanding; they are moot.
M4 and M8 survive above as the non-lexical labelled-data gap.
