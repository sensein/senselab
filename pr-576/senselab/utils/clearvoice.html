senselab.utils.clearvoice

Machinery shared by every senselab task that exposes ClearerVoice-Studio (ClearVoice).

One pip distribution, one isolated venv, one checkpoint-pinning rule, one device contract, one timeout derivation, one worker. No capability lives here, and nothing here imports senselab.audio: this module speaks in file paths, and each task package owns its own Audio/Video conversion.

The six checkpoints and the task package that owns each:

=============================== ========================== ======= =========================================== Upstream task Model Rate senselab home =============================== ========================== ======= =========================================== speech_enhancement FRCRN_SE_16K 16 kHz audio/tasks/speech_enhancement speech_enhancement MossFormerGAN_SE_16K 16 kHz audio/tasks/speech_enhancement speech_enhancement MossFormer2_SE_48K 48 kHz audio/tasks/speech_enhancement speech_separation MossFormer2_SS_16K 16 kHz audio/tasks/source_separation speech_super_resolution MossFormer2_SR_48K 48 kHz audio/tasks/speech_super_resolution target_speaker_extraction AV_MossFormer2_TSE_16K 16 kHz audio/tasks/target_speaker_extraction =============================== ========================== ======= ===========================================

SpeechScore, upstream's fifth component, is not reachable from here: it has no pip distribution and a disjoint dependency set, so it gets its own venv and worker in senselab.audio.tasks.features_extraction.clearvoice_speechscore.

Upstream's loader takes no revision, so senselab pins by pre-staging at a resolved commit and pointing the loader at a local path; stage_clearvoice_checkpoints() and stage_s3fd_weights() are that mechanism. Every design decision, deviation and measurement behind this module: specs/20260819-clearvoice-integration/design.md.

123@dataclass(frozen=True)
124class ClearVoiceModelSpec:
125    """One ClearVoice checkpoint and everything senselab needs in order to run it.
126
127    Attributes:
128        name: Upstream model name. Doubles as the HuggingFace repository name under
129            :data:`CLEARVOICE_HF_ORG` and as the key ``network_wrapper`` dispatches on.
130        upstream_task: The ``task`` string ``clearvoice.ClearVoice`` takes.
131        sampling_rate: Rate the checkpoint was trained at. Inputs are resampled to it on the host,
132            and outputs come back at it.
133        expected_outputs: Signals per input this checkpoint is *expected* to produce — 2 for the
134            separator, 0 for the audio-visual extractor, whose count is its number of face tracks.
135            An expectation to check against, never a source count to assume: design.md D-5.
136        rms_normalises_input: Whether upstream's reader RMS-normalises the input to -25 dBFS before
137            decoding, which it does for ``FRCRN_SE_16K`` and ``MossFormer2_SS_16K`` only. Reproduced
138            including its asymmetry on the multi-source branch: design.md D-11.
139        capability: Human-readable capability name, for log lines and error messages.
140    """
141
142    name: str
143    upstream_task: str
144    sampling_rate: int
145    expected_outputs: int
146    rms_normalises_input: bool
147    capability: str
148
149    @property
150    def model_id(self) -> str:
151        """The HuggingFace id a caller names this checkpoint by."""
152        return f"{CLEARVOICE_HF_ORG}/{self.name}"

184def is_clearvoice_model_id(model_id: str) -> bool:
185    """Whether ``model_id`` names a ClearVoice checkpoint.
186
187    Args:
188        model_id: A HuggingFace-style model id.
189
190    Returns:
191        True for any id under :data:`CLEARVOICE_HF_ORG` — org-wide, so an unknown model under that
192        org reaches :func:`clearvoice_model_spec`'s message rather than a dispatcher's "no backend".
193    """
194    return model_id.startswith(f"{CLEARVOICE_HF_ORG}/")

197def clearvoice_model_spec(model_id: str, *, expected_task: Optional[str] = None) -> ClearVoiceModelSpec:
198    """Resolve a model id (or bare upstream model name) to its spec.
199
200    Args:
201        model_id: ``"alibabasglab/FRCRN_SE_16K"`` or ``"FRCRN_SE_16K"``.
202        expected_task: If given, the upstream task the calling task package owns; a checkpoint for a
203            different capability is rejected rather than run by the wrong entry point.
204
205    Returns:
206        The matching :class:`ClearVoiceModelSpec`.
207
208    Raises:
209        ValueError: If the name is not one of the six checkpoints, or names a different capability
210            than ``expected_task``.
211    """
212    name = model_id.split("/")[-1]
213    spec = CLEARVOICE_MODELS.get(name)
214    if spec is None:
215        raise ValueError(
216            f"{model_id!r} is not a ClearVoice checkpoint. clearvoice=={CLEARVOICE_VERSION} ships "
217            f"exactly six: {', '.join(sorted(CLEARVOICE_MODELS))}."
218        )
219    if expected_task is not None and spec.upstream_task != expected_task:
220        raise ValueError(
221            f"{spec.model_id!r} is a {spec.capability} checkpoint, not a "
222            f"{expected_task.replace('_', ' ')} one. Call {_TASK_OWNERS[spec.upstream_task]} for it "
223            "instead."
224        )
225    return spec

243def stage_clearvoice_checkpoints(spec: ClearVoiceModelSpec, revision: str = "main") -> Tuple[Path, str]:
244    """Download one checkpoint set at a resolved commit, returning its directory and that commit.
245
246    Downloads the files the commit's own ``last_best_checkpoint`` manifest names, which land as
247    siblings in one ``snapshots/<sha>/`` directory — exactly the ``checkpoint_dir`` upstream's loader
248    wants. This is senselab's pin for a loader that accepts no revision: design.md D-6.
249
250    Args:
251        spec: The checkpoint to stage.
252        revision: Ref or commit to resolve, through the run-scoped resolver.
253
254    Returns:
255        ``(checkpoint_dir, commit_sha)`` — a directory holding ``last_best_checkpoint`` and the
256        weight files it names, and the 40-hex commit those bytes came from.
257    """
258    from huggingface_hub import hf_hub_download
259
260    from senselab.utils.model_revision import resolve_revision
261
262    sha = resolve_revision(spec.model_id, revision)
263    manifest = Path(hf_hub_download(spec.model_id, "last_best_checkpoint", revision=sha))
264    # One name per line; MossFormer2_SR_48K's manifest names two (MossFormer stage, then vocoder).
265    for filename in (line.strip() for line in manifest.read_text().splitlines()):
266        if filename:
267            hf_hub_download(spec.model_id, filename, revision=sha)
268    return manifest.parent, sha

271# The S3FD face detector: absent from the wheel, fetched by upstream from an unversioned Google
272# Drive id. Pinned by commit and verified by digest instead; design.md D-7.
273_S3FD_COMMIT = "6b3774dc79c46ae8bed2a4fa5f706f0ac8c75c61"

277_S3FD_SHA256 = "d54a87c2b7543b64729c9a25eafd188da15fd3f6e02f0ecec76ae1b30d86c491"
278_S3FD_SIZE_BYTES = 89844381

281def stage_s3fd_weights() -> Path:
282    """Fetch and verify the S3FD face-detector weights, returning the local path.
283
284    Cached content-addressed under ``~/.cache/senselab/clearvoice/s3fd/<sha256>/``, downloaded under
285    a lock, and moved into place atomically so an interrupted fetch cannot look staged.
286
287    Returns:
288        Path to ``sfd_face.pth``.
289
290    Raises:
291        RuntimeError: If the downloaded bytes do not match :data:`_S3FD_SHA256`. See design.md D-7.
292    """
293    root = _cache_dir_path() / "clearvoice" / "s3fd" / _S3FD_SHA256
294    weights = root / "sfd_face.pth"
295    if weights.is_file():
296        return weights
297
298    root.mkdir(parents=True, exist_ok=True)
299    with SharedFileLock(root, timeout=600):
300        if weights.is_file():
301            return weights
302        logger.info(f"ClearVoice: fetching S3FD face-detector weights at commit {_S3FD_COMMIT[:12]}")
303        digest = hashlib.sha256()
304        with tempfile.NamedTemporaryFile(dir=str(root), delete=False, suffix=".part") as tmp:
305            tmp_path = Path(tmp.name)
306            with urllib.request.urlopen(_S3FD_URL) as response:  # noqa: S310 -- constant https URL
307                while chunk := response.read(1 << 20):
308                    digest.update(chunk)
309                    tmp.write(chunk)
310        actual = digest.hexdigest()
311        if actual != _S3FD_SHA256:
312            tmp_path.unlink(missing_ok=True)
313            raise RuntimeError(
314                f"S3FD weights fetched at commit {_S3FD_COMMIT} hashed {actual}, expected "
315                f"{_S3FD_SHA256}. This file has no revision-addressable home upstream, so the digest "
316                "is its only identity; refusing it rather than running an unknown face detector."
317            )
318        os.replace(tmp_path, weights)
319    return weights

540def _run_worker(payload: Dict[str, object], timeout_s: float, label: str, on_timeout: str) -> dict:
541    """Provision the venv, run the worker, and turn a timeout into an actionable failure.
542
543    Args:
544        payload: The worker's JSON input.
545        timeout_s: Ceiling in seconds.

def stage_s3fd_weights() -> pathlib.Path: 
282def stage_s3fd_weights() -> Path:
283    """Fetch and verify the S3FD face-detector weights, returning the local path.
284
285    Cached content-addressed under ``~/.cache/senselab/clearvoice/s3fd/<sha256>/``, downloaded under
286    a lock, and moved into place atomically so an interrupted fetch cannot look staged.
287
288    Returns:
289        Path to ``sfd_face.pth``.
290
291    Raises:
292        RuntimeError: If the downloaded bytes do not match :data:`_S3FD_SHA256`. See design.md D-7.
293    """
294    root = _cache_dir_path() / "clearvoice" / "s3fd" / _S3FD_SHA256
295    weights = root / "sfd_face.pth"
296    if weights.is_file():
297        return weights
298
299    root.mkdir(parents=True, exist_ok=True)
300    with SharedFileLock(root, timeout=600):
301        if weights.is_file():
302            return weights
303        logger.info(f"ClearVoice: fetching S3FD face-detector weights at commit {_S3FD_COMMIT[:12]}")
304        digest = hashlib.sha256()
305        with tempfile.NamedTemporaryFile(dir=str(root), delete=False, suffix=".part") as tmp:
306            tmp_path = Path(tmp.name)
307            with urllib.request.urlopen(_S3FD_URL) as response:  # noqa: S310 -- constant https URL
308                while chunk := response.read(1 << 20):
309                    digest.update(chunk)
310                    tmp.write(chunk)
311        actual = digest.hexdigest()
312        if actual != _S3FD_SHA256:
313            tmp_path.unlink(missing_ok=True)
314            raise RuntimeError(
315                f"S3FD weights fetched at commit {_S3FD_COMMIT} hashed {actual}, expected "
316                f"{_S3FD_SHA256}. This file has no revision-addressable home upstream, so the digest "
317                "is its only identity; refusing it rather than running an unknown face detector."
318            )
319        os.replace(tmp_path, weights)
320    return weights
