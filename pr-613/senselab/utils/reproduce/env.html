senselab.utils.reproduce.env

The install engine: build a step's venv from its verified locks, check it, and prepare R libraries.

prefetch_env runs, in order: the integrity check (locks.check_integrity); a copy of every verified file into a private temp dir, each copy re-checked against the verified sha256; uv venv --python <python_exact>; stage 1, the torch lock (--no-deps --require-hashes, plus --index-url for an index-compiled lock); stage 2, the body (--no-deps --require-hashes --only-binary :all: --index-url <body.index_url>); stage 3, each sdist_allow wheel, reused or built through build.ensure_wheel, copied with build.stage_wheel and installed --no-deps; then each overlay (test, notebook_tools) into its own derived venv holding the base locks plus the overlay; and finally installed.json, the parsed uv pip freeze, which must equal the locks. Every install reads a copy, never a file in the manifest repository or the wheelhouse. Every uv call passes --no-config and runs with build.base_environment; nothing else of the caller's environment reaches uv.

Venvs live at <cache>/venvs/repro-<analysis>-<env_key8> (derived: …+<overlay sha256[:8]>). Each has a .reproduce-venv.json marker naming its key, overlay, wheel sha256s, the sha256 of installed.json and the result of the checks. An installed venv whose marker matches is reused; anything else is removed and rebuilt, under a flock on the sidecar <venv>senselab.utils.reproduce.lock. A venv is complete (venv_checked) only once uv pip check and the smoke imports have passed, which prefetch_env runs only when given a profile; a run must refuse an unchecked venv.

R envs (kinds r and ir_notebook) are prepared by prefetch_r under the profile's R module, outside the network namespace, from the Posit Package Manager snapshot of env.r_snapshot. It writes <r_lib>/MODULE_ENV.json (the modules' PATH and LD_LIBRARY_PATH) and <r_lib>/SESSION.json (sessionInfo(), .libPaths() and installed versions), and fails unless every declared r_packages version is the installed one. r_env_vars gives a step's R variables in the merge order: module LD_LIBRARY_PATH entries first, then native lib dirs.

 160def env_key(env: EnvSpec) -> str:
 161    """Return the identity of an env's base venv, from its inputs only.
 162
 163    Args:
 164        env: The step's env.
 165
 166    Returns:
 167        A hex sha256 over the torch and body lock sha256s, each sdist's name, URL, sha256, patch
 168        sha256s, build lock sha256, build variables, build modules and arch list, ``python_exact``
 169        and ``max_cuda``. Wheel sha256s, overlays and file locations are not part of it.
 170    """
 171    payload = {
 172        "schema": ENV_KEY_SCHEMA,
 173        "torch_lock_sha256": None if env.torch is None else env.torch.lock_sha256,
 174        "body_lock_sha256": env.body.lock_sha256,
 175        "sdist": [
 176            {
 177                "name": s.name,
 178                "url": s.url,
 179                "sha256": s.sha256,
 180                "patch_sha256s": [p.sha256 for p in s.patches],
 181                "build_env_lock_sha256": s.build_env.lock_sha256,
 182                "build_env_vars": dict(sorted(s.build_env_vars.items())),
 183                "build_modules": list(s.build_modules),
 184                "torch_cuda_arch_list": s.torch_cuda_arch_list,
 185            }
 186            for s in env.sdist_allow
 187        ],
 188        "python_exact": env.python_exact,
 189        "max_cuda": env.max_cuda,
 190    }
 191    return hashlib.sha256(json.dumps(payload, sort_keys=True).encode()).hexdigest()

 250def _write_json(path: Path, data: object) -> str:
 251    text = json.dumps(data, indent=2, sort_keys=True) + "\n"
 252    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")
 253    try:
 254        with os.fdopen(fd, "w") as handle:
 255            handle.write(text)
 256        mask = os.umask(0)
 257        os.umask(mask)
 258        os.chmod(tmp, 0o666 & ~mask)
 259        os.replace(tmp, path)
 260    finally:
 261        if os.path.exists(tmp):
 262            os.unlink(tmp)
 263    return hashlib.sha256(text.encode()).hexdigest()

 266def copy_verified(base_dir: Path, verified: Mapping[str, str], dest: Path) -> None:
 267    """Copy each verified file into ``dest`` and check the copy against the verified sha256.
 268
 269    Args:
 270        base_dir: The manifest repository.
 271        verified: `locks.check_integrity`'s ``{relative path: sha256}``.
 272        dest: A private directory; the copies keep their relative paths.
 273
 274    Raises:
 275        ReproduceLockError: If a copy's bytes differ from what the integrity check hashed.
 276    """
 277    for rel, sha in verified.items():
 278        data = (base_dir / rel).read_bytes()
 279        actual = hashlib.sha256(data).hexdigest()
 280        if actual != sha:
 281            raise ReproduceLockError(f"copy of {rel}: sha256 {actual} != verified {sha}; it changed after the check")
 282        target = dest / rel
 283        target.parent.mkdir(parents=True, exist_ok=True)
 284        target.write_bytes(data)

 293def declared_packages(env: EnvSpec, locks: Iterable[str], wheels: Iterable[Path]) -> dict[str, str]:
 294    """Return ``{name: version}`` that a venv built from these locks and wheels must hold.
 295
 296    Args:
 297        env: The step's env; its Python version decides the markers.
 298        locks: Verified lock texts, in install order; entries whose marker is false are skipped.
 299        wheels: The stage 3 wheel files.
 300
 301    Returns:
 302        Normalised names to versions, ``+cuXXX`` dropped, as `locks.parse_freeze` reports them.
 303
 304    Raises:
 305        ReproduceLockError: If two applicable entries pin one name to different versions.
 306    """
 307    markers = _marker_environment(env)
 308    out: dict[str, str] = {}
 309
 310    def add(name: str, version: str) -> None:
 311        if out.setdefault(name, version) != version:
 312            raise ReproduceLockError(f"{name} is pinned to {out[name]} and {version}")
 313
 314    for text in locks:
 315        for entry in lock_entries(text):
 316            if not entry.marker or Marker(entry.marker).evaluate(markers):
 317                add(entry.name, local_free(entry_version(entry)))
 318    for wheel in wheels:
 319        parts = wheel.name.split("-")
 320        add(normalize_name(parts[0]), local_free(parts[1]))
 321    return out

 330def _wheels_location(env: EnvSpec, base_dir: Path, wheels_lock: Path | None) -> tuple[Path | None, str | None]:
 331    if not env.sdist_allow:
 332        return None, None
 333    if env.wheels is not None:
 334        if wheels_lock is not None and wheels_lock != base_dir / env.wheels.lock:
 335            raise ValueError("wheels_lock is given and env.wheels names another file")

 346class _Wheels:
 347    """Stage 3 inputs: the recorded wheel sha256s, and the wheels reused or built, copied and checked on first use."""
 348
 349    def __init__(
 350        self,
 351        env: EnvSpec,
 352        base_dir: Path,
 353        wheelhouse: Path,
 354        lock: Path | None,
 355        expected: str | None,
 356        rebuild: bool,
 357        dest: Path,
 358        modules_init: Path | None = None,
 359    ) -> None:
 360        self.env, self.base_dir, self.wheelhouse, self.lock = env, base_dir, wheelhouse, lock
 361        self.lock_sha256, self.rebuild, self.dest = expected, rebuild, dest
 362        self.modules_init = modules_init
 363        self.built: list[str] = []
 364        self.shas: dict[str, str] = {}
 365        self._copies: list[Path] | None = None
 366
 367    def recorded(self) -> dict[str, str] | None:
 368        """``{sdist name: wheel sha256}`` from the verified ``wheels.lock`` lines; ``None`` if a build is due."""
 369        if self.rebuild:
 370            return None
 371        if self._copies is not None:
 372            return dict(self.shas)
 373        out = {}
 374        for sdist in self.env.sdist_allow:
 375            assert self.lock is not None
 376            found = reuse_wheel(
 377                self.lock,
 378                sdist,
 379                self.wheelhouse,
 380                self.env.torch,
 381                python=self.env.python_exact,
 382                expected_sha256=self.lock_sha256,
 383            )
 384            if found is None:
 385                return None
 386            out[sdist.name] = found[1]
 387        return out
 388
 389    def copies(self) -> list[Path]:
 390        if self._copies is None:
 391            self._copies = []
 392            for sdist in self.env.sdist_allow:
 393                assert self.lock is not None
 394                result = ensure_wheel(
 395                    sdist,
 396                    self.base_dir,
 397                    self.wheelhouse,
 398                    self.lock,
 399                    self.env.torch,
 400                    python=self.env.python_exact,
 401                    rebuild=self.rebuild,
 402                    expected_sha256=self.lock_sha256,
 403                    modules_init=self.modules_init,
 404                )
 405                self.lock_sha256 = result.wheels_lock_sha256
 406                if result.built:
 407                    self.built.append(sdist.name)
 408                self.shas[sdist.name] = result.wheel_sha256
 409                dest = self.dest / result.wheel_sha256
 410                self._copies.append(stage_wheel(result.wheel, result.wheel_sha256, dest))
 411        return self._copies

 442def confined_r_lib(template: str, cache: Path) -> Path:
 443    """The R library path of a ``{cache}/r/<name>`` template, refused unless it really lies in ``<cache>/r``.
 444
 445    Raises:
 446        ValueError: ``E_SPEC_BAD_R_LIB`` for another form, or when the real path (symlinks resolved) is not
 447            strictly under ``realpath(cache)/r``; checked before any removal, write or lock.
 448    """
 449    if not R_LIB_TEMPLATE.match(template):
 450        raise ValueError("E_SPEC_BAD_R_LIB: r_lib must be {cache}/r/<name>")
 451    r_lib = Path(render(template, {"cache": cache}))
 452    base = os.path.join(os.path.realpath(cache), "r")
 453    real = os.path.realpath(r_lib)
 454    if os.path.dirname(real) != base or real == base:
 455        raise ValueError("E_SPEC_BAD_R_LIB: r_lib resolves outside <cache>/r")
 456    return r_lib

 462def _install_staged_kernel(staged: Path, target: Path) -> None:
 463    """Copy a staged kernel spec dir (regular files only) into the venv, replacing the old one."""
 464    if not staged.is_dir() or staged.is_symlink():
 465        raise ReproduceLockError("IRkernel installspec wrote no kernel spec")
 466    files = sorted(p for p in staged.rglob("*"))
 467    if any(p.is_symlink() or not (p.is_file() or p.is_dir()) for p in files):
 468        raise ReproduceLockError("the staged kernel spec holds a link or a special file")
 469    if target.is_symlink() or target.is_file():
 470        target.unlink()
 471    elif target.exists():
 472        shutil.rmtree(target)
 473    target.parent.mkdir(parents=True, exist_ok=True)
 474    shutil.copytree(staged, target)

 477def kernels_sha256(venv: Path) -> str:
 478    """A sha256 over the venv's ``share/jupyter/kernels`` tree: each entry's relative path and content (or link)."""
 479    root = venv / KERNELS
 480    entries = []
 481    for top, dirs, files in os.walk(root, followlinks=False):
 482        dirs.sort()
 483        for name in sorted([*files, *(d for d in dirs if os.path.islink(os.path.join(top, d)))]):
 484            path = Path(top) / name
 485            rel = path.relative_to(root).as_posix()
 486            if path.is_symlink():
 487                entries.append([rel, "link", os.readlink(path)])
 488            else:
 489                entries.append([rel, "file", hashlib.sha256(path.read_bytes()).hexdigest()])
 490    return hashlib.sha256(json.dumps(sorted(entries)).encode()).hexdigest()

 526def load_venv(path: Path, env: EnvSpec, overlay: LockRef | None = None) -> VenvResult | None:
 527    """The prefetched venv at ``path`` as its marker and ``installed.json`` describe it; a run never builds one.
 528
 529    Args:
 530        path: The venv (`venv_dir` or `derived_venv_dir`).
 531        env: The step's env.
 532        overlay: The overlay lock of a derived venv.
 533
 534    Returns:
 535        A `VenvResult` whose key and overlay sha256 are the marker's and whose packages are
 536        ``installed.json``'s, with ``checked`` from `venv_checked`; None when the marker is missing or
 537        malformed or ``installed.json`` no longer matches it.
 538    """
 539    marker = _read_marker(path)
 540    installed = None if marker is None else _installed_ok(path, marker)
 541    if marker is None or not isinstance(installed, dict) or not isinstance(installed.get("packages"), dict):
 542        return None
 543    key, overlay_sha = marker.get("env_key"), marker.get("overlay_sha256")
 544    if not isinstance(key, str) or not (overlay_sha is None or isinstance(overlay_sha, str)):
 545        return None
 546    return VenvResult(path, key, overlay_sha, True, dict(installed["packages"]), venv_checked(path, env, overlay))

 549def venv_checked(path: Path, env: EnvSpec, overlay: LockRef | None = None) -> bool:
 550    """Whether a venv is complete for ``env``: installed for its key and overlay, and both checks passed.
 551
 552    A run (B12) must refuse a venv for which this is false. `prefetch_env` marks the checks only when
 553    given a profile.
 554
 555    Args:
 556        path: The venv.
 557        env: The step's env.
 558        overlay: The overlay lock of a derived venv.
 559
 560    Returns:
 561        True when the marker names ``env_key(env)`` and the overlay sha256, ``installed.json`` matches the
 562        marker, and ``pip_check_ok`` and ``smoke_ok`` were recorded for the current `checks_digest`.
 563    """
 564    marker = _read_marker(path)
 565    if marker is None or _installed_ok(path, marker) is None:
 566        return False
 567    checks = marker.get("checks") or {}
 568    return (
 569        marker.get("env_key") == env_key(env)
 570        and marker.get("overlay_sha256") == (None if overlay is None else overlay.lock_sha256)
 571        and checks.get("digest") == checks_digest(env)
 572        and checks.get("pip_check_ok") is True
 573        and checks.get("smoke_ok") is True
 574    )

 577def _build_or_reuse(
 578    uv: str,
 579    env: EnvSpec,
 580    path: Path,
 581    inputs: Path,
 582    wheels: _Wheels,
 583    overlay: LockRef | None,
 584    run_env: dict[str, str],
 585) -> VenvResult:
 586    key = env_key(env)
 587    overlay_sha = None if overlay is None else overlay.lock_sha256
 588    with _flock(path):
 589        marker = _read_marker(path)
 590        if marker is not None and (marker.get("env_key"), marker.get("overlay_sha256")) == (key, overlay_sha):
 591            installed = _installed_ok(path, marker)
 592            if installed is not None and marker.get("wheels") == wheels.recorded():
 593                return VenvResult(path, key, overlay_sha, True, installed["packages"], venv_checked(path, env, overlay))
 594        if path.is_symlink() or path.is_file():
 595            path.unlink()
 596        elif path.exists():
 597            shutil.rmtree(path)
 598        _run_ok([uv, "venv", "--no-config", "--python", env.python_exact, str(path)], run_env)
 599        python = path / "bin" / "python"
 600        texts = []
 601        if env.torch is not None:
 602            torch_lock = inputs / env.torch.lock
 603            text = torch_lock.read_text()
 604            _run_ok(install_argv(uv, python, torch_lock, torch_index_url(env.torch, text), True), run_env)
 605            texts.append(text)
 606        body = inputs / env.body.lock
 607        _run_ok(install_argv(uv, python, body, env.body.index_url, True), run_env)
 608        texts.append(body.read_text())
 609        copies = wheels.copies()
 610        for wheel in copies:
 611            _run_ok([uv, "pip", "install", "--no-config", "--python", str(python), "--no-deps", str(wheel)], run_env)
 612        if overlay is not None:
 613            overlay_lock = inputs / overlay.lock
 614            _run_ok(install_argv(uv, python, overlay_lock, env.body.index_url, True), run_env)
 615            texts.append(overlay_lock.read_text())
 616        freeze = pip_freeze(path, uv)
 617        packages = parse_freeze(freeze)
 618        problems = _diff(packages, declared_packages(env, texts, copies))
 619        if problems:
 620            raise ReproduceLockError(f"{path.name}: the installed packages differ from the locks: {problems}")
 621        lines = sorted(line.strip() for line in freeze.splitlines() if line.strip())
 622        installed = {
 623            "env_key": key,
 624            "overlay_sha256": overlay_sha,
 625            "python_exact": env.python_exact,
 626            "wheels": dict(wheels.shas),
 627            "freeze": lines,
 628            "packages": packages,
 629        }
 630        installed_sha = _write_json(path / INSTALLED, installed)
 631        _write_json(
 632            path / MARKER,
 633            {
 634                "env_key": key,
 635                "overlay_sha256": overlay_sha,
 636                "wheels": dict(wheels.shas),
 637                "installed_sha256": installed_sha,
 638                "checks": {"digest": checks_digest(env), "pip_check_ok": False, "smoke_ok": False},
 639            },
 640        )
 641        return VenvResult(path, key, overlay_sha, False, packages, False)

 644def _check_venv(venv: VenvResult, env: EnvSpec, profile: Profile, overlay: LockRef | None) -> VenvResult:
 645    """Run `check_pip` and `smoke` on a venv unless its marker already records both for the current digest."""
 646    with _flock(venv.path):
 647        if venv_checked(venv.path, env, overlay):
 648            return venv._replace(checked=True)
 649        marker = _read_marker(venv.path)
 650        if marker is None or marker.get("env_key") != venv.env_key:
 651            raise ReproduceLockError(f"{venv.path.name} changed while it was being checked")
 652        check_pip(venv.path, env)
 653        failures = smoke(venv.path, env.smoke_imports, profile)
 654        if failures:
 655            raise ReproduceLockError(f"smoke imports failed in {venv.path.name}: {failures}")
 656        marker["checks"] = {"digest": checks_digest(env), "pip_check_ok": True, "smoke_ok": True}
 657        _write_json(venv.path / MARKER, marker)
 658    return venv._replace(checked=True)

 692def _prefetch_env(
 693    env: EnvSpec,
 694    base_dir: Path,
 695    cache: Path,
 696    *,
 697    analysis: str,
 698    wheelhouse: Path,
 699    uv_lock: Path | None = None,
 700    profile: Profile | None = None,
 701    wheels_lock: Path | None = None,
 702    rebuild: bool = False,
 703) -> PrefetchResult:
 704    """Build (or reuse) an env's base venv and its derived venvs from verified copies of its locks.
 705
 706    A venv is reused when its marker names its key and overlay, its ``installed.json`` matches the
 707    marker's sha256, and its recorded wheel sha256s equal the verified ``wheels.lock`` lines. Anything
 708    else, or ``rebuild``, rebuilds it.
 709
 710    Args:
 711        env: The step's env.
 712        base_dir: The manifest repository; every path in ``env`` is relative to it.
 713        cache: The reproduce cache; venvs go under ``<cache>/venvs``.
 714        analysis: The manifest name, used in venv names.
 715        wheelhouse: Where stage 3 wheels are stored.
 716        uv_lock: The checkout's ``uv.lock``, for a uv-export body with a torch lock.
 717        profile: When given, each venv not yet checked is checked: ``uv pip check`` must equal
 718            ``pip_check_expected`` (`check_pip`) and ``smoke_imports`` must import in the sandbox (`smoke`);
 719            the marker then records both. Without it no venv is marked checked (`venv_checked` stays false).
 720        wheels_lock: Where to record wheels when ``env.wheels`` is unset (the first prefetch); the file must
 721            not exist yet.
 722        rebuild: Build every sdist again (`build.ensure_wheel`'s ``rebuild``) and rebuild every venv.
 723
 724    Returns:
 725        A `PrefetchResult`.
 726
 727    Raises:
 728        ReproduceLockError: If the integrity check, a copy check, an install, the freeze comparison or a
 729            check fails, or ``wheels_lock`` exists while ``env.wheels`` is unset.
 730        ValueError: If an env with sdists has nowhere to record wheels, or ``wheels_lock`` contradicts ``env.wheels``.
 731    """
 732    lock_path, expected = _wheels_location(env, base_dir, wheels_lock)
 733    verified = check_integrity(env, base_dir, uv_lock)
 734    uv = uv_executable()
 735    with tempfile.TemporaryDirectory(prefix="reproduce-env-") as tmp:
 736        work = Path(tmp)
 737        inputs = work / "inputs"
 738        copy_verified(base_dir, verified, inputs)
 739        run_env = base_environment(uv, work)
 740        init = None if profile is None else profile.modules_init
 741        wheels = _Wheels(env, base_dir, wheelhouse, lock_path, expected, rebuild, work / "wheels", init)
 742        base = _build_or_reuse(uv, env, venv_dir(cache, analysis, env), inputs, wheels, None, run_env)
 743        derived = {}
 744        for name in OVERLAYS:
 745            ref: LockRef | None = getattr(env, name)
 746            if ref is not None:
 747                path = derived_venv_dir(cache, analysis, env, ref)
 748                derived[name] = _build_or_reuse(uv, env, path, inputs, wheels, ref, run_env)
 749    if profile is not None:
 750        base = _check_venv(base, env, profile, None)
 751        derived = {name: _check_venv(v, env, profile, getattr(env, name)) for name, v in derived.items()}
 752    if "notebook_tools" in derived:
 753        record_kernels(derived["notebook_tools"].path)
 754    lock_sha = None
 755    if lock_path is not None and lock_path.is_file():
 756        lock_sha = hashlib.sha256(lock_path.read_bytes()).hexdigest()
 757    record = lock_sha is not None and lock_sha != expected
 758    return PrefetchResult(base, derived, lock_sha, record, tuple(wheels.built))

 761def parse_pip_check(text: str) -> list[Violation]:
 762    """Parse ``uv pip check`` output into sorted, normalised violations.
 763
 764    Args:
 765        text: The command's output; lines other than ``The package `…` …`` are ignored.
 766
 767    Returns:
 768        Violations sorted by package, kind and detail.
 769    """
 770    found = []
 771    for line in text.splitlines():
 772        match = _PIP_CHECK_LINE.match(line.strip())
 773        if match:
 774            found.append(_violation(match.group(1), None, match.group(2)))
 775    return sorted(found)

 778def _violation(package: str, kind: str | None, detail: str) -> Violation:
 779    detail = " ".join(detail.replace("`", "").split())
 780    if kind is None:
 781        kind = "requirement" if detail.startswith("requires ") else "platform" if "platform" in detail else "other"
 782    return Violation(normalize_name(package), kind, detail)

 785def compare_pip_check(
 786    found: Iterable[Violation], expected: Iterable[PipCheckExpected]
 787) -> tuple[list[Violation], list[Violation]]:
 788    """Compare violations with the declared deviations.
 789
 790    Args:
 791        found: `pip_check`'s violations.
 792        expected: The env's ``pip_check_expected``; package and detail are normalised as `parse_pip_check` does.
 793
 794    Returns:
 795        ``(undeclared, declared but absent)``; both empty means the venv passes.
 796    """
 797    found = list(found)
 798    wanted = [_violation(e.package, e.kind, e.detail) for e in expected]
 799    return [v for v in found if v not in wanted], [w for w in wanted if w not in found]

 802def _uv_in_sandbox(uv: str, args: Sequence[str], venv: Path) -> subprocess.CompletedProcess[str]:
 803    """Run ``uv <args> --python <venv>/bin/python`` inside the sandbox: offline, the venv read-only.
 804
 805    uv queries the venv's interpreter, which runs its ``site`` and any ``.pth`` code; inside the sandbox that
 806    code cannot write or reach the network. uv gets a private cache under a temporary dir.
 807    """
 808    with tempfile.TemporaryDirectory(prefix="reproduce-uv-") as tmp:
 809        work = Path(tmp).resolve()

 811        cache_dir = work / "uv-cache"
 812        cache_dir.mkdir()

 815        result = _run(sandbox.tool_argv(argv, [work], [venv.absolute()]), run_env)
 816    refusal = sandbox.sweep_refusal(result.stderr or "")
 817    if refusal is not None:
 818        raise ReproduceLockError(f"E_SANDBOX_UNAVAILABLE: {refusal}")
 819    return result

 836def installed_from_metadata(venv: Path) -> dict[str, str]:
 837    """The installed set read from the venv's ``*.dist-info/METADATA`` headers; nothing is executed.
 838
 839    Returns:
 840        Normalised names to versions, ``+cuXXX`` dropped, as `locks.parse_freeze` reports a freeze.
 841    """
 842    out: dict[str, str] = {}
 843    for site in sorted((venv / "lib").glob("python*/site-packages")):
 844        for meta in sorted(site.glob("*.dist-info/METADATA")):
 845            name = version = None
 846            try:
 847                lines = meta.read_text(encoding="utf-8", errors="replace").splitlines()
 848            except OSError:
 849                continue
 850            for line in lines:
 851                if not line.strip():
 852                    break
 853                key, _, value = line.partition(":")
 854                if key == "Name":
 855                    name = value.strip()
 856                elif key == "Version":
 857                    version = value.strip()
 858            if name and version:
 859                out[normalize_name(name)] = _CUDA_LOCAL.sub("", version)
 860    return out

 903def _smoke_env(venv: Path, tmp: Path, profile: Profile | None) -> dict[str, str]:
 904    user = dict(profile.env) if profile is not None else {}
 905    reserved = sorted(k for k in user if k in sandbox.RESERVED or k.startswith(sandbox.RESERVED_PREFIXES))
 906    if reserved:
 907        raise ValueError(f"profile env may not set driver-owned variables: {reserved}")

 922def smoke(
 923    venv: Path,
 924    modules: Sequence[str],
 925    profile: Profile | None = None,
 926    *,
 927    step: StepSpec | None = None,
 928    runner: Runner | None = None,
 929) -> list[str]:
 930    """Import each module with the venv's interpreter inside the sandbox, offline, one process per module.
 931
 932    Args:
 933        venv: The venv; mounted read-only.
 934        modules: Dotted module names.
 935        profile: Its ``env`` map is passed to the import; with ``step``, the step's whole env
 936            (`sandbox.build_env`) is used instead.
 937        step: The step whose env to use, with ``profile``.
 938        runner: Runs ``(argv, env, cwd)``; defaults to ``subprocess.run`` with captured output and a
 939            :data:`SMOKE_TIMEOUT` second timeout.
 940
 941    Returns:
 942        ``"<module>: <output tail>"`` for each import that failed; empty when all succeeded. Each import
 943        runs with an empty private working directory, so nothing in the caller's directory is importable.
 944
 945    Raises:
 946        ValueError: If a module name is not a dotted identifier.
 947        ReproduceLockError: ``E_SMOKE_TIMEOUT`` if an import outlives the timeout.
 948    """
 949    bad = [m for m in modules if not _MODULE_NAME.match(m)]
 950    if bad:
 951        raise ValueError(f"not module names: {bad}")
 952    run = runner or _smoke_runner
 953    venv = venv.absolute()
 954    failures = []
 955    with tempfile.TemporaryDirectory(prefix="reproduce-smoke-") as name:
 956        tmp = Path(name).resolve()
 957        cwd = tmp / "cwd"
 958        cwd.mkdir()
 959        if step is not None and profile is not None:
 960            paths = {"out": tmp / "out", "tmp": tmp, "checkout": tmp / "checkout", "venv": venv, "cache": tmp / "cache"}
 961            env = sandbox.build_env(step, profile, paths)[0]
 962        else:
 963            env = _smoke_env(venv, tmp, profile)
 964        for module in modules:
 965            argv = sandbox.tool_argv([str(venv / "bin" / "python"), "-c", f"import {module}"], [tmp], [venv])
 966            try:
 967                result = run(argv, env, cwd)
 968            except subprocess.TimeoutExpired as error:
 969                raise ReproduceLockError(
 970                    f"E_SMOKE_TIMEOUT: import {module} in {venv.name} ran past {error.timeout}s"
 971                ) from error
 972            if result.returncode != 0:
 973                failures.append(f"{module}: {(result.stdout + result.stderr).strip()[-_TAIL:]}")
 974    return failures

1227    kind: str = "r",

1229    runner: Runner | None = None,
1230) -> RResult:
1231    """Install an env's R packages into its private library under the profile's R module.
1232
1233    The download runs outside the sandbox, with network (`r_download_script` fills a local repository); the
1234    install (``install.packages`` from that repository, then the session record) runs inside the sandbox,
1235    offline, with only the library, the temporary work dir and, for ``ir_notebook``, the venv's kernel dir
1236    writable. ``profile.r.build_modules`` and then ``profile.r.module`` are
1237    loaded with ``bash --noprofile --norc -c '. <profile.modules_init> && module load …'``, so no dotfile is
1238    read, and with an allowlisted environment. The packages come from `r_snapshot_url` of
1239    ``env.r_snapshot``; ``R_LIBS`` and ``R_LIBS_USER`` are ``<r_lib>`` and ``R_LIBS_SITE`` is empty, so
1240    neither the module's site library nor a user library under ``HOME`` is seen. A library whose
1241    ``SESSION.json`` records the same key (modules, R version, snapshot, declared packages) is reused;
1242    otherwise ``SESSION.json`` is removed and the library rebuilt from empty.
1243

1245        env: The step's env; ``r_packages``, ``r_snapshot`` and ``r_lib`` are required.
1246        cache: The reproduce cache; fills ``{cache}`` in ``r_lib``.
1247        profile: Its ``r`` entry gives the modules and the R version to expect.
1248        kind: ``r`` or ``ir_notebook``; the latter installs the ``ir`` kernel spec into ``venv``.
1249        venv: The derived (notebook tools) venv, for ``ir_notebook``; its ``bin`` leads ``PATH``.
1250        runner: Runs ``(argv, env, cwd)``; defaults to ``subprocess.run`` with captured output and a
1251            :data:`R_TIMEOUT` second timeout.
1252
1253    Returns:
1254        An `RResult`.
1255
1256    Raises:
1257        ValueError: If the profile has no R module, the env lacks its R fields, or an ``ir_notebook``
1258            env has no venv or does not declare ``IRkernel``.
1259        ReproduceLockError: If a command fails, R is not ``profile.r.version``, the library is not first
1260            on ``.libPaths()``, the kernel spec is missing, or an installed version differs from the declared one.
1261    """

1263        raise ValueError("an R env needs profile.r")
1264    if not env.r_packages or env.r_snapshot is None or env.r_lib is None:
1265        raise ValueError("an R env needs r_packages, r_snapshot and r_lib")

1267        if "IRkernel" not in {p.name for p in env.r_packages}:
1268            raise ValueError("an ir_notebook env must declare IRkernel in r_packages")
1269        if venv is None:
1270            raise ValueError("an ir_notebook env needs the derived venv for its kernel spec")

1273    if not _ENV_MODULE.match(module):

1277    repo = r_snapshot_url(env.r_snapshot)
1278    declared = {p.name: p.version for p in env.r_packages}
1279    key = _r_key(module, build_modules, r_version, repo, declared)

1281    kernel_ok = venv is None or kind != "ir_notebook" or _kernel(venv).is_file()
1282    with _flock(r_lib):

1284            if kind == "ir_notebook" and venv is not None:
1285                record_kernels(venv)
1286            return RResult(
1287                r_lib,
1288                session_path,
1289                hashlib.sha256(session_path.read_bytes()).hexdigest(),
1290                module_path,
1291                hashlib.sha256(module_path.read_bytes()).hexdigest(),
1292                True,
1293            )
1294        session_path.unlink(missing_ok=True)
