senselab_core.runtime.store

A content-addressed result store keyed by logical key, with a recorded execution context (ADR-002, ADR-003).

Layout under root:

  • store@6/<d[:2]>/<d>/<f>/, where d is LogicalKey.digest() and f is ExecutionContext.fingerprint(), holding:
    • result.json: JCS JSON with format: "result@2.0", the key, its digest, the context fingerprint, the encoded outputs and their output identity;
    • context.json: JCS JSON with format: "execution-context@4.0" and the context's fields;
    • <sha256>.npy: each array output in canonical .npy, named by the sha256 of its bytes.
  • equivalence-evidence@4/<d>.json: one verify-sampling comparison (EquivalenceEvidence), JSON named by d, its canonical digest.
  • tmp/<uuid>/: a writer's staging directory, committed by renaming it onto the entry.
  • quarantine/<uuid>: entries that failed verification, and objects of the wrong kind found at a path the store owns, moved aside by rename.

An entry is bound to its address and its context: a reader recomputes the key digest from the stored key and the fingerprint from the stored context, and requires both, and the digest and fingerprint recorded in result.json, to equal the path it read. A committed entry is read-only (committed_modes); directories that hold entries are shared_dir_mode, whatever the umask. World bits are set only when the StorePolicy allows them. An existing root is left as it is.

Every directory below root is reached through StorageDir, so no symlink below the root is followed. A symlink or a non-directory where a directory of the store belongs is moved into the quarantine and the directory is made again; one that cannot be moved raises WrongKindError, naming it and its owner.

Only a completed read that fails verification moves an entry. A member's format is judged by formats.check: a retired context raises StoreFormatRetired, another version's format (a later major, or a later minor's context fields) StoreFormatUnknown, and neither moves the entry; a malformed member, or a retired result, is corruption. An OSError while reading or writing is raised as StoreUnavailable (StorageFull for ENOSPC and EDQUOT) and changes nothing.

Outputs are a mapping of JSON values (what canonical_scalar accepts, in exact list, tuple and str-keyed dict containers) and plain numpy arrays, nested to any depth. In the encoded form each array is replaced by {"$array": <sha256 of its canonical .npy>}, so $array is a reserved key. The output identity is "output:" + identity_digest("output@3", encoded form).

 184def _encode(value: object, arrays: dict[str, bytes], walk: Walk) -> object:
 185    if type(value) is numpy.ndarray:
 186        a = value
 187        return walk.enter(a, lambda: _array(a, arrays))
 188    if type(value) is dict:
 189        d = cast("dict[str, object]", value)
 190        if ARRAY_TAG in d:
 191            raise ValueError(f"{ARRAY_TAG!r} is a reserved key in stored outputs")
 192        return walk.enter(d, lambda: {k: _encode(v, arrays, walk) for k, v in d.items()})
 193    if type(value) is list or type(value) is tuple:
 194        items = cast("list[object] | tuple[object, ...]", value)
 195        return walk.enter(items, lambda: [_encode(v, arrays, walk) for v in items])
 196    return canonical_scalar(value)

 237    """Open the entry directory `entry` unfollowed; a gone entry, or anything but a directory, is corrupt."""
 238    try:
 239        return StorageDir.open_unfollowed(entry)

 246def _read_member(entry: Path, name: str) -> bytes:
 247    """Return the bytes of the regular file `entry/name`, read through the entry's descriptor.
 248
 249    The member is neither followed nor waited on; anything but a regular file there, or a gone entry,
 250    makes the entry corrupt.
 251    """
 252    with _open_entry(entry) as directory:
 253        try:
 254            data = directory.read_regular(name)
 255        except WrongKindError as err:
 256            raise CorruptEntryError(f"corrupt store entry {entry}: {name} is not a regular file") from err
 257    if data is None:
 258        raise CorruptEntryError(f"corrupt store entry {entry}: {name} is missing")
 259    return data

 262def _present(entry: Path, name: str, size: int | None) -> None:
 263    """Require `entry/name` to be a regular file, of `size` bytes when `size` is given, without reading it."""
 264    with _open_entry(entry) as directory:
 265        st = directory.lstat(name)
 266    if st is None or not stat.S_ISREG(st.st_mode):
 267        raise CorruptEntryError(f"corrupt store entry {entry}: {name} is missing or not a regular file")
 268    if size is not None and st.st_size != size:
 269        raise CorruptEntryError(f"corrupt store entry {entry}: {name} holds {st.st_size} bytes, not {size}")

 272def _decode(value: object, entry: Path, sizes: Mapping[str, int] | None = None) -> object:
 273    """Return `value` with each array reference verified against its file and read as that array.
 274
 275    With `sizes` (the byte counts of arrays the caller holds, by sha256), each reference is instead kept
 276    as it is and only its recorded file checked, by `_present`: a regular file, of the held size if any.
 277    """
 278    if isinstance(value, dict):
 279        if set(value) == {ARRAY_TAG}:
 280            sha = value[ARRAY_TAG]
 281            if not isinstance(sha, str) or not SHA256_HEX.fullmatch(sha):
 282                raise CorruptEntryError(f"corrupt store entry {entry}: array reference {sha!r} is not a sha256")
 283            if sizes is not None:
 284                _present(entry, f"{sha}.npy", sizes.get(sha))
 285                return value
 286            data = _read_member(entry, f"{sha}.npy")
 287            if _raw_digest.bytes_digest("npy@1", data) != sha:
 288                raise CorruptEntryError(f"corrupt store entry {entry}: {sha}.npy does not hash to its name")
 289            try:
 290                return numpy.load(io.BytesIO(data), allow_pickle=False)
 291            except OSError as err:
 292                raise CorruptEntryError(f"corrupt store entry {entry}: {sha}.npy is not an array: {err}") from err
 293        return {k: _decode(v, entry, sizes) for k, v in value.items()}
 294    if isinstance(value, list):
 295        return [_decode(v, entry, sizes) for v in value]
 296    return value

 330def _read_object(entry: Path, name: str, fmt: str) -> tuple[dict[str, Any], str]:
 331    """Return the member's record and its format."""
 332    path = entry / name
 333    record = jcs_loads(_read_member(entry, name))
 334    if not isinstance(record, dict):
 335        raise CorruptEntryError(f"corrupt store entry: {path} is not a JSON object")
 336    found = record.pop("format", None)
 337    verdict = check(fmt, found, RETIRED_STORE_FORMATS)
 338    if verdict is FormatVerdict.RETIRED:
 339        raise StoreFormatRetired(path, found)
 340    if verdict is FormatVerdict.UNKNOWN:
 341        raise StoreFormatUnknown(path, found, f"this version reads {fmt} and its minors")
 342    if verdict is FormatVerdict.MALFORMED:
 343        raise CorruptEntryError(f"corrupt store entry: {path} is not {fmt}")
 344    return record, found

 347def _guarded(entry: Path, read: Callable[[], T]) -> T:
 348    """Run `read`; a failed verification is `CorruptEntryError`, an `OSError` is a storage fault."""
 349    try:
 350        return read()
 351    except (CorruptEntryError, StoreFormatRetired, StoreFormatUnknown):
 352        raise
 353    except FieldsOfLaterMinor as err:
 354        raise StoreFormatUnknown(entry, err.read.tag, str(err)) from err
 355    except OSError as err:
 356        raise storage_fault(err, entry) from err
 357    except (ValueError, KeyError, TypeError, ValidationError) as err:
 358        raise CorruptEntryError(f"corrupt store entry {entry}: {type(err).__name__}: {err}") from err

 367def _stored_address(
 368    entry: Path, context: ExecutionContext | None = None
 369) -> tuple[str, str, dict[str, Any], ExecutionContext]:
 370    """Return `(key digest, context fingerprint, result record, context)` as the entry's files state them.
 371
 372    The key in `result.json` must digest to its recorded `key_digest`, and the context in `context.json`
 373    (or `context`, when the caller has already read it from this entry) must fingerprint to the
 374    `context_fingerprint` recorded in `result.json`; a retired `result.json` beside a current context is corrupt.
 375    """
 376    context = _stored_context(entry) if context is None else context
 377    try:
 378        record, found = _read_object(entry, "result.json", RESULT_FORMAT)
 379    except StoreFormatRetired as err:
 380        raise CorruptEntryError(f"corrupt store entry {entry}: a retired result beside a current context") from err
 381    digest = validated(LogicalKey, record["key"], RESULT_FORMAT, found).digest()
 382    if record["key_digest"] != digest:
 383        raise MisfiledEntryError(f"stored key digest {record['key_digest']!r} is not the digest of the stored key")
 384    fingerprint = context.fingerprint()
 385    if record["context_fingerprint"] != fingerprint:
 386        raise MisfiledEntryError(
 387            f"misfiled store entry {entry}: result.json was written under context "
 388            f"{str(record['context_fingerprint'])[:12]}..., context.json holds {fingerprint[:12]}..."
 389        )
 390    return digest, fingerprint, record, context

 401def _read_context(entry: Path, fingerprint: str) -> ExecutionContext:
 402    """Return the context recorded in `entry`, whose fingerprint must be `fingerprint`.
 403
 404    Raises:
 405        CorruptEntryError: the entry is gone, corrupt, or (`MisfiledEntryError`) holds another context.
 406        StoreUnavailable: the entry could not be read.
 407    """
 408
 409    def read() -> ExecutionContext:
 410        context = _stored_context(entry)
 411        if context.fingerprint() != fingerprint:
 412            raise MisfiledEntryError(f"misfiled store entry {entry}: its context is not {fingerprint[:12]}...")
 413        return context
 414
 415    return _guarded(entry, read)

 418def _read_result(
 419    entry: Path,
 420    *,
 421    digest: str,
 422    fingerprint: str,
 423    context: ExecutionContext | None = None,
 424    sizes: Mapping[str, int] | None = None,
 425) -> tuple[str, dict[str, object], ExecutionContext]:
 426    """Return the output identity, decoded outputs and context of the entry at `entry`.
 427
 428    The entry must be bound (`_stored_address`) to key digest `digest` and context fingerprint
 429    `fingerprint`, its outputs must hash to their output identity, and every array file must hash to its name.
 430    `context` is the entry's context when the caller has already read it. With `sizes`, array references are
 431    checked by `_present` and returned as references, not read (`_decode`).
 432
 433    Raises:
 434        CorruptEntryError: the entry is gone or fails verification; `MisfiledEntryError` when it
 435            belongs to another address or context.
 436        StoreUnavailable: the entry could not be read.
 437    """
 438
 439    def read() -> tuple[str, dict[str, object], ExecutionContext]:
 440        stored_digest, stored_fingerprint, record, stored = _stored_address(entry, context)
 441        _bound(entry, digest, fingerprint, stored_digest, stored_fingerprint)
 442        tree, identity = record["outputs"], record["output_identity"]
 443        if not isinstance(identity, str) or _tree_identity(tree) != identity:
 444            raise CorruptEntryError(f"corrupt store entry {entry}: outputs do not hash to their output identity")
 445        outputs = _decode(tree, entry, sizes)
 446        if not isinstance(outputs, dict):
 447            raise CorruptEntryError(f"corrupt store entry {entry}: outputs are not an object")
 448        return identity, outputs, stored
 449
 450    return _guarded(entry, read)

 483def _committed_identity(entry: Path, *, digest: str, fingerprint: str, arrays: Mapping[str, bytes]) -> str | None:
 484    """Return the output identity of the entry at `entry`, None if nothing is there.
 485
 486    Its JSON members are verified and bound to the address; each array it records is checked by the digest
 487    recorded as its name, not read: a regular file, of the size of the caller's array of that digest if any.
 488
 489    Raises:
 490        CorruptEntryError: something is at `entry` that is not a valid entry for this address.

 495    except FileNotFoundError:
 496        return None
 497    except OSError as err:
 498        raise storage_fault(err, entry) from err

 503def _commit(  # noqa: PLR0913 - what the entry holds, where it is staged and placed, and the policy
 504    key: LogicalKey,
 505    context: ExecutionContext,
 506    parent: StorageDir,
 507    name: str,
 508    staging_root: StorageDir,
 509    payload: tuple[object, dict[str, bytes], str],
 510    policy: StorePolicy,
 511) -> bool:
 512    """Stage an entry, make its files read-only, and rename it onto `parent/name`; return False if another was first.
 513
 514    The entry directory is made read-only after the rename.
 515
 516    Raises:
 517        StoreUnavailable: staging or renaming failed for any reason but an occupied target.
 518    """
 519    tree, arrays, identity = payload
 520    file_mode, dir_mode = committed_modes(policy)
 521    stage = Staging(staging_root, mode=STAGING_DIR_MODE)
 522    try:
 523        with stage as staging:
 524            for sha, data in arrays.items():
 525                staging.write_new(f"{sha}.npy", data, file_mode, grammar=MEMBER_NAME)
 526            staging.write_new(
 527                "context.json",
 528                jcs_dumps(context_record(context)),
 529                file_mode,
 530                grammar=MEMBER_NAME,
 531            )
 532            result = {
 533                "format": RESULT_FORMAT,
 534                "key": key_record(key),
 535                "key_digest": key.digest(),
 536                "context_fingerprint": context.fingerprint(),
 537                "output_identity": identity,
 538                "outputs": tree,
 539            }
 540            staging.write_new("result.json", jcs_dumps(result), file_mode, grammar=MEMBER_NAME)
 541            staging.fsync()
 542            try:
 543                staging_root.rename(stage.name, parent, name, grammar=FINGERPRINT_NAME)
 544            except OSError:
 545                if parent.kind(name) is not None:
 546                    return False
 547                raise
 548        _seal(parent, name, dir_mode)
 549        parent.fsync()
 550        return True
 551    except OSError as err:
 552        raise storage_fault(err, parent.path / name) from err

 564    parent: StorageDir, names: tuple[str, ...], levels: tuple[re.Pattern[str], ...], cutoff: float
 565) -> int:
 566    """Remove what is older than `cutoff` in `parent/<names>` and in each child below it named by `levels`, in turn.
 567
 568    Return how many were removed; a directory that cannot be opened is skipped.
 569    """
 570    removed = 0

 572        directory = _opened(parent, name)

 606class ResultStore:
 607    """Results addressed by logical key, one entry per execution context, safe for concurrent writers.
 608
 609    Each entry is staged in `root/tmp/<uuid>/` and committed by `os.rename`; the first writer to
 610    rename wins and later writers discard their staging and return the committed identity. A
 611    staging directory is never read by `get`. An entry that a completed read finds corrupt or
 612    misfiled is moved into `root/quarantine/<uuid>` (see `_quarantine`) and never served. `collect`,
 613    which `put` runs at most once per `policy.collect_interval_s`, removes quarantined entries and
 614    staging directories older than the policy's ages. An entry found valid but writable is re-sealed.
 615
 616    Provenance: a `put` adds the result entity, `output:<hex>`; a `get` hit adds a `senselab:Reuse` activity that
 617    used it (or, with `record=False`, leaves that to `record_reuse`), carrying the key, the current and stored
 618    contexts, the admitting policy, the agent that computed the result and, under `equivalent`, the equivalence
 619    table's `value_digest`, associated with the current context's agent. The store writes no execution activity.
 620
 621    Splits: a disagreeing `EquivalenceEvidence` takes its two members out of the class holding both
 622    (`equivalence.split`). It is persisted as the evidence record, and every store over the same root applies
 623    the recorded disagreements to its table when it first reads the table.
 624
 625    Args:
 626        root: The store root.
 627        provenance: Where the store adds its records; the store owns a fresh one when None.
 628        policy: Modes and retention ages; `StorePolicy.load_default()` when None.
 629        equivalence: The measured classes `equivalent` reuse admits (none by default; `load_equivalence(path)`).
 630        settings: The profile's `store` section; the packaged profile's when None.
 631    """
 632
 633    def __init__(  # noqa: PLR0913 - the root and provenance, then keyword-only policy, table, settings and clock

 638        policy: StorePolicy | None = None,

 644        from senselab_core.runtime.profiles import ExecutionProfile  # noqa: PLC0415 - profiles import this module
 645
 646        self.root = Path(root)

 674    def add_evidence(self, evidence: EquivalenceEvidence) -> None:
 675        """Record `evidence` under its digest, written atomically, and split this store's table if it disagrees.
 676
 677        Recording it again changes nothing.

 679        Raises:
 680            StoreUnavailable: the store could not be written.

 760    def _quarantine(self, entry: Path, *, digest: str, fingerprint: str) -> None:
 761        """Move `entry` aside, re-verify the moved copy, and put it back if it verifies.
 762
 763        The entry goes to `root/quarantine/<uuid>`. If it cannot be made writable for that move (it
 764        belongs to another user) or the quarantine cannot be created, it is renamed to `<uuid>`
 765        beside itself instead, which needs write permission only on its parent; that name is never
 766        a fingerprint, so `get` ignores it, and its owner must remove it. The re-verification uses
 767        the address the entry was read at (`digest`, `fingerprint`). A copy that verifies, or cannot
 768        be read, is renamed back without replacing anything: if a new entry took the address
 769        meanwhile the copy stays aside. Nothing is done if `entry` is already gone. A warning logs where it
 770        went, the outcome, the verdict and the reason.
 771
 772        Raises:
 773            StoreUnavailable: `entry` cannot be moved at all; the message names its owner and the remedy.
 774            WrongKindError: a directory above `entry` is of the wrong kind.
 775        """
 776        try:
 777            root = self._open_root(create=False)
 778        except FileNotFoundError:
 779            return
 780        except OSError as err:
 781            raise storage_fault(err, self.root) from err
 782        with root:
 783            parent = self._parent(root, entry)
 784            if parent is None:
 785                return
 786            with parent:
 787                self._quarantine_in(root, parent, entry.name, digest=digest, fingerprint=fingerprint)

 789    def _move_aside(self, parent: StorageDir, name: str, target: StorageDir, *, reseal: bool) -> str | None:
 790        """Rename `parent/name` to a fresh uuid name in `target` and return that name; None if it is gone.
 791
 792        Raises:
 793            StoreUnavailable: the rename failed; with `reseal`, the entry is made read-only again first.
 794        """
 795        moved_name = uuid.uuid4().hex
 796        try:
 797            parent.rename(name, target, moved_name, grammar=ASIDE_NAME)
 798        except FileNotFoundError:
 799            return None
 800        except OSError as err:
 801            if reseal:
 802                _seal(parent, name, committed_modes(self.policy)[1])
 803            entry = parent.path / name
 804            raise storage_fault(err, entry, hint=owner_remedy(entry)) from err
 805        return moved_name

 807    def _quarantine_in(self, root: StorageDir, parent: StorageDir, name: str, *, digest: str, fingerprint: str) -> None:
 808        entry = parent.path / name
 809        try:
 810            info = parent.lstat(name)
 811        except OSError as err:
 812            raise storage_fault(err, entry) from err
 813        if info is None:
 814            return
 815        is_dir = stat.S_ISDIR(info.st_mode)
 816        into = self._aside(root, parent, name, is_dir)
 817        target = into if into is not None else parent
 818        try:
 819            moved_name = self._move_aside(parent, name, target, reseal=is_dir and into is not None)
 820            if moved_name is None:
 821                return
 822            moved = target.path / moved_name
 823            try:
 824                target.stamp(moved_name)
 825            except OSError as err:
 826                logger.warning("cannot stamp quarantined entry %s: %s", moved, err)
 827            verdict, reason = self._verdict(moved, is_dir, digest=digest, fingerprint=fingerprint)
 828            outcome = "quarantined" if into is not None else "set aside in place"
 829            if verdict != "corrupt":
 830                outcome = self._restore(target, moved_name, parent, name)
 831            elif into is None:
 832                logger.warning("corrupt store entry set aside at %s; %s", moved, owner_remedy(moved))
 833        finally:
 834            if into is not None:
 835                into.close()
 836        logger.warning("store entry %s %s (%s): %s", entry, outcome, verdict, reason)

 838    def _aside(self, root: StorageDir, parent: StorageDir, name: str, is_dir: bool) -> StorageDir | None:
 839        """Return the quarantine if `name` can be moved there, None to set it aside beside itself."""
 840        quarantine = self._quarantine_dir(root)
 841        if quarantine is None or not is_dir:
 842            return quarantine
 843        try:
 844            with parent.child(name) as entry:
 845                entry.set_mode(STAGING_DIR_MODE)
 846        except (OSError, WrongKindError) as err:
 847            logger.warning("cannot move %s into the quarantine, setting it aside in place: %s", parent.path / name, err)
 848            quarantine.close()
 849            return None
 850        return quarantine

 852    @staticmethod
 853    def _verdict(moved: Path, is_dir: bool, *, digest: str, fingerprint: str) -> tuple[str, str]:
 854        """Return `("corrupt" | "verified" | "unreadable", reason)` for a moved entry."""
 855        if not is_dir:
 856            return "corrupt", "not a directory"
 857        try:
 858            _read_result(moved, digest=digest, fingerprint=fingerprint)
 859        except CorruptEntryError as err:
 860            return "corrupt", str(err)
 861        except StoreUnavailable as err:
 862            return "unreadable", str(err)

 903    def collect(self) -> int:
 904        """Remove quarantined entries and staging directories older than the policy's ages; return how many.
 905
 906        Objects set aside in place (`<uuid>` under the root, `store@6/`, a prefix or a key, beside what they
 907        displaced) count as quarantined. Ages are measured from each object's mtime to the clock's storage time on
 908        `root`. Only uuid-named children are removed, through `remove_owned`; no directory below `root` is reached
 909        through a symlink. A failure to read the clock, list or remove is logged and skips that item.
 910        """
 911        try:
 912            root = self._open_root(create=False)
 913        except OSError as err:
 914            if not isinstance(err, FileNotFoundError):
 915                logger.warning("cannot open store %s; not collecting: %s", self.root, err)
 916            return 0
 917        with root:
 918            try:
 919                now = self._clock.storage_now(root)
 920            except (OSError, WrongKindError) as err:
 921                logger.warning("cannot read the clock of store %s; not collecting: %s", self.root, err)
 922                return 0
 923            aside = now - self.policy.quarantine_retention_s
 924            removed = root.remove_older(aside)
 925            for parts, cutoff in (((QUARANTINE_DIR,), aside), ((STAGING_DIR,), now - self.policy.staging_stale_s)):
 926                directory = _opened(root, *parts)
 927                if directory is not None:
 928                    with directory:
 929                        removed += directory.remove_older(cutoff)
 930            return removed + _collect_below(root, (STORE_DIR,), (_PREFIX, SHA256_HEX), aside)

 932    def put(self, key: LogicalKey, outputs: dict[str, object], context: ExecutionContext) -> OutputIdentity:
 933        """Store `outputs` under `key` and `context`, and return the committed output identity.
 934
 935        Outputs are stored as JCS canonicalises them: `1.0` is stored as `1`, strings are
 936        NFC-normalised and tuples become lists, and the output identity is taken over that form.
 937        If a valid entry for `key` and `context` is already committed, nothing is written and that
 938        entry's identity is returned, which may differ from the identity of `outputs`. Its JSON members
 939        are verified first, and each array it records must be a regular file named by its digest, of the
 940        size of this put's array of that digest if there is one; arrays are not read (a `get` reads and
 941        hashes them). Anything else at the entry's path is quarantined and replaced, as is anything of the
 942        wrong kind at a directory of the store on the way to it.
 943        Either way the result entity is added to provenance.
 944
 945        Raises:
 946            TypeError: on an output that is neither a JSON value nor a numpy array.
 947            ValueError: on a container that contains itself, a reserved `$array` key, a value
 948                `jcs_dumps` refuses, or an array dtype `canonical_npy_bytes` refuses.
 949            StoreUnavailable: the store could not be read or written (`StorageFull` when out of space).
 950            WrongKindError: an object of the wrong kind in the store could not be moved aside.
 951            RuntimeError: if the target is still corrupt after `settings.commit_attempts` commits.
 952        """
 953        payload = _serialise(outputs)
 954        d = key.digest()
 955        try:
 956            root = self._open_root(create=True)
 957        except OSError as err:
 958            raise storage_fault(err, self.root) from err
 959        with root:
 960            with self._ensure(root, STAGING_DIR) as staging_root:
 961                self._collect_due()
 962                with self._ensure(root, STORE_DIR, d[:2], d) as parent:
 963                    return self._put_in(key, context, parent, staging_root, payload)

 965    def _put_in(
 966        self,
 967        key: LogicalKey,
 968        context: ExecutionContext,
 969        parent: StorageDir,
 970        staging_root: StorageDir,
 971        payload: tuple[object, dict[str, bytes], str],
 972    ) -> OutputIdentity:
 973        d, f = key.digest(), context.fingerprint()
 974        entry = parent.path / f
 975        for _ in range(self.settings.commit_attempts):
 976            try:
 977                existing = _committed_identity(entry, digest=d, fingerprint=f, arrays=payload[1])
 978            except CorruptEntryError:
 979                self._quarantine(entry, digest=d, fingerprint=f)
 980                existing = None
 981            if existing is not None:
 982                self._reseal(parent, f)
 983                self.provenance.add(_result_entity(existing))
 984                return existing
 985            if _commit(key, context, parent, f, staging_root, payload, self.policy):
 986                self.provenance.add(_result_entity(payload[2]))
 987                return payload[2]
 988        raise RuntimeError(f"{entry} was still corrupt after {self.settings.commit_attempts} commits")

 990    def record_reuse(  # noqa: PLR0913 - the served hit, then what its activity records
 991        self,
 992        key: LogicalKey,
 993        current: ExecutionContext,
 994        hit: StoredResult,
 995        started: datetime,
 996        attributes: Mapping[str, object] | None = None,
 997        association: Callable[[kprov.Record], kprov.Association] | None = None,
 998    ) -> None:
 999        """Add the `senselab:Reuse` activity of serving `hit` for `key` in `current`, `attributes` beside its own.
1000
1001        The activity is associated with the agent of `current` and names the agent that computed `hit`

 761    def _quarantine(self, entry: Path, *, digest: str, fingerprint: str) -> None:
 762        """Move `entry` aside, re-verify the moved copy, and put it back if it verifies.

 779        except FileNotFoundError:

 809        entry = parent.path / name

 812        except OSError as err:

 814        if info is None:
 815            return

Results addressed by logical key, one entry per execution context, safe for concurrent writers.

Each entry is staged in root/tmp/<uuid>/ and committed by os.rename; the first writer to rename wins and later writers discard their staging and return the committed identity. A staging directory is never read by get. An entry that a completed read finds corrupt or misfiled is moved into root/quarantine/<uuid> (see _quarantine) and never served. collect, which put runs at most once per policy.collect_interval_s, removes quarantined entries and staging directories older than the policy's ages. An entry found valid but writable is re-sealed.

Provenance: a put adds the result entity, output:<hex>; a get hit adds a senselab:Reuse activity that used it (or, with record=False, leaves that to record_reuse), carrying the key, the current and stored contexts, the admitting policy, the agent that computed the result and, under equivalent, the equivalence table's value_digest, associated with the current context's agent. The store writes no execution activity.

Splits: a disagreeing EquivalenceEvidence takes its two members out of the class holding both (equivalence.split). It is persisted as the evidence record, and every store over the same root applies the recorded disagreements to its table when it first reads the table.

  • provenance: Where the store adds its records; the store owns a fresh one when None.
  • policy: Modes and retention ages; StorePolicy.load_default() when None.
  • equivalence: The measured classes equivalent reuse admits (none by default; load_equivalence(path)).
