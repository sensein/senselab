senselab_core.runtime.execution.pool

Pool: the Executor that puts fragments on a run's queues and reads what pool workers made of them.

A fragment goes to the queue of its placement's resource class under <run dir>/queues/, named <class>#<model identity> when its node has a resident model. The jobs the store would serve (ResultStore.admits) are put at once. The others are the computed jobs of a unit (MeasureUnit, built by UnitResolver), and the unit moves through a ProbeState: Resolving the hardware class (the index, else the first worker's ready mark), Lookup of its estimate, PeerWait while a peer holds the unit's probe lease, Probing on a probe queue <queue>~probe-<id> served by one worker of the resolved class, then Measured or Unmeasured. Computed jobs wait while the unit resolves, waits or probes; once it ends they are put, cut and batched by size from the estimate, else its safe values. Every result of a probe item is yielded like any other. A worker records each job's ResultRef in the item's outcome, with the Observations of its requests. The Pool yields a result only once the result store holds its outputs, and a failure only as dead/<key digest>.json holds it, so a restarted coordinator reads the same state from disk. Each fault class has its effect here, with the budgets of the profile's faults section:

  • content, not a gap: charged; the job is queued again until content_attempts charges, then it is dead;
  • resource, gap or not: the job is queued again on the next larger memory class of its device, uncharged, at most resource_replacements times; then, or with no larger class, it is dead, unless the fault is a load's (FaultRecord.load): that is the environment's and counts against it as infrastructure does;
  • infrastructure, or a gap that is not resource: queued again uncharged (a gap is logged); at infrastructure_replacements failures of one env in this epoch the env is reported once as broken (BrokenEnv) and held on each queue it is seen on (Queue.hold), so its jobs wait for a later epoch and none is failed.

A retry is a one-job fragment of the next attempt, logged failed then queued by this coordinator; a job held with its env is logged queued again, so it reads as waiting, never as failed.

The Observations of production items are read against the estimate that sized them (ProbeMachine.settled): drift, regime and supersede records, and the unit's m1 raised at once by a device peak above its band; a request that raised a resource fault writes an oom record. Each class's placement event is appended again when its epoch ends, with the work's actuals (ClassActuals).

 148class Pool:
 149    """An `Executor` over the queues of the run in `run_dir`, its jobs run by pool workers a `substrate` starts.
 150
 151    `submit` puts a fragment on its queue unless a newer epoch than `epoch` was taken (`StaleCoordinator`); `poll`
 152    reads its items' outcomes once, never waiting, advances every unit's probe state and applies each fault's effect.
 153    One scaler thread, started by the first submit and stopped by `close`, sizes the substrate's workers once per
 154    `pool.poll_s` while a fragment is followed, and at once after each submit or retry; nothing else scales. An
 155    admission holds the plan only: workers bind graph inputs from the run's `inputs.json`. `events` is the log of
 156    `epoch`'s attempt; an env's infrastructure failures are counted from that epoch's events on disk. `measures` gives
 157    each unit's estimate, `roots` keeps its observations, probe lease and hardware index, and `resolver` builds its
 158    unit; each defaults to the profile's.
 159
 160    Attributes:
 161        broken: Each env this pool reported broken, once.
 162        gaps: Each job given a fault with `gap` set, with its fault.
 163        probes: Each unit this pool probed, by digest.
 164    """

 248    def bind_epoch(self, epoch: int, events: EventLog) -> None:
 249        """Coordinate as `epoch` from now on, logging to `events`, a log of that epoch's attempt.
 250
 251        A run starts its extrapolation log afresh, and the epoch it leaves is closed (`_close_placements`).
 252
 253        Raises:
 254            ValueError: `events` is not a log of `epoch`.
 255        """
 256        if events.epoch != epoch:
 257            raise ValueError(f"the pool coordinates epoch {epoch}; its event log is of epoch {events.epoch}")
 258        if self._bound:
 259            self._close_placements()
 260        self._bound = True
 261        self.epoch, self.events = epoch, events
 262        self._actuals = Actuals(self._clock)
 263        self._ledger = Placements(
 264            events, self._request, self._actuals, lambda name: self.profile.resource_classes[name].device == "cuda"
 265        )
 266        if isinstance(self.substrate, Slurm):
 267            self.substrate.attempt, self.substrate.epoch = events.attempt, epoch
 268        if self._placer is not None:
 269            self._placer.record = self._ledger.record
 270        self._live, self._landed, self._unread = None, set(), 0
 271        self._fleet.reset()
 272        self.broken_workers.clear()
 273        self._relogged.clear()
 274        self._extrapolated = ExtrapolationLog()

 276    def admit(self, placed: Plan, values: Mapping[InputIdentity, object]) -> Admission:
 277        """Hold `placed` and its graph-input `values` until released as often as admitted; its id is `run-<plan hash>`.
 278
 279        Raises:
 280            ValueError: the plan was placed under another execution profile than this pool's.
 281        """
 282        if placed.placement.profile_digest != self.profile.canonical_digest():
 283            raise ValueError(f"plan {placed.hash} was placed under another execution profile than this pool's")
 284        admission = Admission(id=f"run-{placed.hash}", plan_hash=placed.hash)
 285        with self._lock:
 286            self._plans[admission.id] = (placed, values)
 287            self._admitted[admission.id] += 1
 288            if self._placer is None:
 289                self._request_of = (placed, values)
 290                inert = None if isinstance(self.substrate, Slurm) else _INERT
 291                self._placer = Placer(
 292                    self.profile,
 293                    placed.overrides,
 294                    placed.hook,
 295                    request=self._request,
 296                    clock=self._clock,
 297                    record=self._ledger.record,
 298                    inert=inert,
 299                )
 300                if isinstance(self.substrate, Slurm):
 301                    self.substrate.placer = self._placer
 302        return admission

 325    def release(self, admission: Admission) -> None:
 326        """Let go of one admission of `admission`'s plan."""
 327        with self._lock:
 328            self._admitted[admission.id] -= 1
 329            if self._admitted[admission.id] <= 0:
 330                self._plans.pop(admission.id, None)
 331                del self._admitted[admission.id]

 333    def _fence(self, *, recent: bool = False) -> None:
 334        """Raise `StaleCoordinator` once a newer epoch is taken; `recent` reuses a read younger than `first_poll_s`."""
 335        now, fenced = self._clock.now(), self._fenced
 336        if recent and fenced is not None and now - fenced[0] < self.profile.pool.first_poll_s:
 337            current = fenced[1]
 338        else:
 339            current = self._epochs.current()
 340            self._fenced = (now, current)
 341        if current > self.epoch:
 342            raise StaleCoordinator(self.epoch, current)

 353    def _put(self, fragment: PlanFragment, followed: Followed, *, retry: bool = False) -> None:
 354        """Put `fragment` for `followed`: a retry as one item, else its servable jobs at once and the rest by unit.
 355
 356        Raises:
 357            StaleCoordinator: a newer epoch was taken.
 358            QueueHeld: the fragment's env is held on its queue by this epoch or a newer one.
 359            ValueError: the fragment's admission is not held by this pool.
 360        """
 361        self._fence()
 362        name = self._queue_name(fragment)
 363        self._check_held(name, fragment.placement.env)
 364        self._actuals.began(class_of(name))
 365        if retry:
 366            self.queues.queue(name).put_all([fragment])
 367            followed.flights.append(Flight(name, item_digest(fragment), fragment))
 368            return
 369        placed, values = self._admitted_plan(fragment)
 370        rest = self._follow(name, fragment, followed, placed, values)
 371        if rest is None:
 372            return
 373        fragment = rest
 374        jobs, placement = fragment_jobs(fragment, placed, values)
 375        flags = servable_jobs(
 376            jobs,
 377            placement,
 378            self._keys(fragment),
 379            self.resolver.envs,
 380            profile=self.profile,
 381            store=self.store,
 382            run=placed.config if placed.config is not None else RunConfig(),
 383        )
 384        dumped = Dumped.of(fragment)
 385        for wanted in (True, False):
 386            picks = [i for i, flag in enumerate(flags) if flag is wanted]
 387            if not picks:
 388                continue
 389            part = dumped.part(picks)
 390            if wanted:
 391                self._put_served(followed, name, part, placement)
 392            else:
 393                self._machine.place(Held(followed, name, part))

 395    def _live_items(self, placed: Plan, values: Mapping[InputIdentity, object]) -> dict[tuple[JobRef, str, str], str]:
 396        """Return the digest of the oldest live item holding each job, by the job, its key and the queue.
 397
 398        Read from the run's queues once per epoch, at the first put: an item with a slot and no outcome, its oldest
 399        first. A probe queue's items are not production items.
 400        """
 401        if self._live is None:
 402            found: dict[tuple[JobRef, str, str], str] = {}
 403            for queue in self.queues.names():
 404                if probe_of(queue) is not None:
 405                    continue
 406                for digest, old in self.queues.queue(queue).live_items():
 407                    if old.admission not in self._plans:
 408                        continue
 409                    try:
 410                        keys = fragment_keys(old, placed, values)
 411                    except ValueError:
 412                        continue
 413                    for job, key in zip(old.jobs, keys, strict=True):
 414                        found.setdefault((job, key, queue), digest)
 415            self._live = found
 416        return self._live

 418    def _follow(
 419        self,
 420        name: str,
 421        fragment: PlanFragment,
 422        followed: Followed,
 423        placed: Plan,
 424        values: Mapping[InputIdentity, object],
 425    ) -> PlanFragment | None:
 426        """Follow the live item on queue `name` that holds a job of `fragment`; return the fragment of the others.
 427
 428        A job whose live item is on another queue, or under another key, is not followed: it is put again. A followed
 429        item is read through a flight of the jobs of `fragment` it holds, so each job is given and charged once.
 430        None when every job is followed.
 431        """
 432        live = self._live_items(placed, values)
 433        if not live:
 434            return fragment
 435        keys = self._keys(fragment)
 436        holders: dict[str, list[int]] = {}
 437        for index, (job, key) in enumerate(zip(fragment.jobs, keys, strict=True)):
 438            if (digest := live.get((job, key, name))) is not None:
 439                holders.setdefault(digest, []).append(index)
 440        if not holders:
 441            return fragment
 442        dumped = Dumped.of(fragment)
 443        picks = sorted(i for each in holders.values() for i in each)
 444        followed.flights.extend(Flight(name, digest, dumped.part(each)) for digest, each in holders.items())
 445        self._machine.place(Held(followed, name, dumped.part(picks), tuple(holders)))
 446        left = sorted(set(range(len(fragment.jobs))) - set(picks))
 447        return dumped.part(left) if left else None

 471    def _produce(self, release: Release, jobs: Sequence[Job], placement: Placement) -> None:
 472        """Put `release`'s jobs sized (`size`) from its estimate, else the safe values: cut, and batched by length."""
 473        held, estimate = release.held, release.estimate
 474        kind = detected_kind(jobs) if estimate is None else estimate.unit_kind
 475        lengths = tuple(job_units(j, kind) for j in jobs)
 476        sized = size(
 477            estimate,
 478            self._grant(held.queue),
 479            self.profile.sizing,
 480            LengthProfile(units=lengths),
 481            calibration=self.profile.calibration,
 482            bucket_edges=bucket_edges(placement.backend, kind),
 483        )
 484        label = None if release.unit is None else release.unit.label()
 485        if label is not None:
 486            self._extrapolated.note(label, sized)
 487        digests = list(held.following)
 488        if not held.following:
 489            self._check_held(held.queue, held.part.placement.env)
 490            dumped, items = Dumped.of(held.part), []
 491            for start, stop in sized.cuts:
 492                for batch, group in itertools.groupby(
 493                    range(start, stop), key=lambda i: sized.batch_at(lengths[i], len(jobs))
 494                ):
 495                    moved = held.part.placement.model_copy(update={"batch_size": batch})
 496                    items.append(dumped.part(list(group), placement=moved.model_dump(mode="json")))
 497            self.queues.queue(held.queue).put_all(items)
 498            held.followed.flights.extend(Flight(held.queue, item_digest(i), i) for i in items)
 499            digests = [item_digest(i) for i in items]
 500        held.followed.waiting = [p for p in held.followed.waiting if p is not held.part]
 501        self._machine.note(release, digests)
 502        with self._lock:
 503            known = sized.measured.time and all(p is not None for p in sized.predicted_s)
 504            per_job = sum(p or 0.0 for p in sized.predicted_s) / len(jobs) if known else None
 505            cap = self._grant(held.queue).max_workers
 506            if self._grant(held.queue).devices is not None:
 507                cap = min(cap, self._grant(held.queue).devices * sized.workers_per_device)  # type: ignore[operator]
 508            self._rates.setdefault(held.queue, {})[label or "unmeasured"] = (per_job, cap)
 509        self._wake_scaler()

 511    def workers_wanted(self, queue: str, work: int) -> int:
 512        """Return the workers `queue`'s `work` jobs want.
 513
 514        A probe queue wants none: its unit's one worker is counted on the queue it measures, as is the one that waits
 515        for a hello. The rest is by the slowest measured unit's seconds per job over `target_wall_s`; an unmeasured
 516        unit is not scaled (`unmeasured_workers`).
 517        """
 518        if probe_of(queue) is not None:
 519            return 0
 520        with self._lock:
 521            rates = list(self._rates.get(queue, {}).values())
 522        probing, resolving = self._machine.counts(queue)
 523        grant = self._grant(queue)
 524        items = math.ceil(work / grant.quantum_items)
 525        base = 0
 526        if work > 0:
 527            if not rates or any(r is None for r, _ in rates):
 528                base = min(self.profile.calibration.unmeasured_workers, items, grant.max_workers)
 529            else:
 530                slowest = max(r for r, _ in rates if r is not None)
 531                cap = max(c for _, c in rates)
 532                base = min(max(1, math.ceil(work * slowest / self.profile.sizing.target_wall_s)), items, cap)
 533        wanted = base + probing + (1 if resolving and not probing else 0)
 534        return min(wanted, self.granted(queue).max_workers) if wanted > 0 else 0

 558    def _scale(self) -> None:
 559        """Have the substrate size its workers to the queues; only the scaler thread calls it, never re-entered.
 560
 561        A `SubstrateError` is counted (`Fleet.fail_substrate`) and the substrate is not used again until its backoff
 562        has passed; past `faults.infrastructure_replacements` failures in a row it is broken, the run is held
 563        (`WorkersBroken`) and nothing is scaled again this epoch. Any other error ends the scaler and is raised by
 564        `poll`.
 565        """
 566        assert threading.current_thread() is self._scaler and not self._scaling, "only the scaler thread scales"
 567        if not self._fleet.substrate_due():
 568            return
 569        self._scaling = True
 570        try:
 571            scale(
 572                self.queues,
 573                self._fleet,
 574                self.profile,
 575                workers=self.workers_wanted,
 576                surplus_since=self._surplus,
 577                clock=self._clock,
 578                granted=self.granted,
 579            )
 580        except SubstrateError as err:
 581            logger.warning("the substrate failed: %s", err)
 582            self._fleet.fail_substrate(err)
 583        else:
 584            self._fleet.substrate_ok()
 585        finally:
 586            self._scaling = False

 588    def _workers_broken(self, flight: Flight) -> WorkersBroken | None:
 589        """Return the hold of `flight`'s queue by a broken class of workers, noting the break once."""
 590        found = self._fleet.broken_for(flight.queue)
 591        if found is None:
 592            return None
 593        if found.resource_class not in self.broken_workers:

 599                self.events.record("queued", job.node, job=job, key=key, env=flight.fragment.placement.env)
 600        return WorkersBroken(flight.queue, found.resource_class, found.failures, found.reason)

 605    def submit(self, fragment: PlanFragment) -> Handle:
 606        """Put `fragment` on the queue of its resource class, as quantum-sized items, and return its handle.
 607
 608        Raises:
 609            StaleCoordinator: a newer epoch than this coordinator's was taken; nothing is put.
 610            QueueHeld: the fragment's env is held on its queue; nothing is put.
 611            ValueError: the fragment's admission is not held by this pool; nothing is put.
 612        """
 613        followed = Followed([])
 614        self._put(fragment, followed)
 615        handle = Handle(id=f"pool-{self.epoch}-{next(self._ids)}")
 616        with self._lock:
 617            self._followed[handle.id] = followed
 618        self._wake_scaler()
 619        return handle

 638    def poll(self, handle: Handle) -> tuple[list[ResultRef], bool]:
 639        """Read the outcomes of `handle`'s items once, applying each fault's effect, and return the results landed.
 640
 641        Returns the results not yet given, items read in one poll in job order, and whether the fragment is ended:
 642        every result given, or the handle cancelled. A hold is raised once the results landed with it are given. The
 643        epoch is read afresh once outcomes have landed, before any effect is applied.
 644
 645        Raises:
 646            KeyError: the handle is not this pool's.
 647            StaleCoordinator: a newer epoch was taken.
 648            QueueHeld: a job's env is held, or its class's workers are broken; the jobs not given wait in their queues.
 649            ScalerFailed: the scaler thread ended on an error, chained as the cause.
 650        """
 651        if self._scale_error is not None:
 652            raise ScalerFailed(f"the pool's scaler failed: {self._scale_error!r}") from self._scale_error
 653        followed = self._followed[handle.id]
 654        if followed.cancelled or followed.done:
 655            return [], True
 656        self._fence(recent=True)
 657        self._machine.advance()
 658        given: list[ResultRef] = []
 659        landed = [(f, r) for f in followed.flights if (r := self.queues.queue(f.queue).outcome(f.digest))]
 660        if landed:
 661            self._fence()
 662        for flight, record in landed:
 663            followed.flights.remove(flight)
 664            followed.seen = True
 665            given.extend(self._settle(followed, flight, record))
 666        self._flush_reuses()
 667        parts = [Flight(self._queue_name(p), item_digest(p), p) for p in followed.waiting]
 668        held = followed.held + [
 669            self._held(f) for f in [*followed.flights, *parts] if f.fragment.placement.env in self.broken
 670        ]
 671        stopped = [b for f in [*followed.flights, *parts] if (b := self._workers_broken(f)) is not None]
 672        if (held or stopped) and not given:
 673            raise (held or stopped)[0]
 674        followed.done = not followed.flights and not followed.waiting and not held
 675        return given, followed.done

 677    def close(self) -> None:
 678        """Stop the scaler thread, then the workers the substrate started; write the reuses recorded, if any.
 679
 680        Raises:
 681            RunIOError: the reuses cannot be written and no other error is ending the run.
 682        """
 683        with self._lock:
 684            self._closing = True
 685            scaler = self._scaler
 686        self._scale_wake.set()
 687        if scaler is not None:
 688            scaler.join()
 689        self._close_placements()
 690        self._machine.close()
 691        self._fleet.close()
 692        if self._reuses_unwritten and sys.exc_info()[0] is None:
 693            self.store.provenance.write(self.run_dir)
 694            self._reuses_unwritten = False
 695        else:
 696            self._flush_reuses()

 698    def _settle(self, followed: Followed, flight: Flight, record: Mapping[str, object]) -> Iterator[ResultRef]:
 699        """Yield the results of `flight`'s jobs from its outcome `record`, applying each failure's effect.
 700
 701        A reported result is taken only when it names the job's own key and the store holds its outputs; one whose
 702        outcome was written by a claim of another epoch, or of none, is given as served under `exact` unless it was
 703        served under another policy, and is recorded as a reuse in the store's provenance (`_reuse`).
 704        """
 705        fragment = flight.fragment
 706        jobs = record.get("jobs") if record.get("outcome") == "done" else None
 707        given = {r.job: r for r in (ResultRef.model_validate(j) for j in jobs)} if isinstance(jobs, list) else {}
 708        dead = FaultRecord.model_validate(record["fault"]) if record.get("outcome") == "dead" else None
 709        logical = fragment_logical_keys(fragment, *self._admitted_plan(fragment))
 710        reused = record.get("epoch") != self.epoch
 711        seen = _observed(record)
 712        with self._lock:
 713            first = flight.digest not in self._landed
 714            self._landed.add(flight.digest)
 715        if first:
 716            if not reused:
 717                self._actuals.landed(class_of(flight.queue), seen)
 718            self._machine.settled(flight.digest, seen)
 719            self._machine.oom(flight.digest, seen, _worker_of(record))
 720            if _load_oom(record):
 721                self._machine.unfit(flight.digest, _worker_of(record))
 722            if not reused:
 723                self._survived(flight, record)
 724        try:
 725            yield from self._results(followed, flight, record, seen, given, dead, logical, reused)
 726        finally:
 727            if first:
 728                self._machine.forget(flight.digest)

 730    def _survived(self, flight: Flight, record: Mapping[str, object]) -> None:
 731        """Count each worker loss the item survived as an infrastructure failure of its env, uncharged to any job.
 732
 733        The first job and its key stand for the item. Once the env's budget is spent it is held, as for a failed job.
 734        """
 735        lost = record.get("survived")
 736        if not isinstance(lost, list) or not flight.fragment.jobs:
 737            return
 738        job = flight.fragment.jobs[0]
 739        key = self._keys(flight.fragment)[0]
 740        for found in lost:
 741            if not self._infrastructure(flight, job, key, FaultRecord.model_validate(found)):
 742                return

 744    def _results(  # noqa: PLR0913 - the item and its outcome, then what `_settle` read of it
 745        self,
 746        followed: Followed,
 747        flight: Flight,
 748        record: Mapping[str, object],
 749        seen: Sequence[Observation],
 750        given: Mapping[JobRef, ResultRef],
 751        dead: FaultRecord | None,
 752        logical: Sequence[LogicalKey],
 753        reused: bool,  # noqa: FBT001 - whether another epoch's claim wrote the outcome
 754    ) -> Iterator[ResultRef]:
 755        fragment = flight.fragment
 756        placed = self._admitted_plan(fragment)[0]
 757        for index, (job, key) in enumerate(zip(fragment.jobs, (k.digest() for k in logical), strict=True)):
 758            ref = given.get(job)
 759            if ref is not None and ref.key_digest != key:
 760                fault = FaultRecord.from_exception(
 761                    WrongKey(f"the outcome gives {job} the key {ref.key_digest}, not its own {key}")
 762                )
 763            elif ref is not None and ref.failure is None and ref.output_identity is not None:
 764                found = self.store.entry_of(key, ref.output_identity)
 765                if found is not None:
 766                    if reused:
 767                        self._reuse(placed, job, logical[index], found, ref.served)
 768                    yield ref.model_copy(update={"served": "exact"}) if reused and ref.served is None else ref
 769                    continue
 770                fault = FaultRecord.gap_of("MissingOutput", f"the outputs of {job} are not in the result store")
 771            elif ref is not None and ref.failure is not None:
 772                fault = ref.failure
 773            else:
 774                fault = dead or FaultRecord.gap_of(
 775                    "MissingResult", f"the outcome of the item gives no result for {job}"
 776                )
 777            yield from self._effect(followed, flight, index, key, fault)

 779    def _reuse(self, placed: Plan, job: JobRef, key: LogicalKey, hit: StoredResult, served: str | None) -> None:
 780        """Record that this attempt settles `hit` for `key` from an earlier attempt, under the policy `served`."""
 781        settled = f"{job.node}:{key.digest()}"
 782        if settled in self._reused:
 783            return
 784        run = placed.config if placed.config is not None else RunConfig()

 786        record_settled_reuse(
 787            self.store,
 788            key,
 789            hit,
 790            datetime.now(timezone.utc),
 791            ReusePolicy(served or ReusePolicy.EXACT.value),
 792            reuse_attributes(run, hit),
 793            job,
 794        )
 795        self._reused.add(settled)
 796        self._reuses_unwritten = True

 818    def _effect(  # noqa: PLR0913 - the followed fragment, the item and the job's failure
 819        self,
 820        followed: Followed,
 821        flight: Flight,
 822        index: int,
 823        key: str,
 824        fault: FaultRecord,
 825    ) -> Iterator[ResultRef]:
 826        """Apply `fault`'s effect to job `index` of `flight`: retry it, hold its env, or yield it dead."""
 827        fragment, budgets = flight.fragment, self.profile.faults
 828        job, placement = fragment.jobs[index], fragment.placement
 829        if fault.gap:
 830            self.gaps.append((job, fault))
 831            logger.warning("classification gap: %s of %s, not charged", fault.type, job)
 832        larger = larger_class(self.profile, placement.resource_class)
 833        replaced = (
 834            fault.fault == "resource"
 835            and larger is not None
 836            and followed.moved[job.element] < budgets.resource_replacements
 837        )
 838        if fault.counts_against_env and not (fault.load and replaced):
 839            if self._infrastructure(flight, job, key, fault):
 840                self._again(followed, flight, index)
 841            else:
 842                self.events.record("queued", job.node, job=job, key=key, env=placement.env)
 843                followed.held.append(self._held(flight))
 844            return
 845        if fault.fault == "resource":
 846            followed.moved[job.element] += 1
 847            if replaced and larger is not None:
 848                self._failed(job, key, fault, placement.env, replaced=True)
 849                grant = {"resource_class": larger, "partition": self.profile.resource_classes[larger].partition}
 850                self._again(followed, flight, index, placement.model_copy(update=grant))
 851                return
 852        else:
 853            followed.charged[job.element] += 1
 854            if followed.charged[job.element] < budgets.content_attempts:
 855                self._failed(job, key, fault, placement.env)
 856                self._again(followed, flight, index)
 857                return
 858        yield self._dead(job, key, fault)

 860    def _env_failures(self, env: str) -> list[FaultRecord]:
 861        """Return the failures of `env` that count against it, as this epoch's events on disk record, in order.
 862
 863        An event line of this epoch's writers that could not be read has no env to charge: the count may be low by
 864        that many, which is logged once.
 865        """
 866        scan = scan_events(self.run_dir)
 867        mine = {e.writer for e in scan.events if e.epoch == self.epoch}
 868        lost = sum(1 for q in scan.quarantined if q.writer in mine)
 869        if lost > self._unread:
 870            logger.warning("the failures counted against env %s may be low: %d event lines are unreadable", env, lost)
 871            self._unread = lost
 872        return [
 873            e.failure
 874            for e in scan.events
 875            if e.kind == "failed"
 876            and e.epoch == self.epoch
 877            and e.env == env
 878            and e.failure is not None
 879            and not e.replaced
 880            and e.failure.counts_against_env
 881        ]

 888    def _infrastructure(self, flight: Flight, job: JobRef, key: str, fault: FaultRecord) -> bool:
 889        """Count an infrastructure fault of `flight`'s env this epoch; return False once the env is broken and held.
 890
 891        A broken env is held on `flight`'s queue (each queue it is seen on); `poll` has fenced afresh before.
 892        """
 893        env, budget = flight.fragment.placement.env, self.profile.faults.infrastructure_replacements
 894        with self._lock:
 895            failures = len(self._env_failures(env))
 896            if env not in self.broken and failures < budget:
 897                self._failed(job, key, fault, env)
 898                failures += 1
 899                if failures < budget:
 900                    return True
 901            reported = env in self.broken
 902            if not reported:
 903                self.broken[env] = BrokenEnv(env=env, fault=fault, failures=failures)
 904        self.queues.queue(flight.queue).hold(self.epoch, env)
 905        if not reported:
 906            logger.error(
 907                "env %s is broken after %d infrastructure faults; it is held: %s", env, failures, fault.message
 908            )
 909        return False

 996def _scale_rounds(ref: "weakref.ref[Pool]", wake: threading.Event, poll_s: float, clock: Clock) -> None:
 997    """Scale the pool `ref` names on each wake, and once per `poll_s` while it follows a fragment.
 998
 999    While the substrate backs off, the next round comes when its wait ends, if sooner. Ends once the pool is closed or
1000    collected, or on an error other than a `SubstrateError`, which the pool keeps for `poll` to raise; the pool is held
1001    only during a round.
1002    """
1003    woken = True
1004    while (pool := ref()) is not None and not pool._closing:  # noqa: SLF001 - the pool's own scaler
1005        if woken or pool._open():  # noqa: SLF001
1006            try:
1007                pool._scale()  # noqa: SLF001
1008            except Exception as err:  # noqa: BLE001 - carried to the thread that polls
1009                pool._scale_error = err  # noqa: SLF001
1010                return
1011        backoff = pool._fleet.substrate_wait()  # noqa: SLF001
1012        del pool
1013        woken = clock.wait(wake, min(poll_s, backoff) if backoff > 0 else poll_s)
1014        wake.clear()

516        for a hello. The rest is by the slowest measured unit's seconds per job over `target_wall_s`; an unmeasured
517        unit is not scaled (`unmeasured_workers`).
518        """

520            return 0
521        with self._lock:
522            rates = list(self._rates.get(queue, {}).values())
523        probing, resolving = self._machine.counts(queue)
524        grant = self._grant(queue)
525        items = math.ceil(work / grant.quantum_items)
526        base = 0
527        if work > 0:
528            if not rates or any(r is None for r, _ in rates):
529                base = min(self.profile.calibration.unmeasured_workers, items, grant.max_workers)
530            else:
531                slowest = max(r for r, _ in rates if r is not None)
532                cap = max(c for _, c in rates)
533                base = min(max(1, math.ceil(work * slowest / self.profile.sizing.target_wall_s)), items, cap)
534        wanted = base + probing + (1 if resolving and not probing else 0)
535        return min(wanted, self.granted(queue).max_workers) if wanted > 0 else 0

639    def poll(self, handle: Handle) -> tuple[list[ResultRef], bool]:
640        """Read the outcomes of `handle`'s items once, applying each fault's effect, and return the results landed.
641
642        Returns the results not yet given, items read in one poll in job order, and whether the fragment is ended:
643        every result given, or the handle cancelled. A hold is raised once the results landed with it are given. The
644        epoch is read afresh once outcomes have landed, before any effect is applied.
645
646        Raises:
647            KeyError: the handle is not this pool's.
648            StaleCoordinator: a newer epoch was taken.
649            QueueHeld: a job's env is held, or its class's workers are broken; the jobs not given wait in their queues.
650            ScalerFailed: the scaler thread ended on an error, chained as the cause.
651        """
652        if self._scale_error is not None:
653            raise ScalerFailed(f"the pool's scaler failed: {self._scale_error!r}") from self._scale_error
654        followed = self._followed[handle.id]
655        if followed.cancelled or followed.done:
656            return [], True
657        self._fence(recent=True)
658        self._machine.advance()
659        given: list[ResultRef] = []
660        landed = [(f, r) for f in followed.flights if (r := self.queues.queue(f.queue).outcome(f.digest))]
661        if landed:
662            self._fence()
663        for flight, record in landed:
664            followed.flights.remove(flight)
665            followed.seen = True
666            given.extend(self._settle(followed, flight, record))
667        self._flush_reuses()
668        parts = [Flight(self._queue_name(p), item_digest(p), p) for p in followed.waiting]
669        held = followed.held + [
670            self._held(f) for f in [*followed.flights, *parts] if f.fragment.placement.env in self.broken
671        ]
672        stopped = [b for f in [*followed.flights, *parts] if (b := self._workers_broken(f)) is not None]
673        if (held or stopped) and not given:
674            raise (held or stopped)[0]
675        followed.done = not followed.flights and not followed.waiting and not held
676        return given, followed.done

699    def _settle(self, followed: Followed, flight: Flight, record: Mapping[str, object]) -> Iterator[ResultRef]:
700        """Yield the results of `flight`'s jobs from its outcome `record`, applying each failure's effect.
701
702        A reported result is taken only when it names the job's own key and the store holds its outputs; one whose
703        outcome was written by a claim of another epoch, or of none, is given as served under `exact` unless it was
704        served under another policy, and is recorded as a reuse in the store's provenance (`_reuse`).
705        """
706        fragment = flight.fragment
707        jobs = record.get("jobs") if record.get("outcome") == "done" else None
708        given = {r.job: r for r in (ResultRef.model_validate(j) for j in jobs)} if isinstance(jobs, list) else {}
709        dead = FaultRecord.model_validate(record["fault"]) if record.get("outcome") == "dead" else None
710        logical = fragment_logical_keys(fragment, *self._admitted_plan(fragment))
711        reused = record.get("epoch") != self.epoch
712        seen = _observed(record)
713        with self._lock:
714            first = flight.digest not in self._landed
715            self._landed.add(flight.digest)
716        if first:
717            if not reused:
718                self._actuals.landed(class_of(flight.queue), seen)
719            self._machine.settled(flight.digest, seen)
720            self._machine.oom(flight.digest, seen, _worker_of(record))
721            if _load_oom(record):
722                self._machine.unfit(flight.digest, _worker_of(record))
723            if not reused:
724                self._survived(flight, record)
725        try:
726            yield from self._results(followed, flight, record, seen, given, dead, logical, reused)
727        finally:
728            if first:
729                self._machine.forget(flight.digest)

An Executor over the queues of the run in run_dir, its jobs run by pool workers a substrate starts.

submit puts a fragment on its queue unless a newer epoch than epoch was taken (StaleCoordinator); poll reads its items' outcomes once, never waiting, advances every unit's probe state and applies each fault's effect. One scaler thread, started by the first submit and stopped by close, sizes the substrate's workers once per pool.poll_s while a fragment is followed, and at once after each submit or retry; nothing else scales. An admission holds the plan only: workers bind graph inputs from the run's inputs.json. events is the log of epoch's attempt; an env's infrastructure failures are counted from that epoch's events on disk. measures gives each unit's estimate, roots keeps its observations, probe lease and hardware index, and resolver builds its unit; each defaults to the profile's.

  • gaps: Each job given a fault with gap set, with its fault.
  • probes: Each unit this pool probed, by digest.
