senselab_core.runtime.execution.queue

Queues of plan fragments in a shared directory: items by identity, slots in segments, oldest-first claims (ADR-003).

QueueSet.for_run(run_dir) holds one queue per name: a resource class, with #<model identity> for a resident model (gpu:h100#<id>). A queue is the directory <root>/<identity_digest("label@1", name)>, holding:

  • name: the queue's name, written once.
  • items/<digest>.json: a plan-fragment@3.0 document as JCS, named by identity_digest("plan-fragment@3", …) of its JSON form; the first writer wins.
  • segments/<seq>/slot-<n>: the index, a symlink to <digest> (never followed) made by an exclusive symlink at the next free n; n runs from 0 to pool.segment_items - 1, and a put that finds them all taken makes segments/<seq+1>. Order is slot order within a segment and segment order across segments. Nothing in a segment is written in place.
  • segments/<seq>/jobs-<n>-<count>: the number of jobs of slot n's item, written by the put that took the slot, so a listing of the segment gives the queue's work without reading an item.
  • segments/<seq>/res-<n>: the mark that slot n's item has an outcome, written only once outcome/<digest> exists and the slot, read again, names that digest.
  • slotted/<digest>: a symlink to <seq>/<n>, made after the item's first slot; a put of a slotted item adds none.
  • segments/<seq>/retired: the mark, made by an exclusive create, of a segment whose slots are all taken and all marked. A segment stays where it is once retired, so a segment number is made once.
  • claims/<digest>.lease: the Lease of a claim on the item.
  • serve.lease: on a probe queue, the Lease of the one worker that serves it (Queue.serve_lease).
  • hardware, env: on a probe queue, the HardwareClass and the backend's env its serving worker must have, written once by the coordinator (Queue.set_probe_unit); a queue without it is served by no worker.
  • closed: on a probe queue, the mark (Queue.close_probe) that no worker takes its serve lease or claims from it.
  • probe/<digest>: on a probe queue, a JCS record {"phase", "stratum"} of the probe item (Queue.mark_probe).
  • outcome/<digest>: the item's one outcome, a JCS record {"outcome": "done" | "dead", ...} linked from a staged file, so the first writer wins and an item is never both done and dead.
  • held-<epoch>-<env label>: the mark, made by the coordinator of that epoch, that no item placed in that env is claimed; the env label is identity_digest("label@1", env). Only a hold of the current epoch or a newer one counts.

A probe queue is named <queue>~probe-<id> (probe_queue), under the queue it measures.

A claim walks the segments from the oldest live one, lists each, and takes the lease of the first slot that is neither marked nor under a live claim; the outcome is checked again once the lease is held. An outcome is staged, the lease proven, and the staged record linked at outcome/<digest> in the one call after the proof.

 112def probe_queue(queue: str, probe_id: str) -> str:
 113    """Return the name of the probe queue of `probe_id` under `queue`.
 114
 115    Raises:
 116        ValueError: `queue` is itself a probe queue, or the result is not a queue name.
 117    """
 118    name = f"{queue}{PROBE_MARK}{probe_id}"
 119    if PROBE_MARK in queue or not QUEUE_NAME.fullmatch(name):
 120        raise ValueError(f"{name!r} is not the probe queue of {queue!r}")
 121    return name

 139def _resolve(q: StorageDir, seq: int, n: int, digest: str) -> None:
 140    """Mark slot `n` of segment `seq` resolved, only when `outcome/<digest>` exists and the slot names `digest`."""
 141    with q.child("outcome") as outcome:
 142        if outcome.lstat(digest) is None:
 143            return
 144    with contextlib.suppress(FileNotFoundError), q.child("segments") as segments:
 145        with segments.child(_seq(seq)) as segment:
 146            if segment.readlink(f"slot-{n}") != digest:
 147                logger.warning("queue segment %s slot %d no longer names %s; not marked", _seq(seq), n, digest)
 148                return
 149            with contextlib.suppress(FileExistsError):
 150                segment.write_new(f"res-{n}", b"", STAGING_FILE_MODE, grammar=RESOLVED_NAME)

 153def _slots(segment: StorageDir) -> tuple[list[int], set[int], dict[int, int]]:
 154    """Return the slot numbers of a segment, in order, the resolved ones, and each recorded job count by slot."""
 155    slots, resolved, jobs = [], set(), {}
 156    for name in segment.listdir():
 157        if m := SLOT_NAME.fullmatch(name):
 158            slots.append(int(m.group(1)))
 159        elif m := RESOLVED_NAME.fullmatch(name):
 160            resolved.add(int(m.group(1)))
 161        elif m := JOBS_NAME.fullmatch(name):
 162            jobs[int(m.group(1))] = int(m.group(2))
 163    return sorted(slots), resolved, jobs

 171def settle(lease: Lease, q: StorageDir, digest: str, record: dict[str, object]) -> Optional[bool]:
 172    """Write `record` as the one outcome of `digest` under `lease`: staged, then proven, then linked.
 173
 174    Returns True when `outcome/<digest>` holds this record (written now, or by this caller before a lost reply),
 175    False when it holds another, and None when the proof failed and nothing was linked.
 176    """
 177    data = jcs_dumps(record)
 178    with q.child("outcome") as outcome:
 179        temporary = temporary_name(digest)
 180        outcome.write_new(temporary, data, STAGING_FILE_MODE, grammar=TEMPORARY_NAME)
 181        try:
 182            if not lease.prove():
 183                return None
 184            try:
 185                outcome.link(temporary, outcome, digest, grammar=DIGEST_NAME)
 186            except FileExistsError:
 187                return outcome.read_regular(digest) == data
 188            return True
 189        finally:
 190            outcome.remove_owned(temporary, pattern=TEMPORARY_NAME)

 193class _Bound:
 194    """The size of a claim: at most `items` items and, when `jobs` is set, at most `jobs` jobs beyond its first item.
 195
 196    With `singles`, only one-job items join a one-job first item.
 197    """
 198
 199    def __init__(self, items: Optional[int], jobs: Optional[int], singles: bool = False) -> None:
 200        self.items = items if items is not None else (1 if jobs is None else None)
 201        self.jobs = jobs
 202        self.singles = singles
 203
 204    def fits(self, taken: list["_Held"], count: Optional[int]) -> bool:
 205        """Whether an item of `count` jobs (None when unknown) may join `taken`."""
 206        if not taken:
 207            return True
 208        if self.singles and (count != 1 or len(taken[0].fragment.jobs) != 1):
 209            return False
 210        if self.jobs is None or count is None:
 211            return True
 212        return sum(len(h.fragment.jobs) for h in taken) + count <= self.jobs
 213
 214    def full(self, taken: list["_Held"]) -> bool:
 215        """Whether `taken` fills the claim."""
 216        jobs = sum(len(h.fragment.jobs) for h in taken)
 217        return (self.items is not None and len(taken) >= self.items) or (self.jobs is not None and jobs >= self.jobs)

 237class Claim:
 238    """Items one worker claimed from a queue, each under its own beating `Lease` until it is finished.
 239
 240    `outcomes` records, per digest, what became of each item this claim gave up: `committed`, `dead`, `duplicate`
 241    (another claim's outcome was written first), `released` or `lost` (the lease failed its proof; nothing written).
 242    An outcome record names `epoch`, the coordinator epoch current when the claim was taken.
 243    """
 244
 245    def __init__(self, queue: "Queue", worker: str, held: list[_Held], epoch: int) -> None:
 246        """Hold `held` for `worker`, taken in coordinator epoch `epoch`; use `Queue.claim`."""
 247        self.queue = queue
 248        self.worker = worker
 249        self.epoch = epoch
 250        self._held = {h.digest: h for h in held}
 251        self.outcomes: dict[str, str] = {}
 252
 253    @property
 254    def items(self) -> tuple[str, ...]:
 255        """The digests still held, in claim order."""
 256        return tuple(self._held)
 257
 258    @property
 259    def fragments(self) -> tuple[PlanFragment, ...]:
 260        """The fragments still held, in claim order."""
 261        return tuple(h.fragment for h in self._held.values())
 262
 263    def slot(self, digest: str) -> tuple[int, int]:
 264        """Return the `(segment, slot)` a held item was claimed from."""
 265        return self._held[digest].slot
 266
 267    @property
 268    def broke(self) -> dict[str, tuple[BrokenLease, ...]]:
 269        """The stale leases each held item's lease broke when it was taken, by digest; none for an item with none."""
 270        return {d: h.broke for d, h in self._held.items() if h.broke}
 271
 272    def _chosen(self, items: Optional[Iterable[str]]) -> list[_Held]:
 273        if items is None:
 274            return list(self._held.values())
 275        chosen = list(items)
 276        if missing := [d for d in chosen if d not in self._held]:
 277            raise KeyError(f"this claim does not hold {missing}")
 278        return [self._held[d] for d in chosen]
 279
 280    def _end(self, held: _Held, outcome: str) -> None:
 281        del self._held[held.digest]
 282        self.outcomes[held.digest] = outcome
 283        held.stack.close()
 284
 285    def renew(self) -> bool:
 286        """Prove every held lease; an item whose lease was lost is given up as `lost`. Return whether all were held."""
 287        lost = [h for h in self._held.values() if h.state.lost or not h.lease.prove()]
 288        for held in lost:
 289            self._end(held, "lost")
 290        return not lost
 291
 292    def _finish(self, held: _Held, outcome: str, extra: dict[str, object]) -> str:
 293        """Write `outcome` for `held` (`settle`), mark its slot and release it; return what became of it."""
 294        record = _outcome_record(outcome, self.worker, self.epoch, **extra)
 295        written = None
 296        if not held.state.lost:
 297            with self.queue.open() as q:
 298                written = settle(held.lease, q, held.digest, record)
 299                if written is not None:
 300                    _resolve(q, *held.slot, held.digest)
 301        result = (
 302            "lost" if written is None else ("committed" if outcome == "done" else "dead") if written else "duplicate"
 303        )
 304        self._end(held, result)
 305        return result
 306
 307    def commit(
 308        self, items: Optional[Iterable[str]] = None, extra: Optional[dict[str, object]] = None
 309    ) -> tuple[str, ...]:
 310        """Commit the held `items` (all by default) as `done`, with the fields of `extra`; return those committed."""
 311        outcomes = {h.digest: self._finish(h, "done", dict(extra or {})) for h in self._chosen(items)}
 312        return tuple(d for d, o in outcomes.items() if o == "committed")
 313
 314    def dead(self, fault: FaultRecord, items: Optional[Iterable[str]] = None) -> tuple[str, ...]:
 315        """Give the held `items` (all by default) the outcome `dead` with `fault`; return the digests this call did."""
 316        extra: dict[str, object] = {"fault": fault.model_dump(mode="json")}
 317        outcomes = {h.digest: self._finish(h, "dead", extra) for h in self._chosen(items)}
 318        return tuple(d for d, o in outcomes.items() if o == "dead")
 319
 320    def release(self, items: Optional[Iterable[str]] = None) -> None:
 321        """Give the held `items` (all by default) back: their leases are released and they are ready again."""
 322        for held in self._chosen(items):
 323            self._end(held, "released")
 324
 325    def __enter__(self) -> "Claim":
 326        """Return this claim."""
 327        return self
 328
 329    def __exit__(self, *exc: object) -> None:
 330        """Release every item still held."""
 331        self.release()

 359class Queue:
 360    """One queue of plan fragments under a `QueueSet`.
 361
 362    Attributes:
 363        name: The queue's name.
 364        path: The queue's directory.
 365        faults: Each item a claim found missing, with its infrastructure fault; the item stays ready.
 366        backoffs: How many times a claim found an item under another live claim and moved on.
 367    """
 368
 369    def __init__(  # noqa: PLR0913 - the queue's place, name and profile, then the epoch and the clock
 370        self,
 371        root: Path,
 372        name: str,
 373        profile: ExecutionProfile,
 374        lease: JobLease,
 375        epoch: Optional[Callable[[], int]] = None,
 376        clock: Clock = SystemClock(),  # noqa: B008 - stateless
 377    ) -> None:
 378        """Open, creating it if missing, the queue `name` under `root`; use `QueueSet.queue`.
 379
 380        `profile` sizes the segments; `lease` is the bound every lease of the queue is judged and beaten by.
 381        `epoch` gives the current coordinator epoch, below which a hold does not count; every hold counts when None.
 382        Every lease, the storage clock and the claim backoffs are read on `clock`.
 383
 384        Raises:
 385            ValueError: `name` is not a resource class with an optional `#<model identity>`.
 386        """
 387        if not isinstance(name, str) or not QUEUE_NAME.fullmatch(name):
 388            raise ValueError(f"{name!r} is not a queue name: a resource class, with #<model identity> for a model")
 389        self.name = name
 390        self.path = Path(root) / identity_digest(LABEL_TAG, name)
 391        self.faults: list[tuple[str, FaultRecord]] = []
 392        self.backoffs = 0
 393        self._segment_items = profile.pool.segment_items
 394        self._stale_after = lease.stale_after_s
 395        self._settings = lease
 396        self._renew_fraction = lease.renew_fraction
 397        self._judged: dict[str, float] = {}
 398        self._missing: dict[str, float] = {}
 399        self._targets: dict[tuple[int, int], str] = {}
 400        self._envs: dict[str, str] = {}
 401        self._jobs: dict[str, int] = {}
 402        self._epoch, self._clock = epoch, clock
 403        self._head = 0
 404        self._oldest = 0
 405        with StorageDir.open_root(self.path, create=True, mode=STAGING_DIR_MODE) as q:
 406            for directory in DIRECTORIES:
 407                q.child(directory, create=True, mode=STAGING_DIR_MODE).close()
 408            if q.lstat("name") is None:
 409                q.publish("name", name.encode(), grammar=NAME_FILE, mode=STAGING_FILE_MODE)
 410
 411    @contextlib.contextmanager
 412    def open(self) -> Iterator[StorageDir]:
 413        """Yield the queue's directory, open."""
 414        with StorageDir.open_root(self.path) as q:
 415            yield q
 416
 417    def outcome(self, digest: str) -> Optional[dict[str, object]]:
 418        """Return the outcome record of `digest`, None while it has none."""
 419        with self.open() as q, q.child("outcome") as outcome:
 420            data = outcome.read_regular(digest)
 421        record = jcs_loads(data) if data is not None else None
 422        return record if isinstance(record, dict) else None

 542        digests: dict[str, Optional[int]] = {}

 558    def _index(self, q: StorageDir, digests: Mapping[str, Optional[int]]) -> int:
 559        """Give each of `digests` that has neither a slot nor an outcome a slot, in order; return how many.
 560
 561        Each maps to its item's job count, read from the item when None.
 562        """
 563        taken = 0
 564        with (
 565            q.child("outcome") as outcome,
 566            q.child("slotted") as slotted,
 567            q.child("segments") as segments,
 568            q.child("items") as items,
 569        ):
 570            for digest, count in digests.items():
 571                if slotted.lstat(digest) is not None or outcome.lstat(digest) is not None:
 572                    continue
 573                jobs = count if count is not None else self._job_count(items, digest)
 574                seq, n = self._take_slot(segments, digest, jobs)
 575                with contextlib.suppress(FileExistsError):
 576                    slotted.symlink(f"{_seq(seq)}/{n}", digest, grammar=DIGEST_NAME)
 577                taken += 1
 578        return taken

 580    def _take_slot(self, segments: StorageDir, digest: str, jobs: int) -> tuple[int, int]:
 581        """Make the next free slot of the head segment point at `digest`, rolling to a new segment when it is full.
 582
 583        The slot's job count `jobs` is recorded beside it once the slot is taken.
 584
 585        A segment's directory is made by `mkdir`, which the storage refuses for a number made before, so a segment
 586        number, retired or not, is opened and never made again.
 587        """
 588        seq = max(self._head, self._last(segments))
 589        while True:
 590            segment = segments.child(_seq(seq), create=True, mode=STAGING_DIR_MODE)
 591            with segment:
 592                slots, _, _ = _slots(segment)
 593                n = slots[-1] + 1 if slots else 0
 594                while n < self._segment_items:
 595                    try:
 596                        segment.symlink(digest, f"slot-{n}", grammar=SLOT_NAME)
 597                    except FileExistsError:
 598                        n += 1
 599                        continue
 600                    with contextlib.suppress(FileExistsError):
 601                        segment.write_new(f"jobs-{n}-{jobs}", b"", STAGING_FILE_MODE, grammar=JOBS_NAME)
 602                    self._head = seq
 603                    return seq, n
 604            seq += 1

 607        """Return the highest segment number this queue knows of, listing `segments/` when it knows none."""
 608        if self._head:
 609            return self._head
 610        return max((int(n) for n in segments.listdir() if SEQ_NAME.fullmatch(n)), default=0)

 666    def claim(
 667        self, worker: str, max_items: Optional[int] = None, max_jobs: Optional[int] = None, *, singles: bool = False
 668    ) -> Optional[Claim]:
 669        """Claim up to `max_items` items without an outcome, oldest first, for `worker`; None when none is claimable.
 670
 671        `max_items` is 1 when neither bound is given and unbounded when only `max_jobs` is. With `max_jobs`, an item
 672        whose recorded job count would take the claim past it is passed over, except as the claim's first item. With
 673        `singles`, items join a claim only while it and they hold one job each.
 674
 675        Each item is held under a `Lease` beating from its own renewer until the claim commits, kills or releases
 676        it. An item under a live claim is skipped; a stale claim is broken, within one renewal interval of going
 677        stale, and its item claimed again. A missing item is left ready and recorded in `faults`. An item whose env is
 678        held (`hold`) is skipped.
 679
 680        Raises:
 681            ValueError: `max_items` or `max_jobs` is below 1.
 682        """
 683        if (max_items is not None and max_items < 1) or (max_jobs is not None and max_jobs < 1):
 684            raise ValueError(f"a claim takes at least one item of one job (got {max_items}, {max_jobs})")
 685        skip = set(self._holds())
 686        taken: list[_Held] = []
 687        try:
 688            with self.open() as q, q.child("segments") as segments, q.child("claims") as claims:
 689                self._fill(q, segments, claims, taken, _Bound(max_items, max_jobs, singles), skip)
 690        except BaseException:
 691            for held in taken:
 692                held.stack.close()
 693            raise
 694        return Claim(self, worker, taken, self._current()) if taken else None

 696    def _segments(
 697        self, segments: StorageDir
 698    ) -> Generator[tuple[int, StorageDir, list[int], set[int], dict[int, int]], None, None]:
 699        """Yield each live segment, open, oldest first from the oldest this queue has seen live; retire full ones.
 700
 701        A segment is retired by its `retired` mark, made in place once all its slots are taken and marked.
 702        """
 703        seq, prefix = self._oldest, True
 704        while True:
 705            try:
 706                segment = segments.child(_seq(seq))
 707            except FileNotFoundError:
 708                return
 709            with segment:
 710                live = segment.lstat(RETIRED_MARK) is None
 711                if live:
 712                    slots, resolved, jobs = _slots(segment)
 713                    live = len(slots) < self._segment_items or not resolved.issuperset(slots)
 714                    if not live:
 715                        with contextlib.suppress(FileExistsError):
 716                            segment.write_new(RETIRED_MARK, b"", STAGING_FILE_MODE, grammar=RETIRED_NAME)
 717                if live:
 718                    prefix = False
 719                    yield seq, segment, slots, resolved, jobs
 720                elif prefix:
 721                    self._oldest = seq + 1
 722                    self._targets = {k: d for k, d in self._targets.items() if k[0] > seq}
 723            seq += 1

 725    def _fill(  # noqa: PLR0913 - the queue's open directories, the items taken and the bound
 726        self,
 727        q: StorageDir,
 728        segments: StorageDir,
 729        claims: StorageDir,
 730        taken: list[_Held],
 731        bound: _Bound,
 732        skip: set[str],
 733    ) -> None:
 734        """Take claims into `taken`, oldest first, until `bound` is full or no live segment has an item that fits."""
 735        leased = {n.removesuffix(".lease") for n in claims.listdir() if n.endswith(".lease")}
 736        now = self._clock.now()
 737        self._judged = {d: at for d, at in self._judged.items() if d in leased and now - at < self._interval}
 738        self._missing = {d: at for d, at in self._missing.items() if now - at < self._interval}
 739        walk = self._segments(segments)
 740        with contextlib.closing(walk):
 741            self._fill_from(q, claims, walk, taken, bound, skip)

 743    def _fill_from(  # noqa: PLR0913 - as `_fill`, with the walk of live segments
 744        self,
 745        q: StorageDir,
 746        claims: StorageDir,
 747        walk: Iterator[tuple[int, StorageDir, list[int], set[int], dict[int, int]]],
 748        taken: list[_Held],
 749        bound: _Bound,
 750        skip: set[str],
 751    ) -> None:
 752        for seq, segment, slots, resolved, jobs in walk:
 753            for n in slots:
 754                if n in resolved or not bound.fits(taken, jobs.get(n)):
 755                    continue
 756                digest = self._target(segment, seq, n)
 757                if digest is None or digest in self._judged or digest in self._missing:
 758                    continue
 759                if self._envs.get(digest) in skip:
 760                    continue
 761                held = self._take(q, claims, (seq, n), digest, skip)
 762                if held is not None:
 763                    taken.append(held)
 764                    if bound.full(taken):
 765                        return

 771    def _target(self, segment: StorageDir, seq: int, n: int) -> Optional[str]:
 772        """Return the digest slot `n` names, read once per process; None if it names none."""
 773        if (seq, n) not in self._targets:
 774            target = segment.readlink(f"slot-{n}")
 775            if not DIGEST_NAME.fullmatch(target):
 776                logger.warning("queue %s: segment %s slot %d names no item", self.name, _seq(seq), n)
 777                return None
 778            self._targets[(seq, n)] = target

 781    def _take(  # noqa: PLR0913 - the queue's open directories, the slot, the item and the held envs
 782        self, q: StorageDir, claims: StorageDir, slot: tuple[int, int], digest: str, skip: set[str]
 783    ) -> Optional[_Held]:
 784        """Take the claim on `digest` and read its fragment; None if it is claimed, has an outcome or is missing.
 785
 786        None too when its env's label is in `skip`.
 787        """
 788        stack = contextlib.ExitStack()
 789        lease = Lease(claims.path / digest, settings=self._settings, timeout=0, directory=claims, clock=self._clock)
 790        try:
 791            stack.enter_context(lease)
 792        except LeaseTimeout:
 793            self.backoffs += 1
 794            self._judged[digest] = self._clock.now()
 795            return None
 796        try:
 797            with q.child("outcome") as outcome:
 798                if outcome.lstat(digest) is not None:
 799                    _resolve(q, *slot, digest)
 800                    stack.close()
 801                    return None
 802            fragment = self._fragment(q, lease, slot, digest)
 803            if fragment is not None:
 804                self._envs[digest] = identity_digest(LABEL_TAG, fragment.placement.env)
 805            if fragment is None or self._envs[digest] in skip:
 806                stack.close()
 807                return None
 808            state = stack.enter_context(lease.keep_alive(self._renew_fraction))
 809        except BaseException:
 810            stack.close()
 811            raise
 812        return _Held(digest, slot, fragment, lease, state, stack, tuple(lease.broke))

 814    def _fragment(self, q: StorageDir, lease: Lease, slot: tuple[int, int], digest: str) -> Optional[PlanFragment]:
 815        """Return the fragment of `digest`, held under `lease`; None when it is missing or is not that fragment.
 816
 817        A missing item is an infrastructure fault: it is recorded in `faults` and stays ready. An item that is not the
 818        fragment its name digests is a content fault, and its outcome is `dead`.
 819        """
 820        with q.child("items") as items:
 821            data = items.read_regular(f"{digest}.json")
 822        if data is None:
 823            fault = FaultRecord.from_exception(MissingItem(f"queue item {digest}"))
 824            logger.warning("queue %s: item %s is missing; it stays ready", self.name, digest)
 825            self.faults.append((digest, fault))
 826            self._missing[digest] = self._clock.now()
 827            return None
 828        try:
 829            document = jcs_loads(data)
 830            if identity_digest(ITEM_TAG, document) != digest:
 831                raise ValueError("not the item its name digests")
 832            return PlanFragment.model_validate(document)
 833        except ValueError as err:
 834            fault = FaultRecord.from_exception(CorruptItem(str(err)))
 835            logger.warning("queue %s: item %s cannot be read (%s); its outcome is dead", self.name, digest, err)
 836            record = _outcome_record("dead", "queue", self._current(), fault=fault.model_dump(mode="json"))
 837            if settle(lease, q, digest, record) is not None:
 838                _resolve(q, *slot, digest)
 839            return None

 841    def live_items(self) -> list[tuple[str, PlanFragment]]:
 842        """Return the digest and fragment of each item with a slot and no outcome, in queue order.
 843
 844        An item that cannot be read is left out. It reads every live item, so it costs O(live items).
 845        """
 846        found: dict[str, PlanFragment] = {}
 847        with (
 848            self.open() as q,
 849            q.child("segments") as segments,
 850            q.child("items") as items,
 851            q.child("outcome") as outcome,
 852        ):
 853            for name in sorted(n for n in segments.listdir() if SEQ_NAME.fullmatch(n)):
 854                with contextlib.suppress(FileNotFoundError), segments.child(name) as segment:
 855                    if segment.lstat(RETIRED_MARK) is not None:
 856                        continue
 857                    slots, resolved, _ = _slots(segment)
 858                    for n in slots:
 859                        digest = None if n in resolved else self._target(segment, int(name), n)
 860                        if digest is None or digest in found or outcome.lstat(digest) is not None:
 861                            continue
 862                        if (fragment := self._item(items, digest)) is not None:
 863                            found[digest] = fragment
 864        return list(found.items())

 892    def _waiting(self) -> Iterator[int]:
 893        """Yield the job count of each taken, unresolved slot of each live segment."""
 894        with self.open() as q, q.child("segments") as segments, q.child("items") as items:
 895            for name in segments.listdir():
 896                if SEQ_NAME.fullmatch(name):
 897                    with contextlib.suppress(FileNotFoundError), segments.child(name) as segment:
 898                        if segment.lstat(RETIRED_MARK) is None:
 899                            slots, resolved, jobs = _slots(segment)
 900                            for n in sorted(set(slots) - resolved):
 901                                yield jobs[n] if n in jobs else self._unrecorded(items, segment, int(name), n)

 908    def _job_count(self, items: StorageDir, digest: str) -> int:
 909        """Return the jobs of item `digest`, read once per process; 1 while it cannot be read."""
 910        if digest not in self._jobs:
 911            data = items.read_regular(f"{digest}.json")
 912            try:
 913                document = jcs_loads(data) if data is not None else None
 914            except ValueError:
 915                document = None

 922    def oldest_age_s(self) -> Optional[float]:
 923        """Return the storage-clock age of the oldest slot whose item has no outcome and no live claim.
 924
 925        An item behind a stale claim (its holder dead) counts as waiting. None when no item waits.
 926        """
 927        with self.open() as q, q.child("segments") as segments, q.child("claims") as claims:
 928            now = self._clock.storage_now(q)
 929            for name in sorted(n for n in segments.listdir() if SEQ_NAME.fullmatch(n) and int(n) >= self._oldest):
 930                with contextlib.suppress(FileNotFoundError), segments.child(name) as segment:
 931                    if segment.lstat(RETIRED_MARK) is not None:
 932                        continue
 933                    slots, resolved, _ = _slots(segment)
 934                    for n in slots:

701
702        A segment is retired by its `retired` mark, made in place once all its slots are taken and marked.

732        bound: _Bound,
733        skip: set[str],

736        leased = {n.removesuffix(".lease") for n in claims.listdir() if n.endswith(".lease")}

744    def _fill_from(  # noqa: PLR0913 - as `_fill`, with the walk of live segments
745        self,
746        q: StorageDir,
747        claims: StorageDir,
748        walk: Iterator[tuple[int, StorageDir, list[int], set[int], dict[int, int]]],
749        taken: list[_Held],
750        bound: _Bound,
751        skip: set[str],
752    ) -> None:
753        for seq, segment, slots, resolved, jobs in walk:
754            for n in slots:

782    def _take(  # noqa: PLR0913 - the queue's open directories, the slot, the item and the held envs
783        self, q: StorageDir, claims: StorageDir, slot: tuple[int, int], digest: str, skip: set[str]
784    ) -> Optional[_Held]:
785        """Take the claim on `digest` and read its fragment; None if it is claimed, has an outcome or is missing.
786
787        None too when its env's label is in `skip`.
788        """
789        stack = contextlib.ExitStack()

808                return None
