senselab_core.runtime.execution.pool_worker

Pool workers: a host process serving a run's queues of some resource classes (senselab execute --pool).

A pool worker claims one item at a time from the queue of the class whose oldest waiting item is oldest, logs each job claimed under the run's current epoch and attempt, runs the jobs through the process's WorkerSet (execute), and commits each item with one ResultRef per job and a Sample of what the item took (report); the Pool applies each failure's effect. It stays on a class for at most pool.quantum_items jobs or pool.quantum_s seconds, and then claims from the class with the oldest work. While a claim runs, its leases are proven every renewal interval; an item whose lease was lost is not reported. A request that fires a trigger is split in halves by execute until the failing job is alone, which is reported with that failure (ItemCrashedWorker for a job whose worker was lost repeatedly); an item that fails inside a request is reported as it failed. The worker exits once its queues have had nothing to claim for pool.idle_polls polls of pool.poll_s, or on SIGTERM, after committing the items that finished and releasing the rest. A worker of svc:<id> classes registers each server it starts (services); once it holds one, its queues being empty decide nothing: it exits when no consumer lease of any service it holds has been live for services.idle_exit_s, the jobs it runs itself counting as consumption.

 114def run_members(  # noqa: PLR0913 - the members and their placement, the request seam, then the cancel flag and the log
 115    members: Sequence[Member],
 116    placement: Placement,
 117    send: Send,
 118    cancelled: threading.Event | None = None,
 119    record: Callable[[Sent], None] | None = None,
 120    clock: Clock = SystemClock(),  # noqa: B008 - stateless
 121    handover: Handover | None = None,
 122) -> list[JobOutcome]:
 123    """Return one outcome per member, sent as one call of `send`, which splits its requests as `execute` does.
 124
 125    An exception `send` raises is the failure of every member. Each call of `send` is given to `record` as `Sent`s,
 126    timed on `clock`: one for each request the engine split or retried (a report marked `bisected` or `failed`), and
 127    one for the rest, with the requests it made, each timed on `clock` too. With `handover`, each member's outcome is
 128    given to it once it is final, which is as its request ends when `send` takes an `Emit`, else as the call ends; a
 129    request's `Sent` is recorded before its members are handed over, so each carries its own wall and report. A `send`
 130    that takes `cancelled` is given the flag.
 131
 132    Raises:
 133        Abandoned: `cancelled` was set before a request, or while one ran.
 134        LeaseTimeout: a start lease the request needs is busy; nothing failed.
 135    """
 136    if cancelled is not None and cancelled.is_set():
 137        raise Abandoned
 138    refs = tuple(m.job.ref for m in members)
 139    began = clock.now()
 140    forward: _Forward | None = None
 141    try:
 142        with request_reports.collected(clock) as reported:
 143            call = send
 144            if handover is not None and _takes(send, "emit"):
 145                forward = _Forward(members, handover, record, reported)
 146                call = functools.partial(call, emit=forward)
 147            if cancelled is not None and _takes(send, "cancelled"):
 148                call = functools.partial(call, cancelled=cancelled)
 149            outcomes = call([m.job for m in members], placement)
 150    except Exception as exc:
 151        if isinstance(exc, Abandoned) or (cancelled is not None and cancelled.is_set()):
 152            raise exc if isinstance(exc, Abandoned) else Abandoned() from exc
 153        if isinstance(exc, LeaseTimeout):
 154            raise
 155        return _failed_call(members, exc, (record, forward, clock.now() - began), handover)
 156    if record is not None:
 157        left = reported if forward is None else forward.unrecorded(reported)
 158        _record_requests(record, forward, (refs, clock.now() - began), left)
 159    if handover is not None:
 160        handover(members, outcomes)
 161    return outcomes

 164def _failed_call(
 165    members: Sequence[Member],
 166    exc: Exception,
 167    seams: tuple[Callable[[Sent], None] | None, "_Forward | None", float],
 168    handover: Handover | None,
 169) -> list[JobOutcome]:
 170    """Return the failure of every member of a call that raised `exc`, recorded and handed over.
 171
 172    `seams` are the record, the call's forward and its wall.
 173    """
 174    record, forward, wall = seams
 175    _record_failure(record, forward, (tuple(m.job.ref for m in members), wall), exc)
 176    if len(members) == 1:
 177        logger.warning("job %s fails its request alone: %s", members[0].job.ref, type(exc).__name__)
 178    failed: list[JobOutcome] = [Failed(m.job.ref, m.key, failure_of(exc)) for m in members]
 179    if handover is not None:
 180        handover(members, failed)
 181    return failed

 184def _record_requests(
 185    record: Callable[[Sent], None],
 186    forward: "_Forward | None",
 187    call: tuple[tuple[JobRef, ...], float],
 188    reports: Sequence[RequestReport],
 189    *,
 190    bare: bool = True,
 191) -> None:
 192    """Record the requests `reports` of one call in the order they ran: each the engine marked as its own `Sent`.
 193
 194    The others are recorded together, each run of them in one `Sent` under the call's refs less those an emit handed
 195    over; the last takes what is left of the call's wall, less the marked requests' and what the emits recorded. With
 196    `bare` false that last `Sent` is recorded only when some request is in it.
 197    """
 198    refs, wall = call if forward is None else forward.rest(*call)
 199    ordered: list[list[RequestReport] | RequestReport] = []
 200    for request in reports:
 201        if request.failure is not None:
 202            ordered.append(request)
 203        elif ordered and isinstance(ordered[-1], list):
 204            ordered[-1].append(request)
 205        else:
 206            ordered.append([request])
 207    last: list[RequestReport] = []
 208    if ordered and isinstance(ordered[-1], list):
 209        last = ordered.pop()  # type: ignore[assignment]
 210    for entry in ordered:
 211        if isinstance(entry, RequestReport):
 212            tagged = tuple(t for t in entry.tags if isinstance(t, JobRef))
 213            record(Sent(tagged or refs, entry.wall_s or 0.0, (entry,), entry.failure, entry.fault))
 214            wall -= entry.wall_s or 0.0
 215        else:
 216            spent = sum(r.wall_s or 0.0 for r in entry)
 217            record(Sent(refs, spent, tuple(entry), None))
 218            wall -= spent
 219    if refs and (last or bare):
 220        record(Sent(refs, max(0.0, wall), tuple(last), None))

 223def _record_failure(
 224    record: Callable[[Sent], None] | None,
 225    forward: "_Forward | None",
 226    call: tuple[tuple[JobRef, ...], float],
 227    exc: Exception,
 228) -> None:
 229    """Record the call that raised `exc` as a `Sent`, less the members and the requests an emit already recorded."""
 230    if record is None:
 231        return
 232    refs, wall = call if forward is None else forward.rest(*call)
 233    if refs:
 234        kind: FaultKind | None = None if _loading(exc) else classify(exc).value
 235        record(Sent(refs, wall, (), "failed", kind))

 246def _carried(report: RequestReport, refs: set[JobRef]) -> bool:
 247    """Whether `report` is of a request that carried one of `refs`; a report tagged with nothing is every job's."""

 252class _Forward:
 253    """The `Emit` of one call of `send`: records the requests made since the last emit, then hands over their members.
 254
 255    A request is recorded as its own `Sent` before its members are handed over, so the item it settles is measured by
 256    it; the call's own `Sent` then holds only what no emit recorded.
 257    """
 258
 259    def __init__(
 260        self,
 261        members: Sequence["Member"],
 262        handover: Handover,
 263        record: Callable[[Sent], None] | None,
 264        reported: Sequence[RequestReport],
 265    ) -> None:
 266        self.members, self.handover, self.record, self.reported = members, handover, record, reported
 267        self.taken: set[int] = set()
 268        self.wall_s = 0.0
 269        self.given: set[JobRef] = set()
 270
 271    def __call__(self, at: Sequence[int], outcomes: Sequence[JobOutcome]) -> None:
 272        """Record the requests reported since the last call, then hand over the members at `at`."""
 273        chosen = [self.members[i] for i in at]
 274        refs = {m.job.ref for m in chosen}
 275        new = tuple(r for r in self.reported if id(r) not in self.taken and _carried(r, refs))
 276        self.taken.update(id(r) for r in new)
 277        if new and self.record is not None:
 278            wall = sum(r.wall_s or 0.0 for r in new)
 279            self.wall_s += wall
 280            _record_requests(self.record, None, (tuple(m.job.ref for m in chosen), wall), new, bare=False)
 281        self.given.update(m.job.ref for m in chosen)
 282        self.handover(chosen, outcomes)
 283
 284    def unrecorded(self, reports: Sequence[RequestReport]) -> tuple[RequestReport, ...]:
 285        """Return the `reports` no emit has recorded."""
 286        return tuple(r for r in reports if id(r) not in self.taken)
 287
 288    def rest(self, refs: tuple[JobRef, ...], wall_s: float) -> tuple[tuple[JobRef, ...], float]:
 289        """Return the refs of a call not handed over, and its wall less the requests already recorded."""
 290        return tuple(r for r in refs if r not in self.given), max(0.0, wall_s - self.wall_s)

 293@dataclass
 294class _Spans:
 295    """What each item of a claim ran in, by digest: its wall seconds and the requests its jobs were in.
 296
 297    An item's wall is its jobs' share of each request they were in, each timed by itself, and of the time a call of
 298    `send` took beyond its requests. Its requests are those the calls made. `lost` holds the workers lost to a request
 299    whose jobs all completed, which the item reports as survived losses.
 300    """
 301
 302    walls: dict[str, float] = field(default_factory=dict)
 303    requests: dict[str, list[RequestRecord]] = field(default_factory=dict)
 304    lost: dict[str, list[FaultRecord]] = field(default_factory=dict)
 305
 306    def add(self, sent: Sent, owners: Mapping[JobRef, str]) -> None:
 307        """Take one call of `send`: charge each job's item its share of each request and of the rest of the call."""
 308        for request in sent.reports:
 309            tagged = [owners[t] for t in request.tags if isinstance(t, JobRef) and t in owners]
 310            if request.survived and request.crash is not None and tagged:
 311                self.lost.setdefault(tagged[0], []).append(FaultRecord.of(request.crash))
 312        records = records_of(sent)
 313        rest = max(0.0, sent.wall_s - sum(r.wall_s for r in records)) / len(sent.refs)
 314        for ref in sent.refs:
 315            self._charge(owners[ref], rest)
 316        for record in records:
 317            for ref in record.refs:
 318                if ref in owners:
 319                    self._charge(owners[ref], record.wall_s / len(record.refs))
 320            for digest in dict.fromkeys(owners[r] for r in record.refs if r in owners):
 321                self.requests.setdefault(digest, []).append(record)
 322
 323    def _charge(self, digest: str, seconds: float) -> None:
 324        self.walls[digest] = self.walls.get(digest, 0.0) + seconds

 410    def ready(self) -> dict[str, QueueReady]:
 411        """Return what this worker says of each queue it serves: its class, and the env of each backend placed on it.
 412
 413        The backends come from the run's placement of its latest attempt (`private/placements/<attempt>.json`). Each
 414        env is built here, or read when built, so the mark that carries it is written after the builds; a build that
 415        fails is recorded in the mark, not raised.
 416        """
 417        try:
 418            placed = placed_backends(run_plan(self.run_dir, self.profile))
 419        except (FileNotFoundError, ValueError):
 420            placed = {}
 421        found = {}
 422        for name in self.classes:
 423            try:
 424                hardware: HardwareClass | None = self._hardware(class_of(name))
 425            except ValueError as err:
 426                logger.warning("pool worker %s cannot describe the hardware of %s: %s", self.name, name, err)
 427                hardware = None
 428            envs = {f"{task}~{backend}": self._env(name, task, backend) for task, backend in placed.get(name, ())}
 429            found[name] = QueueReady(hardware, envs)
 430        return found

 432    def _env(self, queue: str, task: str, backend_name: str) -> dict[str, Any]:
 433        """Return the mark's entry for the env of `task`'s backend `backend_name`, built here; else its cause."""
 434        registry = packaged().registry
 435        backend = next((b for b in registry.backends(task) if b.name == backend_name), None)
 436        if backend is None:
 437            return {"unbuilt": "unreadable"}

 442            return {"unbuilt": "build-failed"}
 443        device = self.profile.resource_classes[class_of(queue)].device
 444        try:
 445            return mark_entry(self.profile, backend, handle, host_report(self.profile.sizing.device_query_s), device)

 454    @contextlib.contextmanager
 455    def halting_on(self) -> Iterator[Callable[[], None]]:
 456        """Yield `request`, which a signal handler calls to have `halt` run on a thread of this context's own.
 457
 458        `request` only puts on a `SimpleQueue`, which is reentrant, so it takes no lock that the frame a signal
 459        interrupted may hold; `stop.set()` takes the lock of the Event the claim loop waits on, so it is not run in
 460        the handler. Leaving the context ends the thread.
 461        """
 462        requests: queue.SimpleQueue[bool] = queue.SimpleQueue()
 463
 464        def serve_requests() -> None:
 465            if requests.get():
 466                self.halt()
 467
 468        thread = threading.Thread(target=serve_requests, name="senselab-pool-halt", daemon=True)
 469        thread.start()
 470        try:
 471            yield lambda: requests.put(True)
 472        finally:
 473            requests.put(False)
 474            thread.join()

 476    def serve(self) -> int:
 477        """Claim and run items until the queues stay empty for `pool.idle_polls` polls or `stop` is set; return 0.
 478
 479        A probe queue the worker serves (`_pinned_probes`) is waited on from `pool.first_poll_s`, doubling to
 480        `pool.poll_s`, so a probe's next phase costs no full poll; its serve leases are released on return.
 481        """
 482        failed = True
 483        try:
 484            self._check_lease()
 485            result = self._claim_loop()
 486            failed = False
 487            return result
 488        finally:
 489            for lease in self._serving.values():
 490                lease.release()
 491            self._serving.clear()
 492            self._write_provenance(raising=not failed)

 494    def _check_lease(self) -> None:
 495        """Read the newest bound epoch's lease section once the epoch has moved; refuse one this worker's differs from.
 496
 497        Raises:
 498            LeaseMismatch: the section is not this worker's profile's, so its beats and the run's judges would disagree.
 499        """
 500        current = self.epochs.current()
 501        if current == self._seen_epoch:
 502            return
 503        self._seen_epoch = current
 504        bound = self.epochs.bound()
 505        if bound and (keys := differing(self.profile.lease, run := read_section(self.epochs.root / str(bound[-1])))):
 506            raise LeaseMismatch(keys, self.profile.lease, run)

 519    def _claim_loop(self) -> int:
 520        pool = self.profile.pool
 521        current: str | None = None
 522        spent, began, idle, waited = 0, self._clock.now(), None, 0.0
 523        while not self.stop.is_set():
 524            self._check_lease()
 525            ended = current is not None and (spent >= pool.quantum_items or self._clock.now() - began >= pool.quantum_s)
 526            prefer = None if ended else current
 527            asked = self._clock.now()
 528            claim = self._next(prefer, pool.quantum_items - spent)
 529            if claim is None:
 530                current, idle = None, idle if idle is not None else self._clock.now()
 531                provided = self._workers.provided() if self._workers is not None else []
 532                if provided:
 533                    if all(p.idle_s() >= self.profile.services.idle_exit_s for p in provided):
 534                        break
 535                    self._clock.wait(self.stop, pool.poll_s)
 536                    continue
 537                left = pool.idle_polls * pool.poll_s - (self._clock.now() - idle)
 538                if left <= 0:
 539                    break
 540                pause = pool.poll_s
 541                if self._serving:
 542                    waited = min(pool.poll_s, max(waited * 2, pool.first_poll_s))
 543                    pause = waited
 544                self._clock.wait(self.stop, min(pause, left))
 545                continue
 546            idle, waited = None, 0.0
 547            if claim.queue.name != current or ended:
 548                current, spent, began = claim.queue.name, 0, self._clock.now()
 549            spent += sum(len(f.jobs) for f in claim.fragments)
 550            self.served.extend((claim.queue.name, d) for d in claim.items)
 551            self.run_claim(claim, claim_s=self._clock.now() - asked)
 552            for service in self._workers.provided() if self._workers is not None else []:
 553                service.touch()
 554        return 0

 556    def _by_age(self) -> list[str]:
 557        """Return the classes with waiting work, the one whose oldest waiting item is oldest first."""
 558        ages = [(age, n) for n in self.classes if (age := self.queues.queue(n).oldest_age_s()) is not None]
 559        return [n for _, n in sorted(ages, key=lambda a: -a[0])]

 561    def _pinned_probes(self) -> list[str]:
 562        """Return the probe queues of this worker's queues it serves, oldest first.
 563
 564        A worker serves a probe queue while it holds that queue's serve lease; it takes the lease of one with waiting
 565        work whose recorded hardware class is its own (none recorded, or the queue closed: none takes it), and skips
 566        one whose lease is live under another worker. A lease it lost, or on a queue since closed, is dropped. The
 567        run's queues are listed at most once per `pool.presence_refresh_s`.
 568        """
 569        for name, kept in list(self._serving.items()):
 570            if not kept.held or self.queues.queue(name).probe_closed():
 571                kept.release()
 572                del self._serving[name]
 573        now = self._clock.now()
 574        if self._listed is None or now - self._listed >= self.profile.pool.presence_refresh_s:
 575            self._listed = now
 576            for name in self.queues.names():
 577                found = probe_of(name)
 578                if found is not None and found[0] in self.classes and name not in self._serving:
 579                    queue = self.queues.queue(name)
 580                    if queue.oldest_age_s() is not None and self._serves(queue):
 581                        if (lease := queue.serve_lease()) is not None:
 582                            self._serving[name] = lease
 583        ages = {n: self.queues.queue(n).oldest_age_s() or 0.0 for n in self._serving}
 584        return sorted(ages, key=lambda n: -ages[n])

 586    def _serves(self, queue: Queue) -> bool:
 587        """Return whether this worker is what the probe queue names: its class and its env for the probe's backend.
 588
 589        False while the queue names none, or is closed; the lease is never taken on a guess.
 590        """
 591        if queue.probe_closed():
 592            return False
 593        wanted, env = queue.probe_hardware(), queue.probe_env()
 594        if wanted is None or env is None:
 595            return False
 596        try:
 597            if self._hardware(class_of(queue.name)) != wanted:
 598                return False
 599        except ValueError:
 600            return False
 601        production = probe_of(queue.name)
 602        if production is None or "~" not in env[0]:
 603            return False
 604        task, backend = env[0].split("~", 1)
 605        mine = self._entries.get((production[0], env[0]))
 606        if mine is None:
 607            mine = self._entries[production[0], env[0]] = self._env(production[0], task, backend)
 608        return "unbuilt" not in mine and env_identity(mine) == env_identity(env[1])

 610    def _next(self, prefer: str | None, left: int) -> Claim | None:
 611        """Claim up to `left` jobs from `prefer`, else from the class with the oldest work; None if none.
 612
 613        A claim holds one item, or one-job items up to the bound; on a queue this worker has not run, one item, so
 614        the model load falls on one item alone. A probe queue this worker serves comes first, and its items are
 615        claimed one per claim, never gathered.
 616        """
 617        order = [prefer] if prefer is not None else []
 618        order += [n for n in self._by_age() if n != prefer]
 619        probes = self._pinned_probes()
 620        for name in [*probes, *(n for n in order if n not in probes)]:
 621            size = left if name == prefer else self.profile.pool.quantum_items
 622            queue = self.queues.queue(name)
 623            if name in probes:
 624                claim = queue.claim(self.name, max_items=1)
 625            elif name in self._warm:
 626                claim = queue.claim(self.name, max_jobs=max(size, 1), singles=True)
 627            else:
 628                claim = queue.claim(self.name, max_items=1, max_jobs=max(size, 1))
 629            if claim is not None:
 630                return claim
 631        return None

 633    def run_claim(self, claim: Claim, claim_s: float = 0.0) -> None:
 634        """Run every item of `claim`, committing each as its jobs finish; release what is held at the end.
 635
 636        An item whose jobs cannot be built is given the outcome `dead` with that failure. The jobs run on a thread
 637        while this one waits, proving the claim's leases every renewal interval. Once a lease is lost, the claim's
 638        other items are released at once, the request in flight is abandoned (`WorkerSet.abandon`), nothing more is
 639        sent, and this returns only after the thread stopped. Once `stop` is set, the request is abandoned too, the
 640        thread is given `join_s`, and the items whose jobs finished by then are committed. Each claim is a writer of
 641        its own (`ProvStore.restart`): its document in the run's `prov/` holds the claim's activities and the run's
 642        plan, and is replaced before each commit and when the claim ends, however it ends; a failed write is raised,
 643        or logged where an error already ends the claim. A raise stops the request in flight before the claim's items
 644        are released.
 645        """
 646        self.store.provenance.restart()
 647        failed = True
 648        try:
 649            self._run_claim(claim, claim_s)
 650            failed = False
 651        finally:
 652            self._write_provenance(raising=not failed)

 654    def _run_claim(self, claim: Claim, claim_s: float) -> None:
 655        spans = _Spans()
 656        with claim:
 657            self._log_claimed(claim)
 658            groups, dead = self._groups(claim)
 659            sample = self._sampler(claim, groups, spans, claim_s)
 660            observe = self._observer(claim, groups, spans)
 661            for digest, failure in dead.items():
 662                claim.dead(failure, [digest])
 663            pending = {d: len(f.jobs) for d, f in zip(claim.items, claim.fragments, strict=True)}
 664            outcomes: dict[str, dict[int, JobOutcome]] = {d: {} for d in claim.items}
 665            finished: Finished = queue.SimpleQueue()
 666            self._finished, cancelled = finished, threading.Event()
 667            runner = threading.Thread(target=self._run_groups, args=(groups, finished, cancelled, spans), daemon=True)
 668            runner.start()
 669            interval = self.queues.lease.renew_fraction * self.queues.lease.stale_after_s
 670            running, renewed = True, self._clock.now()
 671            try:
 672                while running and claim.items and not self.stop.is_set():
 673                    with contextlib.suppress(queue.Empty):
 674                        batch = finished.get(timeout=interval)
 675                        running = batch is not None
 676                        self._commit(
 677                            claim, batch or [], outcomes, pending, (sample, observe, lambda d: spans.lost.get(d, []))
 678                        )
 679                    if self._clock.now() - renewed >= interval:
 680                        renewed = self._clock.now()
 681                        if not claim.renew():
 682                            logger.warning(
 683                                "pool worker %s lost a claim on queue %s; its request is abandoned",
 684                                self.name,
 685                                claim.queue.name,
 686                            )
 687                            claim.release()
 688                            break
 689            finally:
 690                self._stop_runner(runner, cancelled)
 691            while not finished.empty():
 692                self._commit(
 693                    claim,
 694                    finished.get_nowait() or [],
 695                    outcomes,
 696                    pending,
 697                    (sample, observe, lambda d: spans.lost.get(d, [])),
 698                )
 699        self._warm.add(claim.queue.name)

 701    def _sampler(
 702        self, claim: Claim, groups: list["_Group"], spans: "_Spans", claim_s: float
 703    ) -> Callable[[str], Sample]:
 704        """Return what measures an item of `claim` once its jobs ran.
 705
 706        Its wall (by the group spans it ran in), the items per request it was sent in, its inputs and host memory; the
 707        device memory its requests' backend allocated, per item beyond what stays allocated, where the backend
 708        reported it; and on a `cuda` class the device memory of this worker's processes, read once per claim, its
 709        baseline before the worker's first `cuda` claim.
 710        """
 711        batches = {
 712            m.digest: request_size(g.placement.backend, g.placement.batch_size) for g in groups for m in g.members
 713        }
 714        inputs: dict[str, float | None] = {}
 715        chars: dict[str, int | None] = {}
 716        for member in (m for g in groups for m in g.members):
 717            kind, amount = job_units(member.job)
 718            known, so_far = inputs.get(member.digest, 0.0), chars.get(member.digest, 0)
 719            inputs[member.digest] = amount + known if kind == "audio_s" and known is not None else None
 720            chars[member.digest] = int(amount) + so_far if kind == "chars" and so_far is not None else None
 721        cold = claim.queue.name not in self._warm
 722        device: list[int | None] = []
 723        grant = self.profile.resource_classes.get(class_of(claim.queue.name))
 724        on_device = grant is not None and grant.device == "cuda"
 725        if on_device and self._device_baseline is None:
 726            self._device_baseline = self._device_memory()
 727
 728        def sample(digest: str) -> Sample:
 729            jobs = len(claim.fragments[claim.items.index(digest)].jobs)
 730            current, peak = self._memory()
 731            if on_device and self._device_baseline is not None and not device:
 732                device.append(self._device_memory())
 733            used = device[0] if device else None
 734            requests = [(r.device[0], r.device[1], r.items) for r in spans.requests.get(digest, []) if r.device]
 735            return Sample(
 736                wall_s=spans.walls.get(digest, 0.0),
 737                claim_s=claim_s,
 738                jobs=jobs,
 739                batch_size=min(batches.get(digest, 1), jobs),
 740                input_s=inputs.get(digest),
 741                input_chars=chars.get(digest),
 742                baseline_bytes=self._baseline,
 743                resident_bytes=current,
 744                peak_memory_bytes=peak,
 745                device_baseline_bytes=None if used is None else self._device_baseline,
 746                device_bytes=used,
 747                served=is_service_class(claim.queue.name),
 748                device_item_bytes=max(((p - a) // n for p, a, n in requests), default=None),
 749                device_allocated_bytes=min((a for _, a, _ in requests), default=None),
 750                cold=cold,
 751                job=worker_id(),
 752                ended_s=time.time(),
 753            )
 754
 755        return sample

 758        self, claim: Claim, groups: list["_Group"], spans: "_Spans"
 759    ) -> Callable[[str, Sequence[JobOutcome]], list[Observation]]:
 760        """Return what gives an item of `claim` its `Observation`s once its jobs ran.

 770                seen.append(self._seen(claim))

 780                digest,
 781                spans.requests.get(digest, []),
 782                jobs,
 783                outcomes,
 784                found,
 785                mark=mark,
 786                item_wall_s=self._clock.now() - began,

 801    def _stop_runner(self, runner: threading.Thread, cancelled: threading.Event) -> None:
 802        """Abandon what `runner` still runs and wait for it: `join_s` once halted, else until it stops."""
 803        if not runner.is_alive():
 804            return
 805        cancelled.set()
 806        if runner.ident is not None:
 807            (self._workers if self._workers is not None else process_workers(self.profile)).abandon(runner.ident)
 808        if self.stop.is_set():
 809            runner.join(self.join_s)
 810            return
 811        while runner.is_alive() and not self.stop.is_set():
 812            runner.join(self.profile.pool.poll_s)
 813        if runner.is_alive():
 814            runner.join(self.join_s)

 816    def _commit(
 817        self,
 818        claim: Claim,
 819        batch: list[tuple[Member, JobOutcome | None]],
 820        outcomes: dict[str, dict[int, JobOutcome]],
 821        pending: dict[str, int],
 822        measure: tuple[
 823            Callable[[str], Sample],
 824            Callable[[str, Sequence[JobOutcome]], list[Observation]],
 825            Callable[[str], Sequence[FaultRecord]],
 826        ],
 827    ) -> None:
 828        """Record `batch`'s outcomes; commit each item still held whose every job has one, with what `measure` gives.
 829
 830        `measure` is the item's `Sample`, its `Observation`s given its outcomes, and the worker losses it survived.
 831        The claim's provenance document is replaced before the first of them is committed, so the execution or Reuse
 832        of every job of a committed item is on disk before its outcome is (an item given `dead` because its jobs
 833        cannot be built has none); a failed write is raised and nothing is committed.
 834
 835        An item with a job whose outcome is None (a busy start lease) is released, unreported.
 836        """
 837        busy = {m.digest for m, outcome in batch if outcome is None}
 838        claim.release([d for d in busy if d in claim.items])
 839        for member, outcome in batch:
 840            if outcome is not None:
 841                outcomes[member.digest][member.index] = outcome
 842        ready = [d for d in {m.digest for m, _ in batch} - busy if len(outcomes[d]) == pending[d] and d in claim.items]
 843        if ready:
 844            self._write_provenance(raising=True)
 845        for digest in ready:
 846            done = [outcomes[digest][i] for i in range(pending[digest])]
 847            sample, observe, lost = measure
 848            report(claim, digest, done, sample(digest), observe(digest, done), lost(digest))

 850    def _run_groups(
 851        self, groups: list[_Group], finished: Finished, cancelled: threading.Event, spans: "_Spans"
 852    ) -> None:
 853        """Run each group until `cancelled`, putting its members' outcomes on `finished`; then put None.
 854
 855        Each call of a group's send is given in `spans`, with the requests it made, before the outcomes are put. A
 856        member's outcome is put once, as its request ends when the send emits (`Emit`), else when the group ends.
 857        """
 858        given: set[tuple[str, int]] = set()
 859
 860        def hand(members: Sequence[Member], outcomes: Sequence[JobOutcome | None]) -> None:
 861            fresh = [(m, o) for m, o in zip(members, outcomes, strict=True) if (m.digest, m.index) not in given]
 862            given.update((m.digest, m.index) for m, _ in fresh)
 863            if fresh:
 864                finished.put(fresh)
 865
 866        try:
 867            for group in groups:
 868                send = self._send or functools.partial(self._execute, run=group.run)
 869                owners = {m.job.ref: m.digest for m in group.members}
 870                try:
 871                    outcomes: list[JobOutcome | None] = list(
 872                        run_members(
 873                            group.members,
 874                            group.placement,
 875                            send,
 876                            cancelled,
 877                            lambda sent: spans.add(sent, owners),
 878                            self._clock,
 879                            hand,
 880                        )
 881                    )
 882                except LeaseTimeout as busy:
 883                    logger.info("pool worker %s gives its items back: %s", self.name, busy)
 884                    outcomes = [None] * len(group.members)
 885                except Abandoned as stopped:
 886                    hand(
 887                        [group.members[i] for i in sorted(stopped.kept)],
 888                        [stopped.kept[i] for i in sorted(stopped.kept)],
 889                    )
 890                    raise
 891                hand(group.members, outcomes)
 892        except Abandoned:
 893            logger.info("pool worker %s abandoned the rest of its claim", self.name)
 894        finally:
 895            finished.put(None)

 918    def _groups(self, claim: Claim) -> tuple[list[_Group], dict[str, FaultRecord]]:
 919        """Return the claim's jobs grouped by plan, node and placement, and each item that cannot be built."""
 920        groups: dict[tuple[str, str, str], _Group] = {}
 921        dead: dict[str, FaultRecord] = {}
 922        for digest, fragment in zip(claim.items, claim.fragments, strict=True):
 923            try:
 924                placed, values = self._plan(fragment)
 925                jobs, placement = fragment_jobs(fragment, placed, values)
 926            except Exception as exc:  # noqa: BLE001 - an item that cannot be built fails with what it raised
 927                dead[digest] = failure_of(exc)
 928                continue
 929            keys = fragment_keys(fragment, placed, values)
 930            label = (fragment.plan_hash, fragment.node, fragment.placement.canonical_digest())
 931            run = placed.config or RunConfig(reuse=ReusePolicy(placed.logical.reuse))
 932            group = groups.setdefault(label, _Group(placement, run, []))
 933            group.members.extend(Member(digest, i, j, k) for i, (j, k) in enumerate(zip(jobs, keys, strict=True)))
 934        return list(groups.values()), dead

 986def serve_pool(  # noqa: PLR0913 - the queues and classes, then keyword-only parts and seams
 987    pool_dir: Path,
 988    classes: Sequence[str],
 989    *,
 990    profile: ExecutionProfile,
 991    store: ResultStore,
 992    workers: WorkerSet | None = None,
 993    send: Send | None = None,
 994    join_s: float = DEFAULT_GRACES.bound,
 995    clock: Clock = SystemClock(),  # noqa: B008 - stateless
 996) -> int:
 997    """Serve the queues of `classes` in `pool_dir` (a run's `queues` directory) as one `PoolWorker`; return 0.
 998
 999    The worker runs under a `Supervisor`, so every process it launches, and every orphan they leave, ends with it.
1000    Without `workers`, a worker of service classes runs on a set that provides its servers to this host's registry
1001    (`service_registry`), closed when it returns.
1002    A worker that cannot reach the run directory or the store returns `EXIT_UNREACHABLE` and marks nothing; one that can

527            prefer = None if ended else current

542                if self._serving:

Serve the queues of classes in pool_dir (a run's queues directory) as one PoolWorker; return 0.

The worker runs under a Supervisor, so every process it launches, and every orphan they leave, ends with it. Without workers, a worker of service classes runs on a set that provides its servers to this host's registry (service_registry), closed when it returns. A worker that cannot reach the run directory or the store returns EXIT_UNREACHABLE and marks nothing; one that can marks itself ready (mark_ready, with each queue's HardwareClass and the env of each backend placed on it, built first) once its worker is built and supervised, just before it serves. On the main thread SIGTERM halts the worker (PoolWorker.halt); the previous handler is restored after.
