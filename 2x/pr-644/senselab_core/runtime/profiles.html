senselab_core.runtime.profiles

The execution profile (execution-profile@5) and resolve_execution, which places a task call under it.

A profile holds stack preferences per task, device preference, env roots, the torch index override, the model-source allowlist, the model-cache budget, the retry policy, the network policy, the resource classes, the substrate, the pool, calibration, job leases, fault budgets, worker timeouts and service settings. ExecutionProfile.load deep-merges a user mapping or YAML file over a packaged profile (laptop, slurm) or a profile file of the user's own. A profile is recorded with each result through canonical_digest and never reaches a key.

150class ExecutionProfile(Formatted):
151    """Where and how calls run on one site.
152
153    Attributes:
154        name: The packaged profile this was loaded from, or the file stem of a user profile.
155        stack_preferences: Per task, its stacks best first.
156        devices: Device kinds best first (`cuda`, `mps`, `cpu`).
157        env_roots: Per env kind (`isolated`, `server`), the directory env trees are built under;
158            `${VAR:-fallback}`, then `~` and `$VAR`, are expanded where the root is used.
159        envs: Env settings.
160        model_sources: Allowed hub organisations; None allows those of the catalogue entries.
161        model_cache_budget_bytes: Cap on the model cache; None measures it (`hardware.measured_budget`).
162        retry: How a transient fault is retried.
163        network: `online`, or `offline` to forbid any fetch.
164        resource_classes: The worker classes a node is placed on, by name (`cpu`, `gpu:<type>`, `mps`, `svc:<id>`).
165        substrate: What starts workers: `local` processes or `slurm` jobs.
166        pool: How pool workers claim and yield, and the quantum ceilings.
167        sizing: The fractions and targets a unit's batch, quantum and worker count are derived from (`size`).
168        calibration: How a unit without a measure is probed, where measures are kept and whose are trusted.
169        lease: How a lease is kept alive: its stale bound and renewal share, for job and pool leases alike.
170        faults: The retry budget of each fault class.
171        timeouts: A worker's load and request timeouts.
172        services: When an idle service exits.
173        supervisor: How a supervisor reads a launched process's start time, and reaps.
174        store: How a result store commits and how a storage root's clock is probed.
175        vllm: How a `vllm serve` process is started, polled, asked and stopped.
176        worker: How a worker client starts and watches its worker subprocess.
177    """

210    def check_qos_cap(self, placed: Mapping[str, str]) -> None:
211        """Raise `QosCapTooSmall` for a placed class whose `cpus` exceed the substrate's `qos_cpu_cap`.
212
213        `placed` maps each node to the resource class it is placed on; the error names the first such node.
214        """
215        cap = self.substrate.qos_cpu_cap
216        for node, name in placed.items():
217            grant = self.resource_classes.get(name)
218            if cap is not None and grant is not None and grant.cpus is not None and grant.cpus > cap:
219                raise QosCapTooSmall(name, grant.cpus, cap, node)

227    @classmethod
228    def load(
229        cls, source: str | Path = DEFAULT_PROFILE, override: Mapping[str, Any] | Path | None = None
230    ) -> "ExecutionProfile":
231        """Return the profile `source` names with `override` (a mapping or a YAML file) deep-merged over it.
232
233        `source` is a packaged profile name (`laptop`, `slurm`), or a path to a profile file holding a whole profile.
234
235        Raises:
236            FileNotFoundError: `source` is neither a packaged profile nor a file.
237            IncompleteProfile: the merged mapping lacks keys, as a partial file passed as a profile does.
238            ProfileFormatRetired: the merged mapping declares a retired format.
239            UnfilledProfile: a value is still a `<fill: ...>` placeholder.
240            UnknownProfileKey: a key of `override` that the format does not define, naming the closest one.
241            LeaseBoundError: two of the lease's beat intervals plus its attribute delay are not below its stale bound.
242            ValueError: the merged mapping is invalid.
243        """
244        packaged = _read(_profile_source(source))
245        extra = override if isinstance(override, Mapping) else _read(override) if override is not None else {}
246        merged = merge_over(packaged, extra)
247        if check(EXECUTION_PROFILE_FORMAT, merged.get("format"), RETIRED_EXECUTION_PROFILE_FORMATS) is (
248            FormatVerdict.RETIRED
249        ):
250            raise ProfileFormatRetired(str(merged.get("format")))
251        missing = [k for k, f in cls.model_fields.items() if f.is_required() and k not in merged]
252        if missing:
253            raise IncompleteProfile(os.fspath(source), missing)
254        unfilled = _unfilled(merged)
255        if unfilled:
256            raise UnfilledProfile(str(merged.get("name", source)), unfilled)
257        _check_keys(merged, cls.model_fields)
258        profile = cls.model_validate(merged)
259        profile.lease.check_bound()
260        return profile

311def _profile_source(source: str | Path) -> Any:  # noqa: ANN401 - a Path or a package resource
312    """Return where profile `source` is read from: a path when it looks like one, else a packaged profile."""
313    text = os.fspath(source)
314    if isinstance(source, Path) or os.sep in text or text.endswith(_PROFILE_SUFFIXES):
315        if not Path(text).is_file():
316            raise FileNotFoundError(f"{text}: not a profile file")
317        return Path(text)
318    if text not in packaged_profiles():
319        raise FileNotFoundError(f"{text!r} is neither a packaged profile {list(packaged_profiles())} nor a file path")
320    return resources.files("senselab_core.runtime").joinpath("data", "profiles", f"{text}.yaml")

323def _unfilled(node: Any, path: str = "") -> dict[str, str]:  # noqa: ANN401 - any YAML node
324    """Return each `<fill: what>` string under `node` by its key path, with `what`."""
325    if isinstance(node, str):
326        found = _UNFILLED.match(node)
327        return {path: found[1]} if found else {}
328    if isinstance(node, Mapping):
329        return {
330            k: v
331            for key, item in node.items()
332            for k, v in _unfilled(item, f"{path}.{key}" if path else str(key)).items()
333        }
334    if isinstance(node, list):
335        return {k: v for i, item in enumerate(node) for k, v in _unfilled(item, f"{path}[{i}]").items()}
336    return {}

357def _check_keys(mapping: Mapping[str, Any], fields: Mapping[str, object], path: str = "") -> None:
358    known = list(fields)
359    for key, value in mapping.items():
360        if key not in known:
361            close = difflib.get_close_matches(str(key), known, n=1)
362            hint = f"did you mean {close[0]!r}?" if close else f"known keys: {known}"
363            raise UnknownProfileKey(f"unknown profile key {path + str(key)!r}; {hint}")
364        if path or not isinstance(value, Mapping):
365            continue
366        if key in _SECTIONS:
367            _check_keys(value, _SECTIONS[key].model_fields, f"{key}.")
368        elif key == "resource_classes":
369            for name, given in value.items():
370                if isinstance(given, Mapping):
371                    _check_keys(given, ResourceClass.model_fields, f"resource_classes.{name}.")

374def _has(resource: ResourceClass, hardware: HardwareInfo) -> bool:
375    if resource.device == "cpu":
376        return True
377    if resource.device == "mps":
378        return hardware.apple_silicon
379    wanted = resource.gpu_type
380    return any(wanted is None or wanted.lower() in g.name.lower() for g in hardware.gpus)

383def resource_class(
384    backend: BackendSpec, profile: ExecutionProfile, hardware: HardwareInfo | None
385) -> tuple[str, ResourceClass] | None:
386    """Return the first resource class of `profile` that runs `backend`, by name, or None.
387
388    Devices are taken in `profile.devices` order and classes in profile order; a class runs the backend when the
389    backend declares its device and, with `hardware` given, this host has that device (and GPU type). With
390    `hardware` None the class is not judged against this host, as when a scheduler places the worker. A server
391    backend takes a service class (`svc:<id>`) that runs it before any other class, so its consumers share one
392    registered server; no other backend is placed on a service class.
393    """
394    server = backend.env.kind == "server"
395    for services in (True, False) if server else (False,):
396        for device in profile.devices:
397            if device not in backend.devices:
398                continue
399            for name, resource in profile.resource_classes.items():
400                runs = resource.device == device and (hardware is None or _has(resource, hardware))
401                if runs and is_service_class(name) == services:
402                    return name, resource
403    return None

410def _chosen(
411    task: TaskSpec, model_entry: CatalogueEntry | None, profile: ExecutionProfile, registry: Registry
412) -> tuple[BackendSpec, bool]:
413    served = [
414        b
415        for b in registry.backends(task.name)
416        if model_entry is None
417        or (
418            b.name in model_entry.backends
419            and b.stack in model_entry.stacks
420            and model_entry.id in (b.models or (model_entry.id,))
421        )
422    ]
423    wanted = profile.stack_preferences.get(task.name, ())
424    candidates = [b for s in wanted for b in served if b.stack == s] if wanted else served
425    if not candidates:
426        raise NoBackend(
427            f"no backend of task {task.name!r} serves model {model_entry.id if model_entry else None!r} on stacks "
428            f"{list(wanted) or 'any'}; available: {sorted({b.stack for b in served})}"
429        )
430    return candidates[0], bool(wanted)

433def resolve_execution(  # noqa: PLR0913 - the brief fixes the signature and the allowlist needs the catalogue
434    task: TaskSpec,
435    model_entry: CatalogueEntry | None,
436    profile: ExecutionProfile,
437    hardware: HardwareInfo | None,
438    registry: Registry,
439    catalogue: Catalogue,
440) -> Placement:
441    """Return where `task` runs under `profile`: backend (hence stack and env), resource class, device and partition.
442
443    The first stack of `profile.stack_preferences[task.name]` with a backend serving `model_entry` wins, or the
444    first declared backend when the profile lists none. The resource class is `resource_class`'s, judged against
445    `hardware` (None when a scheduler places the worker); the device is the class's. The batch size is 1: `size`
446    sizes it from an estimate where the work runs.
447
448    Raises:
449        UnlistedSource: the model's organisation is neither in `model_sources` nor, when that is None, in `catalogue`.
450        NoBackend: no backend serves the task and model under the preferences.
451        NoDevice: no resource class runs the chosen backend here; names the host, never falls back to another device.
452    """
453    if model_entry is not None:
454        profile.check_source(model_entry.id, catalogue)
455    backend, preferred = _chosen(task, model_entry, profile, registry)
456    chosen = resource_class(backend, profile, hardware)
457    if chosen is None:
458        here = "" if hardware is None else f" and node {platform.node()!r} has {_host_devices(hardware)}"
459        raise NoDevice(
460            f"backend {backend.name!r} of {task.name!r} runs on {list(backend.devices)}; profile {profile.name!r} "
461            f"lists devices {list(profile.devices)} and resource classes {sorted(profile.resource_classes)}{here}"
462        )
463    name, resource = chosen
464    why = f"stack {backend.stack!r} " + (f"preferred by profile {profile.name!r}" if preferred else "first declared")
465    return Placement(
466        backend=backend,
467        backend_params=backend.params(),
468        device=resource.device,
469        why=f"{why}; resource class {name!r} is the first that runs it",
470        resource_class=name,
471        partition=resource.partition,
472    )

396    for services in (True, False) if server else (False,):
397        for device in profile.devices:
398            if device not in backend.devices:
399                continue
400            for name, resource in profile.resource_classes.items():
401                runs = resource.device == device and (hardware is None or _has(resource, hardware))
402                if runs and is_service_class(name) == services:
403                    return name, resource
404    return None

Return the first resource class of profile that runs backend, by name, or None.

Devices are taken in profile.devices order and classes in profile order; a class runs the backend when the backend declares its device and, with hardware given, this host has that device (and GPU type). With hardware None the class is not judged against this host, as when a scheduler places the worker. A server backend takes a service class (svc:<id>) that runs it before any other class, so its consumers share one registered server; no other backend is placed on a service class.
