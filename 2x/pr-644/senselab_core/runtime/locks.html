senselab_core.runtime.locks

A lease on a resource in a shared directory: a directory taken by mkdir and renewed by beats (ADR-003).

Lease over a resource <dir>/<name> is the directory <name>.lease, which holds one directory named by its holder's uuid token. Every operation is relative to the directory's descriptor, never follows a symlink, and stays inside <dir>; no file is written under the lease:

  • take: mkdir <name>.lease, which fails if anything is at the name, so one taker wins; then mkdir <name>.lease/<token>. An EEXIST on the token is this holder's own (a lost NFS reply). A taker that finds another token beside its own withdraws, and removes the lease directory if that leaves it empty, so two takers that both withdraw leave nothing at the name. A taker checks its token afresh after the take.
  • renew: keep_alive runs a renewer thread, owned by the lease and independent of the work, that creates <token>/beat-<n+1> and removes <token>/beat-<n> on a cadence of renew_fraction × stale_after, so the storage stamps <token>/ at each beat. A beat that finds the lease gone (ENOENT, or ESTALE on NFS), or a renewer that ends for any other reason, marks its LeaseState lost.
  • prove: before committing anything under the lease, a holder calls prove, a mkdir in its token directory that the storage answers itself.
  • judge: a lease's age is the storage clock (StorageDir.dir_now) less the newest mtime of <name>.lease and its tokens, read by a fresh lstat; a lease is broken only when that age, read after a fresh clock probe, passes stale_after. Anything but a directory at the name is moved aside (quarantined).
  • break and release: the breaker or releaser claims the lease by renaming an entry inside it: its token to gone-<token>, or, in a lease with no token, another entry (a dead claimant's) to claim-<uuid4>. An entry is one directory's, so one claim succeeds, and only the claimant renames <name>.lease to a fresh uuid name beside it and removes it. A lease with no entry is removed by rmdir, which fails once a taker's token is in it; one that cannot be listed is not broken. A holder whose token was claimed learns it at its next beat, owns or prove.

Every wait ends at timeout in LeaseTimeout. The lease is an efficiency hint: what it guards stays correct by idempotence, not by the lease.

128class Lease:
129    """A lease over the resource `path`, held for the duration of a `with` block.
130
131    Args:
132        path: The resource being guarded (not the lease itself).
133        settings: The profile's lease section; None reads the packaged profile's.
134        timeout: Seconds a wait in `__enter__` may take before `LeaseTimeout`; not negative; None is `settings.wait_s`.
135        stale_after: Seconds on the storage clock after which another taker breaks the lease; None is
136            `settings.stale_after_s`.
137        mode: The mode of the lease directory and of the token directory; None is `settings.mode`.
138        directory: The directory holding `path`, already open; it is duplicated and `path`'s parent is not
139            opened again.
140        clock: How the lease reads monotonic time and the storage clock, and waits.
141
142    Attributes:
143        broke: The stale leases this lease broke before it was taken (`BrokenLease`).
144        set_aside: The paths this lease moved aside: objects of the wrong kind at its name.
145    """
146
147    def __init__(  # noqa: PLR0913 - the resource and its five keyword-only settings
148        self,
149        path: Path,
150        *,
151        settings: Optional[JobLease] = None,
152        timeout: Optional[float] = None,
153        stale_after: Optional[float] = None,
154        mode: Optional[int] = None,
155        directory: Optional[StorageDir] = None,
156        clock: Clock = SystemClock(),  # noqa: B008 - stateless
157    ) -> None:
158        """Configure a lease over `path` without taking it.
159
160        Raises:
161            ValueError: `timeout` or `stale_after` is negative, or `path`'s name or its lease's is not one component.
162        """
163        if settings is None:
164            from senselab_core.runtime.profiles import ExecutionProfile  # noqa: PLC0415 - profiles import this module
165
166            settings = ExecutionProfile.packaged().lease
167        timeout = settings.wait_s if timeout is None else timeout
168        stale_after = settings.stale_after_s if stale_after is None else stale_after
169        if timeout < 0 or stale_after < 0:
170            raise ValueError(f"a lease's timeout and stale_after are not negative (got {timeout}, {stale_after})")
171        self._path = Path(path)
172        self._name = path_component(path_component(self._path.name) + LEASE_SUFFIX)
173        self._lease_path = self._path.with_name(self._name)
174        self._timeout = timeout
175        self._stale_after = stale_after
176        self._mode = settings.mode if mode is None else mode
177        self._settings = settings
178        self._given = directory
179        self._time = clock
180        self._dir: Optional[StorageDir] = None
181        self._held: Optional[str] = None
182        self._probe: Optional[tuple[float, float]] = None
183        self._renewer: Optional[tuple[threading.Thread, threading.Event, float]] = None
184        self.broke: list[BrokenLease] = []
185        self.set_aside: list[Path] = []

187    @property
188    def path(self) -> Path:
189        """The lease directory."""
190        return self._lease_path
191
192    def _directory(self) -> StorageDir:
193        if self._dir is None:
194            self._dir = self._given.dup() if self._given is not None else StorageDir.open_root(self._path.parent)
195        return self._dir
196
197    def _now(self, *, fresh: bool) -> float:
198        """Return the storage clock: probed now when `fresh`, else the last probe plus the monotonic time since."""
199        if fresh or self._probe is None:
200            self._probe = (self._time.storage_now(self._directory()), self._time.now())
201        return self._probe[0] + self._time.now() - self._probe[1]
202
203    def _listing(self) -> Optional[tuple[dict[str, float], Optional[dict[str, float]]]]:
204        """Return the mtime of each token directory in the lease and of each other entry; None if the lease is gone.
205
206        The other entries are None when the lease cannot be listed.
207        """
208        try:
209            with self._directory().child(self._name) as lease:
210                found = {n: _lstat_or_gone(lease, n) for n in lease.listdir()}
211        except (FileNotFoundError, WrongKindError):
212            return None
213        except PermissionError:
214            return {}, None
215        except OSError as err:
216            if err.errno in GONE_ERRNOS:
217                return None
218            raise
219        tokens = {
220            n: st.st_mtime
221            for n, st in found.items()
222            if st is not None and UUID_HEX.fullmatch(n) and stat.S_ISDIR(st.st_mode)
223        }
224        return tokens, {n: st.st_mtime for n, st in found.items() if st is not None and n not in tokens}
225
226    def _seen(self) -> Optional[tuple[frozenset[str], float, Optional[frozenset[str]]]]:
227        """Return the lease's tokens, the newest mtime of it, its tokens and claims, and its other entries.
228
229        None when no lease is at the name. The lease is read again after its entries, so a claim renamed inside it
230        meanwhile shows in its mtime. The other entries are None when the lease cannot be listed. Anything but a
231        directory at the name is moved aside.
232        """
233        directory = self._directory()
234        st = _lstat_or_gone(directory, self._name)
235        if st is None:
236            return None
237        if not stat.S_ISDIR(st.st_mode):
238            self.set_aside.append(directory.set_aside(self._name, None))
239            logger.warning("lease %s: moved an object of the wrong kind aside", self._lease_path)
240            return None
241        listing = self._listing()
242        if listing is None:
243            return None
244        tokens, others = listing
245        after = _lstat_or_gone(directory, self._name)
246        if after is None:
247            return None
248        claims = [m for n, m in (others or {}).items() if GONE_NAME.fullmatch(n) or CLAIM_NAME.fullmatch(n)]
249        newest = max([st.st_mtime, after.st_mtime, *tokens.values(), *claims])
250        return frozenset(tokens), newest, None if others is None else frozenset(others)
251
252    def _remove(self, aside: str) -> None:
253        """Remove the moved lease `aside`, again while a taker that reached it before the move races the removal."""
254        directory = self._directory()
255        failure: Optional[OSError] = None
256        for _ in range(self._settings.remove_attempts):
257            try:
258                directory.remove_owned(aside, pattern=UUID_HEX)
259            except OSError as err:
260                failure = err
261            if _lstat_or_gone(directory, aside) is None:
262                return
263        self.set_aside.append(directory.path / aside)
264        logger.warning("lease %s: moved aside to %s, which cannot be removed: %s", self._lease_path, aside, failure)
265
266    def _break(self, tokens: frozenset[str], others: Optional[frozenset[str]]) -> bool:
267        """Claim the lease holding `tokens` (or, with none, the entries `others`), move it aside and remove it.
268
269        Returns whether this caller removed it. The caller first claims the lease by renaming one entry inside it:
270        its first token to `gone-<token>`, or, with no token, another entry (a dead claimant's `gone-<token>`, a
271        `claim-` entry only when there is no other) to `claim-<uuid4>`. The entry is stamped before the rename and
272        again after, so a judge that lists the lease at any point of the claim ages it as fresh. An entry name is one
273        directory's, so of all callers that judged the lease only one claim succeeds, and only the claimant moves
274        `<name>.lease`. A further token is claimed too; it cannot be a live holder's, since the lease's age is the
275        newest of its tokens' and it was judged stale. A lease with no entry at all is removed by `rmdir`, which
276        succeeds only while it is empty; so is a lease that cannot be listed, as a crash between its `mkdir` and its
277        mode change leaves it.
278
279        Raises:
280            LeaseUnavailable: the lease holds entries and cannot be listed, so it cannot be claimed.
281        """
282        if others is None:
283            return self._remove_unlistable()
284        if not tokens and not others:
285            return self._remove_empty()
286        claims = [(t, GONE_PREFIX + t, GONE_NAME) for t in sorted(tokens)] or [
287            (
288                min(others, key=lambda n: (bool(CLAIM_NAME.fullmatch(n)), n)),
289                f"{CLAIM_PREFIX}{uuid.uuid4().hex}",
290                CLAIM_NAME,
291            )
292        ]
293        claimed = self._claim(claims)
294        if claimed is None:
295            return False
296        directory = self._directory()
297        current = _lstat_or_gone(directory, self._name)
298        if current is None or (current.st_dev, current.st_ino) != (claimed.st_dev, claimed.st_ino):
299            logger.warning("lease %s: claimed, then found another directory at its name", self._lease_path)
300            return False
301        aside = uuid.uuid4().hex
302        try:
303            directory.rename(self._name, directory, aside, grammar=UUID_HEX)
304        except OSError as err:
305            if err.errno in GONE_ERRNOS:
306                return False
307            raise
308        self._remove(aside)
309        return True
310
311    def _claim(self, claims: list[tuple[str, str, re.Pattern[str]]]) -> Optional[os.stat_result]:
312        """Rename each `(entry, claim)` in the lease, the first deciding; return the claimed lease's stat, else None."""
313        try:
314            with self._directory().child(self._name) as lease:
315                (name, claim, grammar), *rest = claims
316                with contextlib.suppress(OSError):
317                    lease.stamp(name)
318                lease.rename(name, lease, claim, grammar=grammar)
319                with contextlib.suppress(OSError):
320                    lease.stamp(claim)
321                for name, claim, grammar in rest:
322                    with contextlib.suppress(OSError):
323                        lease.rename(name, lease, claim, grammar=grammar)
324                return os.fstat(lease.fd)
325        except WrongKindError:
326            return None
327        except OSError as err:
328            if err.errno in CLAIM_LOST_ERRNOS:
329                return None
330            raise

332    def _remove_unlistable(self) -> bool:
333        """Remove a lease this caller cannot list by `rmdir`, which succeeds only while it is empty.
334
335        Raises:
336            LeaseUnavailable: it is still there, so it holds entries and cannot be claimed.
337        """
338        if self._remove_empty():
339            return True
340        if _lstat_or_gone(self._directory(), self._name) is None:
341            return False
342        raise LeaseUnavailable(
343            self._lease_path,
344            f"{self._lease_path} is stale, holds entries and cannot be listed, so it cannot be claimed; "
345            f"{owner_remedy(self._lease_path)}",
346        )
347
348    def _remove_empty(self) -> bool:
349        """Remove the lease by `rmdir`, which succeeds only while it holds nothing; return whether it did."""
350        try:
351            self._directory().remove_dir(self._name, grammar=LEASE_NAME)
352        except OSError as err:
353            if err.errno in (*GONE_ERRNOS, errno.ENOTEMPTY, errno.EEXIST):
354                return False
355            raise
356        return True

358    def _judge(self) -> None:
359        """Clear the lease name if what is there is of the wrong kind or a stale lease."""
360        try:
361            seen = self._seen()
362            if seen is None or self._now(fresh=False) - seen[1] <= self._stale_after:
363                return
364            now = self._now(fresh=True)
365            seen = self._seen()
366            if seen is None or now - seen[1] <= self._stale_after:
367                return
368            judged = seen[0]
369            if self._break(judged, seen[2]):
370                self.broke.append(BrokenLease(self._lease_path, now - seen[1], tuple(sorted(judged))))
371                logger.warning(
372                    "lease %s: broke a stale lease %.1fs old (> %.1fs), held by %s",
373                    self._lease_path,
374                    now - seen[1],
375                    self._stale_after,
376                    ", ".join(sorted(judged)) or "no token",
377                )
378        except (WrongKindError, PermissionError) as err:
379            raise LeaseUnavailable(
380                self._lease_path,
381                f"{self._lease_path} is stale or of the wrong kind and cannot be judged or moved ({err}); "
382                f"{owner_remedy(self._lease_path)}",
383            ) from err
384
385    def _try_take(self) -> Optional[str]:
386        """Make the lease directory and this holder's token in it; return the token, None if another holds it."""
387        directory = self._directory()
388        try:
389            directory.make_dir(self._name, grammar=LEASE_NAME, mode=self._mode)
390        except (FileExistsError, FileNotFoundError):
391            return None
392        except PermissionError as err:
393            raise LeaseUnavailable(
394                self._lease_path,
395                f"cannot take the lease {self._lease_path}: {err.strerror}; {owner_remedy(directory.path)}",
396            ) from err
397        token = uuid.uuid4().hex
398        try:
399            with directory.child(self._name) as lease:
400                lease.make_dir(token, grammar=UUID_HEX, mode=self._mode, exist_ok=True)
401                if any(t != token and UUID_HEX.fullmatch(t) for t in lease.listdir()):
402                    lease.remove_dir(token, grammar=UUID_HEX)
403                    with contextlib.suppress(OSError):
404                        directory.remove_dir(self._name, grammar=LEASE_NAME)
405                    return None
406        except (FileNotFoundError, WrongKindError):
407            return None
408        except OSError as err:
409            if err.errno not in GONE_ERRNOS:
410                raise
411            self._withdraw(token)
412            return None
413        return token if self._has(token) else None
414
415    def _withdraw(self, token: str) -> None:
416        """Remove `token` and then the lease, each only if it is still there and the lease holds nothing else."""
417        directory = self._directory()
418        with contextlib.suppress(OSError, WrongKindError), directory.child(self._name) as lease:
419            lease.remove_dir(token, grammar=UUID_HEX)
420        with contextlib.suppress(OSError):
421            directory.remove_dir(self._name, grammar=LEASE_NAME)
422
423    def holder(self) -> Optional[dict[str, Any]]:
424        """Return the token and owning user of the lease's token directory, None if no token is there."""
425        try:
426            with self._directory().child(self._name) as lease:
427                for token in sorted(t for t in lease.listdir() if UUID_HEX.fullmatch(t)):
428                    st = lease.lstat(token)
429                    if st is not None:
430                        return {"token": token, "user": _user(st.st_uid)}
431        except (OSError, WrongKindError):
432            return None
433        return None

435    def age(self) -> Optional[float]:
436        """Return the lease's age on a freshly probed storage clock, as a breaker judges it; None when none is held.
437
438        Anything but a directory at the lease name is moved aside, as a breaker would.
439        """
440        try:
441            seen = self._seen()
442            return None if seen is None else self._now(fresh=True) - seen[1]
443        finally:
444            self._close()

446    def owns(self) -> bool:
447        """Return whether this lease's token directory is in the directory at the lease name."""
448        return self._held is not None and self._has(self._held)

450    def _has(self, token: str) -> bool:
451        try:
452            with self._directory().child(self._name) as lease:
453                return lease.kind(token) == "directory"
454        except WrongKindError:
455            return False
456        except OSError as err:
457            if err.errno in GONE_ERRNOS:
458                return False
459            raise

461    def prove(self) -> bool:
462        """Return whether this lease is still held, proven by a `mkdir` (and `rmdir`) in its token directory.
463
464        A `mkdir` is answered by the storage itself, never from a client's attribute cache, so a holder calls this
465        immediately before it commits anything under the lease; False means the lease was lost.
466        """
467        if self._held is None:
468            return False
469        proof = f"proof-{uuid.uuid4().hex}"
470        try:
471            with self._directory().child(self._name) as lease, lease.child(self._held) as mine:
472                mine.make_dir(proof, grammar=PROOF_NAME, exist_ok=True)
473                with contextlib.suppress(OSError):
474                    mine.remove_dir(proof, grammar=PROOF_NAME)
475        except WrongKindError:
476            return False
477        except OSError as err:
478            if err.errno in GONE_ERRNOS:
479                return False
480            raise
481        return True

483    @contextlib.contextmanager
484    def keep_alive(self, renew_fraction: float) -> Iterator[LeaseState]:
485        """Renew the held lease every `renew_fraction × stale_after` seconds from a daemon thread until the block ends.
486
487        Raises:
488            ValueError: `renew_fraction` is not in (0, 1).
489            RuntimeError: the lease is not held, or is already kept alive.
490        """
491        if not 0 < renew_fraction < 1:
492            raise ValueError(f"a renew fraction is in (0, 1) (got {renew_fraction})")
493        if self._held is None or self._renewer is not None:
494            raise RuntimeError(f"lease {self._lease_path}: keep_alive needs a held lease without a renewer")
495        lost, stop = threading.Event(), threading.Event()
496        state = LeaseState(lost)
497        interval = renew_fraction * self._stale_after
498        thread = threading.Thread(
499            target=self._renew,
500            args=(self._directory().dup(), self._held, interval, state, lost, stop),
501            name=RENEWER_PREFIX + self._name,
502            daemon=True,
503        )
504        self._renewer = (thread, stop, interval)
505        thread.start()
506        try:
507            yield state
508        finally:
509            self._stop_renewer()
510
511    def _stop_renewer(self) -> None:
512        """Stop the renewer and wait for it for one interval; one held in a hung beat is left to end on its own."""
513        renewer, self._renewer = self._renewer, None
514        if renewer is not None:
515            thread, stop, interval = renewer
516            stop.set()
517            thread.join(interval)
518            if thread.is_alive():
519                logger.warning("lease %s: its renewer is still in a beat; it ends when the beat returns", self._name)

521    def _beat(self, directory: StorageDir, token: str, n: int) -> None:
522        """Make `beat-<n+1>` in this holder's token directory, reached afresh, and remove `beat-<n>`."""
523        with directory.child(self._name) as lease, lease.child(token) as mine:
524            mine.make_dir(f"beat-{n + 1}", grammar=BEAT_NAME, exist_ok=True)
525            if n:
526                with contextlib.suppress(FileNotFoundError):
527                    mine.remove_dir(f"beat-{n}", grammar=BEAT_NAME)

529    def _renew(  # noqa: PLR0913 - its own directory handle, the token, the interval, the state and its two events
530        self,
531        directory: StorageDir,
532        token: str,
533        interval: float,
534        state: LeaseState,
535        lost: threading.Event,
536        stop: threading.Event,
537    ) -> None:
538        """Beat every `interval` seconds until `stop`; a lease found gone, or unrenewed past its bound, is lost.
539
540        Each beat is due `interval` after the last one was due, whatever the beats took, and a beat that is already
541        overdue runs at once. The renewer marks the lease lost whenever it ends for any reason but `stop`.
542        """
543        last = due = self._time.now()
544        try:
545            while True:
546                due += interval
547                if self._time.wait(stop, max(0.0, due - self._time.now())):
548                    return
549                try:
550                    self._beat(directory, token, state.beats)
551                except WrongKindError:
552                    logger.warning("lease %s: was broken while held; its holder stops", self._lease_path)
553                    return
554                except OSError as err:
555                    if err.errno in GONE_ERRNOS:
556                        logger.warning("lease %s: was broken while held; its holder stops", self._lease_path)
557                        return
558                    logger.warning("lease %s: a beat failed: %s", self._lease_path, err)
559                    if self._time.now() - last > self._stale_after:
560                        return
561                    continue
562                state.beats += 1
563                last = self._time.now()
564                due = max(due, last - interval)
565        except Exception:
566            logger.exception("lease %s: the renewer failed; the lease is lost", self._lease_path)
567        finally:
568            directory.close()
569            if not stop.is_set():
570                lost.set()
571
572    def __enter__(self) -> "Lease":
573        """Take the lease, breaking a stale one and moving a wrong kind aside.
574
575        Raises:
576            LeaseTimeout: a live lease was held for the whole `timeout`.
577            LeaseUnavailable: a lease cannot be created in the directory, or a stale or wrong-kind object at
578                the lease name cannot be moved.
579            StorageUnsupported: the directory has no atomic `mkdir`.
580        """
581        self.broke, self.set_aside, self._probe = [], [], None
582        deadline = self._time.now() + self._timeout
583        try:
584            while True:
585                self._judge()
586                self._held = self._try_take()
587                if self._held is not None:
588                    return self
589                if self._time.now() >= deadline:
590                    raise LeaseTimeout(
591                        f"Timed out after {self._timeout:.1f}s waiting for the lease {self._lease_path}, "
592                        f"held by {self.holder() or 'an unknown holder'}; it is broken once older than "
593                        f"{self._stale_after:.1f}s on the storage clock"
594                    )
595                self._time.sleep(min(self._settings.poll_s, max(0.0, deadline - self._time.now())))
596        except BaseException:
597            self._close()
598            raise
599
600    def __exit__(self, *exc: object) -> None:
601        """Stop the renewer and release the lease if this lease still holds it; one broken while held is logged."""
602        try:
603            self._stop_renewer()
604            token = self._held
605            if token is not None and not self._break(frozenset({token}), frozenset()):
606                logger.warning("lease %s: was broken while held; the work it guarded may run twice", self._lease_path)
607        finally:
608            self._held = None
609            self._close()

611    def _close(self) -> None:
612        directory, self._dir = self._dir, None
613        if directory is not None:
614            directory.close()

267    def _break(self, tokens: frozenset[str], others: Optional[frozenset[str]]) -> bool:
268        """Claim the lease holding `tokens` (or, with none, the entries `others`), move it aside and remove it.
269
270        Returns whether this caller removed it. The caller first claims the lease by renaming one entry inside it:
271        its first token to `gone-<token>`, or, with no token, another entry (a dead claimant's `gone-<token>`, a
272        `claim-` entry only when there is no other) to `claim-<uuid4>`. The entry is stamped before the rename and
273        again after, so a judge that lists the lease at any point of the claim ages it as fresh. An entry name is one
274        directory's, so of all callers that judged the lease only one claim succeeds, and only the claimant moves
275        `<name>.lease`. A further token is claimed too; it cannot be a live holder's, since the lease's age is the
276        newest of its tokens' and it was judged stale. A lease with no entry at all is removed by `rmdir`, which
277        succeeds only while it is empty; so is a lease that cannot be listed, as a crash between its `mkdir` and its
278        mode change leaves it.
279
280        Raises:
281            LeaseUnavailable: the lease holds entries and cannot be listed, so it cannot be claimed.
282        """
283        if others is None:
284            return self._remove_unlistable()
285        if not tokens and not others:
286            return self._remove_empty()
287        claims = [(t, GONE_PREFIX + t, GONE_NAME) for t in sorted(tokens)] or [
288            (
289                min(others, key=lambda n: (bool(CLAIM_NAME.fullmatch(n)), n)),
290                f"{CLAIM_PREFIX}{uuid.uuid4().hex}",
291                CLAIM_NAME,
292            )
293        ]
294        claimed = self._claim(claims)
295        if claimed is None:
296            return False
297        directory = self._directory()
298        current = _lstat_or_gone(directory, self._name)
299        if current is None or (current.st_dev, current.st_ino) != (claimed.st_dev, claimed.st_ino):
300            logger.warning("lease %s: claimed, then found another directory at its name", self._lease_path)
301            return False
302        aside = uuid.uuid4().hex
303        try:
304            directory.rename(self._name, directory, aside, grammar=UUID_HEX)
305        except OSError as err:
306            if err.errno in GONE_ERRNOS:
307                return False
308            raise
309        self._remove(aside)
310        return True

494        if self._held is None or self._renewer is not None:

498        interval = renew_fraction * self._stale_after
499        thread = threading.Thread(

502            name=RENEWER_PREFIX + self._name,
503            daemon=True,
504        )

523        """Make `beat-<n+1>` in this holder's token directory, reached afresh, and remove `beat-<n>`."""
524        with directory.child(self._name) as lease, lease.child(token) as mine:

530    def _renew(  # noqa: PLR0913 - its own directory handle, the token, the interval, the state and its two events
531        self,
532        directory: StorageDir,
533        token: str,
534        interval: float,
535        state: LeaseState,
536        lost: threading.Event,
537        stop: threading.Event,
538    ) -> None:
539        """Beat every `interval` seconds until `stop`; a lease found gone, or unrenewed past its bound, is lost.
540
541        Each beat is due `interval` after the last one was due, whatever the beats took, and a beat that is already
542        overdue runs at once. The renewer marks the lease lost whenever it ends for any reason but `stop`.
543        """
544        last = due = self._time.now()
545        try:
546            while True:
547                due += interval
548                if self._time.wait(stop, max(0.0, due - self._time.now())):
549                    return
550                try:
551                    self._beat(directory, token, state.beats)
552                except WrongKindError:
553                    logger.warning("lease %s: was broken while held; its holder stops", self._lease_path)
554                    return
555                except OSError as err:
556                    if err.errno in GONE_ERRNOS:
557                        logger.warning("lease %s: was broken while held; its holder stops", self._lease_path)
558                        return
559                    logger.warning("lease %s: a beat failed: %s", self._lease_path, err)
560                    if self._time.now() - last > self._stale_after:
561                        return
562                    continue
563                state.beats += 1
564                last = self._time.now()
565                due = max(due, last - interval)
566        except Exception:
567            logger.exception("lease %s: the renewer failed; the lease is lost", self._lease_path)
568        finally:
569            directory.close()
570            if not stop.is_set():
571                lost.set()

573    def __enter__(self) -> "Lease":
574        """Take the lease, breaking a stale one and moving a wrong kind aside.
575
576        Raises:
577            LeaseTimeout: a live lease was held for the whole `timeout`.
578            LeaseUnavailable: a lease cannot be created in the directory, or a stale or wrong-kind object at
579                the lease name cannot be moved.
580            StorageUnsupported: the directory has no atomic `mkdir`.
581        """
582        self.broke, self.set_aside, self._probe = [], [], None
583        deadline = self._time.now() + self._timeout
584        try:
585            while True:
586                self._judge()
587                self._held = self._try_take()
588                if self._held is not None:
589                    return self
590                if self._time.now() >= deadline:
591                    raise LeaseTimeout(
592                        f"Timed out after {self._timeout:.1f}s waiting for the lease {self._lease_path}, "
593                        f"held by {self.holder() or 'an unknown holder'}; it is broken once older than "
594                        f"{self._stale_after:.1f}s on the storage clock"
595                    )
596                self._time.sleep(min(self._settings.poll_s, max(0.0, deadline - self._time.now())))
597        except BaseException:
598            self._close()
599            raise

485    def keep_alive(self, renew_fraction: float) -> Iterator[LeaseState]:
486        """Renew the held lease every `renew_fraction × stale_after` seconds from a daemon thread until the block ends.
487
488        Raises:

490            RuntimeError: the lease is not held, or is already kept alive.
491        """
492        if not 0 < renew_fraction < 1:
493            raise ValueError(f"a renew fraction is in (0, 1) (got {renew_fraction})")
