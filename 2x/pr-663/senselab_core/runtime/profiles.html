senselab_core.runtime.profiles

The execution profile (execution-profile@6) and resolve_execution, which places a task call under it.

A profile holds stack preferences per task, device preference, env roots, the torch index override, the model-source allowlist, the model-cache budget, the retry policy, the network policy, the resource classes, the substrate, the pool, calibration, job leases, fault budgets, worker timeouts and service settings. ExecutionProfile.load deep-merges a user mapping or YAML file over a packaged profile (laptop, slurm) or a profile file of the user's own. A profile is recorded with each result through canonical_digest and never reaches a key.

185        name: The packaged profile this was loaded from, or the file stem of a user profile.
186        stack_preferences: Per task, its stacks best first.
187        devices: Device kinds best first (`cuda`, `mps`, `cpu`).
188        env_roots: Per env kind (`isolated`, `server`), the directory env trees are built under; `~` is expanded
189            where the root is used.
190        envs: Env settings.
191        model_sources: Allowed hub organisations; None allows those of the catalogue entries.
192        model_cache_budget_bytes: Cap on the model cache; None measures it (`hardware.measured_budget`).
193        retry: How a transient fault is retried.
194        network: `online`, or `offline` to forbid any fetch.
195        resource_classes: The worker classes a node is placed on, by name (`cpu`, `gpu:<type>`, `mps`, `svc:<id>`).
196        substrate: What starts workers: `local` processes or `slurm` jobs.
197        pool: How pool workers claim and yield, and the quantum ceilings.
198        sizing: The fractions and targets a unit's batch, quantum and worker count are derived from (`size`).
199        calibration: How a unit without a measure is probed, where measures are kept and whose are trusted.
200        lease: How a lease is kept alive: its stale bound and renewal share, for job and pool leases alike.
201        faults: The retry budget of each fault class.
202        timeouts: A worker's load and request timeouts.
203        services: When an idle service exits.
204        supervisor: How a supervisor reads a launched process's start time, and reaps.
205        store: How a result store commits and how a storage root's clock is probed.
206        vllm: How a `vllm serve` process is started, polled, asked and stopped.
207        worker: How a worker client starts and watches its worker subprocess.
208        written: Each value `load` expanded, by its key path (a JSON list of keys), as `(written, expanded)` JSON:
209            what `identity_digest` takes in its place, the expanded form as validated. Only `load` records it.

263    @classmethod
264    def load(
265        cls, source: str | Path = DEFAULT_PROFILE, override: Mapping[str, Any] | Path | None = None
266    ) -> "ExecutionProfile":
267        """Return the profile `source` names with `override` (a mapping or a YAML file) deep-merged over it.
268
269        `source` is a packaged profile name (`laptop`, `slurm`), or a path to a profile file holding a whole profile.
270        Every string value of the merged mapping has its variables expanded (`expand_profile`).
271
272        Raises:
273            FileNotFoundError: `source` is neither a packaged profile nor a file.
274            IncompleteProfile: the merged mapping lacks keys, as a partial file passed as a profile does.
275            ProfileFormatRetired: the merged mapping declares a retired format.
276            UnfilledProfile: a value is still a `<fill: ...>` placeholder.
277            UnknownProfileKey: a key of `override` that the format does not define, naming the closest one.
278            UnsetProfileVariable: a value names a variable that is unset or empty, with no fallback.
279            WrittenFormsGiven: the profile or `override` holds a `written` block, which only the loader records.
280            LeaseBoundError: two of the lease's beat intervals plus its attribute delay are not below its stale bound.
281            ValueError: the merged mapping is invalid.
282        """
283        packaged = _read(_profile_source(source))
284        extra = override if isinstance(override, Mapping) else _read(override) if override is not None else {}
285        merged = merge_over(packaged, extra)
286        if check(EXECUTION_PROFILE_FORMAT, merged.get("format"), RETIRED_EXECUTION_PROFILE_FORMATS) is (
287            FormatVerdict.RETIRED
288        ):
289            raise ProfileFormatRetired(str(merged.get("format")))
290        missing = [k for k, f in cls.model_fields.items() if f.is_required() and k not in merged]
291        if missing:
292            raise IncompleteProfile(os.fspath(source), missing)
293        unfilled = _unfilled(merged)
294        if unfilled:
295            raise UnfilledProfile(str(merged.get("name", source)), unfilled)
296        _check_keys(merged, cls.model_fields)
297        if "written" in merged:
298            raise WrittenFormsGiven(os.fspath(source))
299        expanded = expand_profile(merged)
300        read = cls.model_validate(expanded).model_dump(mode="json")
301        written = {
302            json.dumps(p): (json.dumps(old), json.dumps(_at(read, p))) for p, old, _ in _changed(merged, expanded)
303        }
304        profile = cls.model_validate({**expanded, "written": written})
305        profile.lease.check_bound()
306        return profile

308    def identity_digest(self) -> str:
309        """Return the digest of the profile as written: each value `load` expanded counts as its written form.
310
311        It is the profile's identity in a plan (`PlanPlacement.profile_digest`) and the check a resume makes, so two
312        hosts whose environments expand a profile's variables differently place and resume under one profile. A
313        value changed since `load` (it no longer equals its expansion as read) counts as it is. The digest is the
314        `value@2` digest of the dumped document with the written forms in place, which is not validated again: a
315        written form such as `${HOOK}` need not satisfy its field.
316        """
317        document = self.model_dump(mode="json", exclude={"written"})
318        for path, (written, expanded) in self.written.items():
319            *above, last = json.loads(path)
320            holder: Any = document
321            for key in above:
322                holder = holder.get(key) if isinstance(holder, dict) else None
323            if isinstance(holder, dict) and holder.get(last) == json.loads(expanded):
324                holder[last] = json.loads(written)
325        return value_digest(f"{type(self).__module__}.{type(self).__qualname__}", document)

381def _unfilled(node: Any, path: str = "") -> dict[str, str]:  # noqa: ANN401 - any YAML node
382    """Return each `<fill: what>` string under `node` by its key path, with `what`."""
383    if isinstance(node, str):
384        found = _UNFILLED.match(node)
385        return {path: found[1]} if found else {}
386    if isinstance(node, Mapping):
387        return {
388            k: v
389            for key, item in node.items()
390            for k, v in _unfilled(item, f"{path}.{key}" if path else str(key)).items()
391        }
392    if isinstance(node, list):
393        return {k: v for i, item in enumerate(node) for k, v in _unfilled(item, f"{path}[{i}]").items()}
394    return {}

397def expand_profile(node: Any, key: str = "") -> Any:  # noqa: ANN401 - any YAML node
398    """Return `node` with every variable of every string value expanded from the environment.
399
400    `${VAR}` and `$VAR` are VAR's value, and `${VAR:-fallback}` VAR's value or, when VAR is unset or empty,
401    `fallback`. `${cache_root}` is left for `measures.resolve_roots`. A list item that holds a variable and expands
402    to the empty string is left out, so `${VAR:-}` is an optional item.
403
404    Raises:
405        UnsetProfileVariable: a value names a variable that is unset or empty and has no fallback, naming `key`'s path.
406    """
407    if isinstance(node, str):
408
409        def value(found: re.Match[str]) -> str:
410            name = found[1] or found[3]
411            if found[0] == CACHE_ROOT_TOKEN:
412                return found[0]
413            given = os.environ.get(name)
414            if given:
415                return given
416            if found[2] is not None:
417                return found[2][2:]
418            raise UnsetProfileVariable(key, name)
419
420        return _VARIABLE.sub(value, node)
421    if isinstance(node, Mapping):
422        return {k: expand_profile(v, f"{key}.{k}" if key else str(k)) for k, v in node.items()}
423    if isinstance(node, list):
424        items = [(item, expand_profile(item, f"{key}[{i}]")) for i, item in enumerate(node)]
425        return [new for old, new in items if not (new == "" and isinstance(old, str) and _VARIABLE.search(old))]
426    return node

436def _changed(old: Any, new: Any, path: tuple[str, ...] = ()) -> list[tuple[list[str], Any, Any]]:  # noqa: ANN401
437    """Return the key path, old value and new value of each leaf (a value that is not a mapping) that differs."""

461def _check_keys(mapping: Mapping[str, Any], fields: Mapping[str, object], path: str = "") -> None:
462    known = list(fields)
463    for key, value in mapping.items():
464        if key not in known:
465            close = difflib.get_close_matches(str(key), known, n=1)
466            hint = f"did you mean {close[0]!r}?" if close else f"known keys: {known}"
467            raise UnknownProfileKey(f"unknown profile key {path + str(key)!r}; {hint}")
468        if path or not isinstance(value, Mapping):
469            continue
470        if key in _SECTIONS:
471            _check_keys(value, _SECTIONS[key].model_fields, f"{key}.")
472        elif key == "resource_classes":
473            for name, given in value.items():
474                if isinstance(given, Mapping):
475                    _check_keys(given, ResourceClass.model_fields, f"resource_classes.{name}.")

487def resource_class(
488    backend: BackendSpec, profile: ExecutionProfile, hardware: HardwareInfo | None
489) -> tuple[str, ResourceClass] | None:
490    """Return the first resource class of `profile` that runs `backend`, by name, or None.
491
492    Devices are taken in `profile.devices` order and classes in profile order; a class runs the backend when the
493    backend declares its device and, with `hardware` given, this host has that device (and GPU type). With
494    `hardware` None the class is not judged against this host, as when a scheduler places the worker. A server
495    backend takes a service class (`svc:<id>`) that runs it before any other class, so its consumers share one
