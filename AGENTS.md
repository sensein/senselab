# AGENTS.md

This branch is senselab 2.x: the packages under `packages/`. The 1.x tree under `src/` is frozen and not
developed here.

Read [CLAUDE.md](CLAUDE.md) before working; it and [README.md](README.md) hold the setup, the test and lint
commands, and the conventions.

Never run `pytest -n auto`. Run the tests of the package or directory you changed, serially.
