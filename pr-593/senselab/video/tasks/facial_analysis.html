senselab.video.tasks.facial_analysis

Facial analysis of gallery-view recordings

Task overview

Per-person facial geometry, nonverbal events and affect from video calls recorded in gallery view (Zoom and similar): each participant occupies a fixed tile on a dark canvas. The recording is split into tiles once, each tile is analysed as its own face stream, and tiles can be linked to diarized speakers from mouth motion.

from senselab.video.tasks.facial_analysis import (
    analyze_gallery_video, detect_gallery_tiles, extract_face_geometry, extract_facial_affect,
    detect_nonverbal_events, summarize_tiles, link_tiles_to_speakers, segments_to_activity,
)

layout = detect_gallery_tiles("call.mp4")                 # tiles T0..Tn + layout timeline
geometry = extract_face_geometry("call.mp4", layout)      # MediaPipe, default 8 fps
affect = extract_facial_affect("call.mp4", layout)        # py-feat Detectorv2, default 2 fps
events = detect_nonverbal_events(geometry)                # nods, shakes, blinks per tile
summaries = summarize_tiles(geometry, affect, events)

frame = geometry.tiles["T0"]                              # one pandas DataFrame per tile
geometry.to_long().to_parquet("geometry.parquet")         # all tiles, with a tile_id column

t = geometry.tiles["T0"]["time_s"].to_numpy()
activity = {spk: segments_to_activity(segs, t) for spk, segs in diarization.items()}
mouths = {tile: df["bs_jawOpen"].to_numpy() for tile, df in geometry.tiles.items()}
link = link_tiles_to_speakers(mouths, activity, fps=geometry.fps)
link.assignment, link.p_value

analyze_gallery_video(path) runs all of the above in order. Inputs are file paths or file-backed Video objects; the video is always decoded from the file, front to back, inside the worker, so no frames cross the process boundary and memory stays bounded for any length.

Stages

Stage Function Backend Default rate
Tiles detect_gallery_tiles numpy, in process 48 sampled frames
Geometry extract_face_geometry MediaPipe Face Landmarker (subprocess venv mediapipe-face) 8 fps
Events detect_nonverbal_events scipy, in process from geometry
Affect extract_facial_affect py-feat 2.1.5 Detectorv2 (subprocess venv pyfeat) 2 fps
Linking link_tiles_to_speakers scipy Hungarian, in process geometry grid

Tiles. Sampled frames are split recursively along rows and columns that are dark over nearly their full extent (XY-cut), which handles one tile, side-by-side pairs, grids, and uneven arrangements such as two over one. The most frequent layout is the reference; its extents are re-estimated on the per-pixel maximum over the frames that share it and equalised across tiles, then inset past the active-speaker border, with a mask over the bottom-left name label. Every sampled frame is classified as reference, subset (a tile went dark, e.g. camera off) or different (screen share, speaker view); layout.layout_changes() lists the different runs.

Geometry columns. face_present, n_faces, head_pitch_deg (positive up), head_yaw_deg (positive toward the subject's right, i.e. image left), head_roll_deg, head translation, face box in tile-normalised coordinates, iris offsets eye_horizontal/eye_vertical (eye widths), inner-lip mouth_aspect, all 52 blendshapes as bs_<name>, tile motion_energy (mean absolute grey-level frame difference, 0-1, label masked) and the gaze proxy gaze_yaw_deg, gaze_pitch_deg, toward_camera (0-1). MediaPipe reports no face-confidence score; presence is binary.

Affect columns. face_score (0 when no face), n_faces, face box, head pose and gaze in degrees (same sign conventions as geometry), seven emotion probabilities (neutral, happy, sad, surprise, fear, disgust, anger), valence and arousal in [-1, 1], twenty AU probabilities (AU01 ... AU43). The largest face per tile is kept.

Events. Nods and shakes are runs of alternating extrema of band-passed (0.5-4 Hz) pitch or yaw with a minimum swing and a dominance ratio over the other axis. Blinks are brief rises of the eyeBlink blendshapes above a rolling-median baseline.

Linking. Mouth activity (rolling standard deviation of jawOpen) is correlated with each speaker's smoothed activity; the Hungarian algorithm picks the assignment, and a circular-shift null gives p_value. Use p_value, not total_margin, as the confidence.

Configuration

Every threshold and rate is in data/defaults.yaml with its derivation; pass a partial mapping as config= to any function to override it (deep-merged). geometry.threads / affect.threads cap a worker's CPU threads on a shared host. Throughput is measured by scripts/bench_facial_analysis.py.

Licences

  • MediaPipe and the Face Landmarker face_landmarker.task (float16, v1): Apache-2.0. The file is downloaded from Google's model bucket and verified against a pinned SHA-256.
  • py-feat code: MIT. The py-feat/face_multitask_v2 weights are released for research use only; see that repository's LICENSE. RetinaFace weights come from py-feat/retinaface_r34. Both are fetched at pinned commit SHAs, recorded in FrameTable.provenance.

Limitations

  • The gaze proxy is uncalibrated (no screen or camera geometry).
  • Blinks need about 16 fps; at the default 8 fps, rates are lower bounds. Blendshape blinks are weak behind glasses and on low-resolution video.
  • Nod, shake and blink thresholds are unfitted priors.
  • A tile showing two people is analysed for one face (MediaPipe num_faces=1; py-feat keeps the largest).
  • Gutters narrower than about 3 px at the 960 px analysis width can merge tiles.

331def detect_nonverbal_events(
332    geometry: FrameTable, config: Optional[Mapping[str, Any]] = None
333) -> Dict[str, NonverbalEvents]:
334    """Nods, shakes and blinks per tile from a geometry table.
335
336    Args:
337        geometry: Output of :func:`extract_face_geometry`.
338        config: Overrides of the defaults (``gestures`` and ``blinks`` sections).
339
340    Returns:
341        ``tile_id -> events``.
342    """
343    merged = load_defaults(config)
344    gestures = {k: v for k, v in merged["gestures"].items() if k != "derivation"}
345    blinks = {k: v for k, v in merged["blinks"].items() if k != "derivation"}
346    out: Dict[str, NonverbalEvents] = {}
347    for tile_id, frame in geometry.tiles.items():
348        head = detect_head_gestures(
349            frame["time_s"].to_numpy(),
350            frame["head_pitch_deg"].to_numpy(),
351            frame["head_yaw_deg"].to_numpy(),
352            geometry.fps,
353            tile_id=tile_id,
354            **gestures,
355        )
356        blink_events: List[BlinkEvent] = []
357        if "bs_eyeBlinkLeft" in frame and "bs_eyeBlinkRight" in frame:
358            blink_events = detect_blinks(
359                frame["time_s"].to_numpy(),
360                frame["bs_eyeBlinkLeft"].to_numpy(),
361                frame["bs_eyeBlinkRight"].to_numpy(),
362                tile_id=tile_id,
363                **blinks,
364            )
365        out[tile_id] = NonverbalEvents(
366            nods=[e for e in head if e.kind == "nod"],
367            shakes=[e for e in head if e.kind == "shake"],
368            blinks=blink_events,
369        )

118def extract_face_geometry(

121    fps: Optional[float] = None,
122    config: Optional[Mapping[str, Any]] = None,
123    timeout_s: Optional[float] = None,
124) -> FrameTable:
125    """Per-tile face geometry with MediaPipe Face Landmarker.
126
127    The video is decoded once, sequentially, at ``fps``; each tile (name label masked) goes through
128    its own landmarker in video mode. Columns per frame: ``face_present``, ``n_faces``, head
129    ``pitch/yaw/roll`` in degrees and translation from the facial transformation matrix, the face box
130    in tile-normalised coordinates, iris offsets, mouth aspect ratio, all 52 blendshapes as
131    ``bs_<name>``, tile ``motion_energy`` (mean absolute frame difference, 0-1), and the
132    toward-camera gaze proxy (``gaze_yaw_deg``, ``gaze_pitch_deg``, ``toward_camera``).
133
134    Args:
135        video: The recording.
136        layout: Tiles to analyse; detected when ``None``.
137        fps: Sampling rate; ``geometry.fps`` from the defaults when ``None``.
138        config: Overrides of the defaults.
139        timeout_s: Wall-clock ceiling on the worker.
140
141    Returns:
142        One DataFrame per tile, with provenance and timing.
143    """
144    merged = load_defaults(config)
145    path = _video_path(video)
146    layout = _layout_for(path, layout, merged)
147    geometry = dict(merged["geometry"])
148    if fps is not None:
149        geometry["fps"] = float(fps)
150    status, arrays = backends.run_mediapipe(path, layout, geometry, timeout_s=timeout_s)
151    names = status.get("blendshape_names") or []
152    gaze = merged["gaze"]
153    tables: Dict[str, pd.DataFrame] = {}
154    for tile in layout.tiles:
155        key = tile.tile_id
156        if f"{key}/time_s" not in arrays:
157            continue
158        pose = arrays[f"{key}/pose"]
159        eye = arrays[f"{key}/eye_offset"]
160        box = arrays[f"{key}/face_box"]
161        trans = arrays[f"{key}/translation"]
162        frame = pd.DataFrame(
163            {
164                "time_s": arrays[f"{key}/time_s"],
165                "face_present": arrays[f"{key}/face_present"],
166                "n_faces": arrays[f"{key}/n_faces"].astype(np.int16),
167                "head_pitch_deg": pose[:, 0],
168                "head_yaw_deg": pose[:, 1],
169                "head_roll_deg": pose[:, 2],
170                "head_tx": trans[:, 0],
171                "head_ty": trans[:, 1],
172                "head_tz": trans[:, 2],
173                "face_x": box[:, 0],
174                "face_y": box[:, 1],
175                "face_w": box[:, 2],
176                "face_h": box[:, 3],
177                "eye_horizontal": eye[:, 0],
178                "eye_vertical": eye[:, 1],
179                "mouth_aspect": arrays[f"{key}/mouth_aspect"],
180                "motion_energy": arrays[f"{key}/motion_energy"],
181            }
182        )
183        blends = arrays[f"{key}/blendshapes"]
184        for i, name in enumerate(names):
185            frame[f"bs_{name}"] = blends[:, i]
186        gaze_yaw, gaze_pitch, score = gaze_proxy(
187            frame["head_pitch_deg"].to_numpy(),
188            frame["head_yaw_deg"].to_numpy(),
189            frame["eye_horizontal"].to_numpy(),
190            frame["eye_vertical"].to_numpy(),
191            eye_gain_deg=gaze["eye_gain_deg"],
192            sigma_deg=gaze["sigma_deg"],
193            eye_vertical_neutral=gaze["eye_vertical_neutral"],
194        )
195        frame["gaze_yaw_deg"] = gaze_yaw.astype(np.float32)
196        frame["gaze_pitch_deg"] = gaze_pitch.astype(np.float32)
197        frame["toward_camera"] = score.astype(np.float32)
198        tables[key] = frame
199    return FrameTable(
200        kind="geometry",
201        fps=float(geometry["fps"]),
202        layout=layout,
203        tiles=tables,
204        provenance={
205            "backend": "mediapipe-face-landmarker",
206            "mediapipe_version": status.get("mediapipe_version"),
207            "model_url": backends.MEDIAPIPE_MODEL_URL,
208            "model_sha256": backends.MEDIAPIPE_MODEL_SHA256,
209            "decode_size": status.get("decode_size"),
210            "config": {k: v for k, v in geometry.items() if k != "derivation"},
211        },
212        timing=_timing(status),
213    )

242def extract_facial_affect(
243    video: VideoSource,
244    layout: Optional[GalleryLayout] = None,
245    fps: Optional[float] = None,
246    device: Optional[str] = None,
247    config: Optional[Mapping[str, Any]] = None,
248    timeout_s: Optional[float] = None,
249) -> FrameTable:
250    """Per-tile facial affect with py-feat ``Detectorv2`` (research-only weights).
251
252    Tile crops of each frame sampled at ``fps`` are batched through RetinaFace and the
253    ``face_multitask_v2`` model; the largest face per tile is kept. Columns per frame: ``face_score``
254    (0 without a face), ``n_faces``, the face box in tile pixels at the decode scale, head pose and
255    gaze in degrees, seven emotion probabilities (lower-case names), ``valence`` and ``arousal`` in
256    ``[-1, 1]``, and twenty AU probabilities (``AU01``..``AU43``).
257
258    The model weights are released for research use only; see the module documentation.
259
260    Args:
261        video: The recording.
262        layout: Tiles to analyse; detected when ``None``.
263        fps: Sampling rate; ``affect.fps`` from the defaults when ``None``.
264        device: ``"mps"``, ``"cuda"`` or ``"cpu"``; the best available when ``None``.
265        config: Overrides of the defaults.
266        timeout_s: Wall-clock ceiling on the worker.
267
268    Returns:
269        One DataFrame per tile, with provenance and timing.
270    """
271    merged = load_defaults(config)
272    path = _video_path(video)
273    layout = _layout_for(path, layout, merged)
274    affect = dict(merged["affect"])
275    if fps is not None:
276        affect["fps"] = float(fps)
277    status, arrays = backends.run_pyfeat(path, layout, affect, device or _default_device(), timeout_s=timeout_s)
278    columns: List[str] = status["columns"]
279    tables: Dict[str, pd.DataFrame] = {}
280    for tile in layout.tiles:
281        key = tile.tile_id
282        if f"{key}/time_s" not in arrays:
283            continue
284        values = arrays[f"{key}/values"]
285        frame = pd.DataFrame(values, columns=columns)
286        for column in _RADIAN_COLUMNS:
287            if column in frame:
288                frame[column] = np.degrees(frame[column])
289        frame = frame.rename(columns=_PYFEAT_RENAMES)
290        frame = frame.rename(
291            columns={c: c.lower() for c in frame.columns if c[:1].isupper() and not c.startswith("AU")}
292        )
293        frame.insert(0, "time_s", arrays[f"{key}/time_s"])
294        frame["n_faces"] = frame["n_faces"].astype(np.int16)
295        tables[key] = frame
296    return FrameTable(
297        kind="affect",
298        fps=float(affect["fps"]),
299        layout=layout,
300        tiles=tables,
301        provenance={
302            "backend": "py-feat-detectorv2",
303            "pyfeat_version": status.get("pyfeat_version"),
304            "torch_version": status.get("torch_version"),
305            "device": status.get("device"),
306            "multitask": (
307                f"{backends.PYFEAT_MULTITASK_REPO}@{backends.PYFEAT_MULTITASK_SHA}/{backends.PYFEAT_MULTITASK_FILE}"

def summarize_tiles( geometry: Optional[FrameTable] = None, affect: Optional[FrameTable] = None, events: Optional[Mapping[str, NonverbalEvents]] = None, config: Optional[Mapping[str, Any]] = None) -> List[TileSummary]: 
373def summarize_tiles(
374    geometry: Optional[FrameTable] = None,
375    affect: Optional[FrameTable] = None,
376    events: Optional[Mapping[str, NonverbalEvents]] = None,
377    config: Optional[Mapping[str, Any]] = None,
378) -> List[TileSummary]:
379    """Per-tile summaries over the whole recording.
380
381    Rates are per minute of face-present time (geometry frames with a face times the frame step).
382
383    Args:
384        geometry: Output of :func:`extract_face_geometry`.
385        affect: Output of :func:`extract_facial_affect`.
386        events: Output of :func:`detect_nonverbal_events`.
387        config: Overrides of the defaults (``gaze.toward_threshold``).
388
389    Returns:
390        One summary per tile seen in either table.
391    """
392    threshold = float(load_defaults(config)["gaze"]["toward_threshold"])
393    tile_ids = sorted(set(geometry.tiles if geometry else {}) | set(affect.tiles if affect else {}))
394    out: List[TileSummary] = []
395    for tile_id in tile_ids:
396        summary: Dict[str, Any] = {"tile_id": tile_id, "duration_s": 0.0, "face_present_fraction": 0.0}
397        if geometry is not None and tile_id in geometry.tiles:
398            frame = geometry.tiles[tile_id]
399            present = frame["face_present"].to_numpy(bool)
400            times = frame["time_s"].to_numpy()
401            summary["duration_s"] = float(times[-1] - times[0] + 1.0 / geometry.fps) if len(times) else 0.0
402            summary["face_present_fraction"] = float(present.mean()) if len(present) else 0.0
403            minutes = present.sum() / geometry.fps / 60.0
404            if present.any():
405                face = frame[present]
406                if "bs_jawOpen" in face:
407                    summary["mouth_open_mean"] = float(face["bs_jawOpen"].mean())
408                summary["toward_camera_fraction"] = float((face["toward_camera"] >= threshold).mean())
409            summary["motion_energy_mean"] = float(np.nanmean(frame["motion_energy"])) if len(frame) > 1 else None
410            if events is not None and tile_id in events and minutes > 0:
411                tile_events = events[tile_id]
412                summary["blink_rate_per_min"] = len(tile_events.blinks) / minutes
413                summary["nods_per_min"] = len(tile_events.nods) / minutes
414                summary["shakes_per_min"] = len(tile_events.shakes) / minutes
415        if affect is not None and tile_id in affect.tiles:
416            frame = affect.tiles[tile_id]
417            face = frame[frame["face_score"] > 0]
418            skip = {"time_s", "n_faces", "face_x", "face_y", "face_w", "face_h"}
419            summary["affect_means"] = {c: float(face[c].mean()) for c in face.columns if c not in skip and len(face)}
420            if geometry is None or tile_id not in geometry.tiles:
421                summary["face_present_fraction"] = float((frame["face_score"] > 0).mean()) if len(frame) else 0.0
422        out.append(TileSummary(**summary))
423    return out
